# 随机图与复杂网络

现实中的网络（互联网、社交网络、蛋白质网络）既不是规则的格子，也不是完全随机的。随机图模型和网络科学的指标，帮助我们理解这些大型网络的共同规律：小世界、高聚集、幂律度分布。

## 网络的基本指标

| 指标 | 定义 | 含义 |
| -- | -- | -- |
| 度分布 $P(k)$ | 随机顶点度为 $k$ 的概率 | 刻画连接数的不均匀程度 |
| 平均路径长度 $L$ | 所有顶点对最短距离的平均 | 信息传播的“远近” |
| 聚集系数 $C$ | 邻居之间也互相相邻的比例 | “朋友的朋友也是朋友”的程度 |
| 直径 | 最大的最短距离 | 最坏情况下的距离 |

表中依次为指标、定义和含义。顶点 $v$ 的局部聚集系数：

$$
C_v=\frac{2\,e_v}{d_v(d_v-1)}=\frac{\text{包含 }v\text{ 的三角形数}}{\text{以 }v\text{ 为中心的“连通三元组”数}}
$$

其中 $d_v$ 是 $v$ 的度，$e_v$ 是 $v$ 的邻居之间实际存在的边数（分母是邻居之间最多可能有的 $\binom{d_v}2$ 对）。全局聚集系数 $C$ 是各顶点 $C_v$ 的平均。例：完全图 $C=1$，树 $C=0$。

## Erdős–Rényi 随机图

$G(n,p)$：$n$ 个顶点，每对顶点以独立概率 $p$ 连边。

$$
\mathbb{E}[m]=p\binom n2,\qquad \mathbb{E}[\deg]=p(n-1)=\bar d,\qquad P(k)=\binom{n-1}kp^k(1-p)^{n-1-k}
$$

其中 $m$ 是边数，度 $k$ 服从二项分布；当 $n$ 大而平均度 $\bar d$ 固定时近似**泊松分布** $P(k)\approx e^{-\bar d}\dfrac{\bar d^k}{k!}$（见 [常见分布](/0063_概率论_常见分布)）。度分布集中在平均值附近，几乎没有度特别大的顶点。

**相变（阈值现象）**：随着 $p$ 增大，图的性质会突然改变：

| $p$ 的量级（$n\to\infty$） | 图的结构 |
| -- | -- |
| $p\ll\dfrac1n$ | 只有很小的树状分量 |
| $p=\dfrac cn$，$c>1$ | 出现**巨连通分量**（占顶点的比例是正数） |
| $p>\dfrac{\ln n}n$ | 几乎必然连通 |

表中依次为 $p$ 的量级和图的结构。巨分量出现的临界点是平均度 $\bar d=1$：每个顶点平均有一个邻居时，探索一个分量的过程像分支过程，$\bar d>1$ 时有正概率无限繁殖。临界点附近就像渗流相变。连通性阈值 $\ln n/n$ 来自“没有孤立点”的条件：孤立点期望个数 $n(1-p)^{n-1}\approx ne^{-pn}$，在 $p=\ln n/n$ 处趋近常数。证明工具是概率论中的第一/第二矩方法与泊松近似（见 [大数定律与中心极限定理](/0066_概率论_大数定律与中心极限定理)）。

但是 ER 图的聚集系数 $C\approx p$（很小），与真实网络不符。

## 小世界网络（Watts–Strogatz）

真实社交网络有两个特点：**高聚集**（朋友的朋友是朋友）与**短路径**（“六度分隔”，平均距离 $L\sim\ln n$）。规则环状格子聚集高但路径长（$L\sim n$）；随机图路径短但聚集低。**Watts–Strogatz 模型**：从每个顶点连向最近的 $k$ 个邻居的环形格子出发，以概率 $\beta$ 把每条边的一端随机重连。只需极少量的重连（$\beta\approx0.01$–$0.1$）就能使 $L$ 大幅下降，而 $C$ 几乎保持不变——这就是“小世界”。

## 无标度网络（Barabási–Albert）

许多网络（万维网、引文网络、蛋白质网络）的度分布是**幂律**：

$$
P(k)\sim k^{-\gamma},\qquad 2<\gamma<3\ (\text{典型值})
$$

其中 $\gamma$ 是幂律指数。幂律分布有“重尾”：少数**枢纽（hub）**拥有极多连接，缺少“特征尺度”，因此称**无标度**。在双对数坐标下 $\log P(k)$ 对 $\log k$ 近似直线（斜率 $-\gamma$）。$\gamma\le3$ 时度的方差发散，与泊松度分布迥然不同。

**BA 模型**（增长 + 优先连接）：每步新增一个顶点，带 $m$ 条边，连向已有顶点 $i$ 的概率正比于它的度：

$$
\Pi(i)=\frac{d_i}{\sum_jd_j}
$$

其中 $d_i$ 是顶点 $i$ 当前的度。“富者愈富”机制导致幂律，理论上 $\gamma=3$。后果：对随机失效**鲁棒**（随机删点大概率删到低度点），对针对枢纽的攻击**脆弱**；病毒传播的流行阈值趋于 $0$。

## 中心性

衡量顶点“重要程度”：

| 中心性 | 定义 | 解释 |
| -- | -- | -- |
| 度中心性 | $d_v/(n-1)$ | 直接朋友多 |
| 接近中心性 | $\dfrac{n-1}{\sum_ud(v,u)}$ | 到所有人平均很近 |
| 介数中心性 | $\sum_{s\ne v\ne t}\dfrac{\sigma_{st}(v)}{\sigma_{st}}$ | 位于大量最短路径上的“桥梁” |
| 特征向量中心性 | $A\mathbf{x}=\lambda_{\max}\mathbf{x}$ | 邻居重要则自己重要 |
| PageRank | $\mathbf{r}=\dfrac{1-\alpha}n\mathbf{1}+\alpha P^\top\mathbf{r}$ | 随机游走的平稳分布 |

表中依次为中心性、定义和解释。其中 $d(v,u)$ 是最短距离，$\sigma_{st}$ 是 $s$ 到 $t$ 的最短路径条数，$\sigma_{st}(v)$ 是其中经过 $v$ 的条数，$P$ 是随机游走转移矩阵，$\alpha\approx0.85$ 是阻尼系数。特征向量中心性与 PageRank 是矩阵特征向量，用幂法计算（见 [谱图论](/0124_图论_谱图论)、[特征值数值算法](/0113_数值计算_特征值数值算法)）；介数中心性用 Brandes 算法 $O(nm)$（BFS 计最短路径数，见 [图论 最短路径](/0115_图论_最短路径)）。

## 社区发现

网络中紧密连接的子群称**社区**。**模块度**衡量划分质量：

$$
Q=\frac1{2m}\sum_{i,j}\Bigl(A_{ij}-\frac{d_id_j}{2m}\Bigr)\delta(c_i,c_j)
$$

其中 $m$ 是边数，$c_i$ 是顶点 $i$ 所在社区，$\delta(c_i,c_j)=1$ 当且仅当同社区，$\dfrac{d_id_j}{2m}$ 是在保持度序列的随机图中 $i,j$ 之间边的期望数。含义：社区内部的边数比随机预期多多少。方法：Louvain 算法（贪心最大化 $Q$）、谱聚类（见 [谱图论](/0124_图论_谱图论)）、标签传播、Girvan-Newman（反复删去介数最大的边）。

## 网络上的传播

SIR/SIS 流行病模型在网络上的阈值：

$$
\frac{\beta}{\gamma}>\frac{\langle k\rangle}{\langle k^2\rangle}
$$

其中 $\beta$ 是感染率，$\gamma$ 是恢复率，$\langle k\rangle,\langle k^2\rangle$ 是度的一阶、二阶矩（见 [期望方差与矩](/0064_概率论_期望方差与矩)）。无标度网络中 $\langle k^2\rangle\to\infty$，阈值趋于 $0$：疾病/谣言几乎总能传播。免疫策略应优先针对枢纽。

## 应用

- 社交网络分析、推荐系统、舆情传播
- 互联网拓扑与鲁棒性设计、电网级联故障
- 生物与脑科学：蛋白质相互作用网络、神经连接组
- 流行病学：接触网络上的传播控制、疫苗分配
