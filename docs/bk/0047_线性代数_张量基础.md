# 张量基础

张量是向量、矩阵向更多维度的推广。深度学习里的数据（图像、批量序列、卷积核）几乎都以张量形式出现，理解它的阶、缩并和重排，是读懂各种
reshape/einsum 代码的基础。

## 概念关系图

``` mermaid
flowchart LR
    T[张量 多维数组] --> O[阶 0 标量 1 向量 2 矩阵 3 及以上]
    T --> E[爱因斯坦求和 指标记号]
    T --> P[基本运算 缩并 外积 逐元素]

```

图中：张量按阶（维度个数）分类；用指标记号和爱因斯坦求和简洁地写出运算；缩并（求和）与外积是基本运算；高阶张量可以分解成低阶因子的组合。

## 阶（维度）

| 阶数 | 对象   | 例子                              | 形状          |
| -- | ---- | ------------------------------- | ----------- |
| 0  | 标量   | 温度                              | $()$        |
| 1  | 向量   | 特征向量（见 [向量空间](/0034_线性代数_向量空间)） | $(d)$       |
| 2  | 矩阵   | 灰度图像、权重矩阵                       | $(m,n)$     |
| 3  | 三阶张量 | 彩色图像                            | $(H,W,C)$   |
| 4  | 四阶张量 | 一批图像                            | $(B,H,W,C)$ |

表中列依次为阶数（指标个数）、对象类型、例子和 NumPy/PyTorch
里的形状。注意这里的“维度”指张量的阶（轴的个数），不是向量空间的维数。

## 指标记号与爱因斯坦求和

张量元素用下标表示，例如 $T\_{ijk}$。爱因斯坦求和约定：重复出现的下标表示对其求和。

$$ C\_{ik}=\\sum\_jA\_{ij}B\_{jk}\\ \\equiv\\ A\_{ij}B\_{jk} $$

其中：

  - $A\\in\\mathbb{R}^{m\\times n}$，$B\\in\\mathbb{R}^{n\\times
    p}$，$C\\in\\mathbb{R}^{m\\times p}$：这就是矩阵乘积（见
    [矩阵乘积](/0027_线性代数_Matrix_矩阵乘积)）
  - $j$：重复下标，被求和消去（缩并）；$i,k$：自由下标，保留在结果里
  - 对应代码 `einsum("ij,jk->ik", A, B)`；同理内积 `"i,i->"`，迹 `"ii->"`（见
    [迹](/0037_线性代数_Matrix_迹)），哈达玛乘积 `"ij,ij->ij"`（见
    [哈达玛乘积](/0028_线性代数_Matrix_哈达玛乘积)），外积 `"i,j->ij"`

## 基本运算

  - 外积：$(\\mathbf{u}\\otimes\\mathbf{v})\_{ij}=u\_iv\_j$，把两个一阶张量变成二阶张量（矩阵，秩为
    1）
  - 缩并：对一对指标求和，使阶数减 2；矩阵乘积、内积、迹都是缩并的特例
  - 转置/置换轴：重新排列指标顺序，如 $(B,H,W,C)\\to(B,C,H,W)$
  - 重塑（reshape）：不改变元素和顺序，只改变形状；展开成矩阵（unfolding）是张量分解的第一步
  - 广播：形状不同的张量按规则（从末尾对齐，长度为 1 的轴复制）逐元素运算

## 与克罗内克积的联系

用列优先拉直 $\\operatorname{vec}(\\cdot)$，矩阵方程可以化为线性方程组：

$$ \\operatorname{vec}(AXB)=(B^\\top\\otimes A)\\operatorname{vec}(X) $$

其中：

  - $A\\in\\mathbb{R}^{m\\times p}$，$X\\in\\mathbb{R}^{p\\times
    q}$，$B\\in\\mathbb{R}^{q\\times r}$
  - $\\otimes$：克罗内克积（见 [克罗内克积](/0026_线性代数_Matrix_克罗内克积)）
  - $\\operatorname{vec}(X)$：把 $X$ 按列依次堆成一个长向量
  - 意义：对矩阵未知数的线性方程 $AXB=C$ 可以写成 $(B^\\top\\otimes
    A)\\mathbf{x}=\\operatorname{vec}(C)$，用线性方程组的方法求解（见
    [线性方程组](/0035_线性代数_线性方程组)）

## 张量分解（简介）

  - CP 分解：把三阶张量写成若干个秩 1 张量（三个向量外积）之和
    $\\mathcal{T}\\approx\\sum\_{r=1}^R\\mathbf{a}\_r\\otimes\\mathbf{b}\_r\\otimes\\mathbf{c}\_r$，是矩阵低秩分解的推广
  - Tucker 分解：核心张量乘以各个模上的因子矩阵，是 SVD 在高阶上的推广

其中 $R$ 是秩-1 分量的个数，$\\mathbf{a}\_r,\\mathbf{b}\_r,\\mathbf{c}\_r$
分别是三个模式上的因子向量。与矩阵不同，张量的秩没有简单的计算方法，也没有像 SVD 那样唯一的最佳低秩逼近。

## 应用

  - 深度学习：卷积核 $(C\_{out},C\_{in},k\_h,k\_w)$、注意力中的批量矩阵乘（`bmm`/`einsum`）
  - 模型压缩：用张量分解近似大权重
  - 推荐系统、信号处理中的多维数据分析

## 常见误区

  - 机器学习里说的「张量」一般指**多维数组**，不强调物理学中对坐标变换的协变 / 逆变性质
  - 张量的「阶」是维度个数，不要和矩阵的「秩」混淆；张量也有「秩」的概念，但定义和计算都比矩阵复杂得多
  - 不同框架对维度顺序的约定不同（如图像的 NCHW 与 NHWC），做运算和 reshape 前必须确认每个维度的含义
