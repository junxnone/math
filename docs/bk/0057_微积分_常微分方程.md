# 常微分方程

常微分方程（ODE）是含有未知函数及其导数的方程。自然界中“变化率取决于当前状态”的现象——人口增长、放射性衰变、振动、电路、神经网络的动力学——都用它描述。

## 概念关系图

``` mermaid
flowchart LR
    O[常微分方程 ODE] --> F[一阶 可分离 线性 齐次]
    O --> S[二阶常系数线性]
    O --> M[方程组 矩阵指数]
    O --> Q[稳定性 相平面 特征值]
    O --> N[数值解 欧拉法]
```

图中：ODE 按阶数与线性性分类；一阶与二阶常系数方程有解析解法；方程组借助线性代数（特征值）求解并分析稳定性；一般方程用数值方法求近似解。

## 基本概念

$$ F\\bigl(t,,y,,y',,\\dots,,y^{(n)}\\bigr)=0 $$

其中：

  - $t$：自变量（常为时间）；$y(t)$：未知函数；$y^{(k)}$：$k$ 阶导数
  - $n$：方程中出现的最高阶导数的阶数，称为方程的阶
  - 通解含 $n$ 个任意常数；加上 $n$ 个初始条件 $y(t\_0),y'(t\_0),\\dots$ 得到特解（初值问题）
  - 存在唯一性定理：$y'=f(t,y)$ 中 $f$ 与 $\\partial f/\\partial y$ 连续，则初值问题局部有唯一解

## 一阶方程

| 类型    | 形式                        | 解法                                                        |
| ----- | ------------------------- | --------------------------------------------------------- |
| 可分离变量 | $y'=g(t)h(y)$             | $\\displaystyle\\int\\frac{dy}{h(y)}=\\int g(t),dt$       |
| 一阶线性  | $y'+p(t)y=q(t)$           | 积分因子 $\\mu=e^{\\int p,dt}$，$y=\\dfrac1\\mu\\int\\mu q,dt$ |
| 齐次    | $y'=f(y/t)$               | 令 $u=y/t$ 化为可分离                                           |
| 恰当方程  | $M,dt+N,dy=0$，$M\_y=N\_t$ | 存在 $\\phi$ 使 $d\\phi=0$                                   |

表中依次为类型、形式和解法，其中 $g,h,p,q,f,M,N$ 为已知函数，$C$ 为积分常数。积分的计算见
[积分](/0052_微积分_积分)。

例（指数增长/衰减）：

$$ \\frac{dy}{dt}=ky\\ \\Rightarrow\\ y(t)=y\_0e^{kt} $$

其中 $y\_0=y(0)$ 是初值，$k$ 是增长率（$k\>0$ 增长，$k\<0$ 衰减）。放射性衰变 $k\<0$，半衰期
$T\_{1/2}=\\ln2/|k|$。

## 二阶常系数线性方程

$$ y''+py'+qy=f(t) $$

其中 $p,q$ 为常数，$f(t)$ 为外力项（$f=0$ 为齐次方程）。通解 = 齐次通解 + 一个特解。

齐次方程的特征方程 $r^2+pr+q=0$ 的根决定解的形式：

| 特征根                        | 通解                                                   |
| -------------------------- | ---------------------------------------------------- |
| 两个不同实根 $r\_1,r\_2$         | $C\_1e^{r\_1t}+C\_2e^{r\_2t}$                        |
| 重根 $r$                     | $(C\_1+C\_2t)e^{rt}$                                 |
| 共轭复根 $\\alpha\\pm i\\beta$ | $e^{\\alpha t}(C\_1\\cos\\beta t+C\_2\\sin\\beta t)$ |

表中左列为特征根情形，右列为通解，$C\_1,C\_2$ 是由初始条件确定的常数。复根情形由欧拉公式 $e^{i\\beta
t}=\\cos\\beta t+i\\sin\\beta t$ 得到（见 [级数](/0053_微积分_级数)）。

例：简谐振动 $y''+\\omega^2y=0$，根为 $\\pm i\\omega$，解 $y=C\_1\\cos\\omega
t+C\_2\\sin\\omega t$，$\\omega$ 为角频率；加入阻尼 $y''+2\\gamma y'+\\omega^2y=0$
则对应实部 $-\\gamma$：衰减振荡。

## 方程组与线性代数

一阶线性常系数方程组：

$$ \\dot{\\mathbf{x}}=A\\mathbf{x}\\ \\Rightarrow\\
\\mathbf{x}(t)=e^{At}\\mathbf{x}\_0 $$

其中：

  - $\\mathbf{x}(t)\\in\\mathbb{R}^n$：状态向量；$\\dot{\\mathbf{x}}=d\\mathbf{x}/dt$；$A\\in\\mathbb{R}^{n\\times
    n}$：常数矩阵；$\\mathbf{x}\_0$：初始状态
  - $e^{At}=\\sum\_{k\\ge0}\\dfrac{(At)^k}{k\!}$：矩阵指数
  - 若 $A=P\\Lambda P^{-1}$ 可对角化，则 $e^{At}=Pe^{\\Lambda t}P^{-1}$，每个分量按
    $e^{\\lambda\_it}$ 演化（见 [特征值与特征向量](/0036_线性代数_特征值与特征向量)）
  - 高阶方程可以化为一阶方程组：令 $x\_1=y,\\ x\_2=y'$

## 例题

  - **一阶线性**：$y'+y=t$，积分因子 $\\mu=e^t$，$(e^ty)'=te^t$，积分得
    $e^ty=(t-1)e^t+C$，所以
    $y=t-1+Ce^{-t}$。验证：$y'+y=(1-Ce^{-t})+(t-1+Ce^{-t})=t$ ✓。
  - **逻辑斯蒂方程**：$\\dot y=ry(1-y/K)$ 分离变量并用部分分式，解为
    $y(t)=\\dfrac{K}{1+\\bigl(\\tfrac K{y\_0}-1\\bigr)e^{-rt}}$，其中
    $y\_0$ 为初值；$t\\to\\infty$ 时 $y\\to K$，$y=K$ 是稳定平衡点，$y=0$ 不稳定。
  - **二阶**：$y''-3y'+2y=0$，特征方程 $r^2-3r+2=0$，$r=1,2$，通解
    $y=C\_1e^t+C\_2e^{2t}$；若 $y(0)=1,\\ y'(0)=0$，则 $C\_1+C\_2=1,\\
    C\_1+2C\_2=0$，得 $C\_1=2,\\ C\_2=-1$。
  - **欧拉法数值例**：$y'=y,\\ y(0)=1$，$h=0.1$，十步得 $(1.1)^{10}\\approx2.594$，真解
    $y(1)=e\\approx2.718$，相对误差约 4.6%；$h$ 减半误差约减半（一阶方法）。

## 受迫振动与共振（简介）

$$ y''+\\omega^2y=F\\cos\\Omega t $$

其中 $\\omega$ 是系统固有角频率，$F$ 是外力幅度，$\\Omega$ 是外力角频率。$\\Omega\\ne\\omega$
时特解为 $\\dfrac F{\\omega^2-\\Omega^2}\\cos\\Omega
t$，振幅有界；$\\Omega\\to\\omega$
时振幅趋于无穷（共振），实际系统中由阻尼限制。这也是桥梁、电路设计中要避开固有频率的原因。

## 稳定性

对 $\\dot{\\mathbf{x}}=A\\mathbf{x}$，平衡点 $\\mathbf{x}=\\mathbf{0}$：

| 特征值 $\\lambda\_i$ | 平衡点性质        |
| ----------------- | ------------ |
| 所有实部 $\<0$        | 渐近稳定（解衰减到 0） |
| 存在实部 $\>0$        | 不稳定（解发散）     |
| 实部为 0             | 临界（如纯振荡）     |

表中左列是特征值实部的情形，右列是系统行为。非线性系统在平衡点附近用雅可比矩阵线性化后判断（见
[雅可比矩阵](/0044_线性代数_Matrix_雅可比矩阵)）。

## 数值解：欧拉法

$$ y\_{k+1}=y\_k+h,f(t\_k,y\_k) $$

其中 $h$ 为步长，$t\_k=t\_0+kh$，$y\_k\\approx y(t\_k)$。这是一阶泰勒展开（见
[中值定理与泰勒公式](/0051_微积分_中值定理与泰勒公式)）的直接结果，局部误差
$O(h^2)$，整体误差 $O(h)$；实际常用精度更高的龙格-库塔法。

## 应用

  - 物理：牛顿第二定律 $m\\ddot{x}=F$、电路 RLC
  - 生物与社会：人口模型（逻辑斯蒂方程 $\\dot y=ry(1-y/K)$，$r$ 为增长率，$K$ 为环境容量）、传染病 SIR 模型
  - 机器学习：梯度流 $\\dot{\\theta}=-\\nabla L(\\theta)$ 是梯度下降的连续极限；Neural ODE
    把网络层数连续化
  - 控制：状态空间模型、稳定性设计

## 在机器学习中的作用

  - 神经常微分方程（Neural ODE）：把残差网络看作 ODE 的欧拉离散，$h\_{t+1}=h\_t+f(h\_t)$ 是欧拉法
  - 梯度流：梯度下降是 $\\dot\\theta=-\\nabla\\mathcal{L}(\\theta)$
    的欧拉离散，学习率就是步长，见
    [一阶方法与随机梯度](https://github.com/junxnone/math/issues/81)
  - 动力系统的稳定性分析：用特征值判断平衡点性质，见
    [特征值与特征向量](https://github.com/junxnone/math/issues/36)

## 常见误区

  - 通解含任意常数，需要**初值条件**才能确定唯一特解；初值问题的解的存在唯一性有定理保证（Picard），不是总成立
  - 线性方程组的稳定性由系数矩阵特征值的**实部**决定，不是模长
  - 数值解的步长太大会使显式方法失稳（尤其对刚性方程），不是步长越小总越好，见
    [常微分方程数值解](https://github.com/junxnone/math/issues/112)
