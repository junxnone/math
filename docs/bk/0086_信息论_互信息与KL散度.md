# 互信息与 KL 散度

KL 散度衡量两个概率分布的差异，互信息衡量两个随机变量的统计依赖。两者本质上是同一个量：互信息就是联合分布与“假设独立”的乘积分布之间的 KL
散度。

## 概念关系图

``` mermaid
flowchart LR
    KL[KL 散度 衡量 P 与 Q 的差异] --> MI[互信息 联合分布与边缘乘积的 KL]
    KL --> O[其他散度 JS f-散度 Wasserstein]
    MI --> DP[数据处理不等式]
    KL --> FI[局部与费希尔信息的联系]
```

图中：互信息是联合分布相对于「独立假设下的边缘乘积」的 KL 散度；JS、$f$-散度、Wasserstein 是 KL
的推广或替代；数据处理不等式说明处理不会增加信息；局部上 KL 对应费希尔信息。

## KL 散度

$$ D\_{\\mathrm{KL}}(P\\Vert
Q)=\\sum\_xp(x)\\log\\frac{p(x)}{q(x)}=\\mathbb{E}\_{x\\sim
P}\\Bigl\[\\log\\frac{p(x)}{q(x)}\\Bigr\] $$

其中：

  - $P,Q$：两个分布，$p,q$ 是各自的概率（连续时换成密度并改为积分）；要求 $q(x)=0\\Rightarrow
    p(x)=0$（绝对连续），否则散度为 $+\\infty$
  - 含义：真实分布是 $P$ 而用 $Q$ 来编码/建模时，每个样本平均多付出的比特数

性质：

  - **非负性**（吉布斯不等式）：$D\_{\\mathrm{KL}}(P\\Vert Q)\\ge0$，等号当且仅当
    $P=Q$。证明：由詹森不等式（$-\\log$ 是凸函数，见
    [期望方差与矩](/0064_概率论_期望方差与矩)）$D\_{\\mathrm{KL}}=\\mathbb{E}\_P\[-\\log\\tfrac
    qp\]\\ge-\\log\\mathbb{E}\_P\[\\tfrac qp\]=-\\log\\sum q=0$。
  - **不对称**：$D\_{\\mathrm{KL}}(P\\Vert Q)\\ne D\_{\\mathrm{KL}}(Q\\Vert
    P)$，不是距离（不满足三角不等式）。
  - 对分布的参数是凸的（对 $(P,Q)$ 联合凸）。

例：$P=\\text{Bern}(0.5)$，$Q=\\text{Bern}(0.1)$（奈特）：

$$ D\_{\\mathrm{KL}}(P\\Vert
Q)=0.5\\ln\\frac{0.5}{0.1}+0.5\\ln\\frac{0.5}{0.9}\\approx0.5\\times1.609-0.5\\times0.588\\approx0.511,
$$

反过来 $D\_{\\mathrm{KL}}(Q\\Vert
P)=0.1\\ln0.2+0.9\\ln1.8\\approx-0.161+0.529=0.368$，二者不同。

**两个高斯的 KL 散度**（一维，闭式）：

$$
D\_{\\mathrm{KL}}\\bigl(\\mathcal{N}(\\mu\_1,\\sigma\_1^2)\\Vert\\mathcal{N}(\\mu\_2,\\sigma\_2^2)\\bigr)=\\ln\\frac{\\sigma\_2}{\\sigma\_1}+\\frac{\\sigma\_1^2+(\\mu\_1-\\mu\_2)^2}{2\\sigma\_2^2}-\\frac12
$$

其中 $\\mu\_i,\\sigma\_i$ 是两个分布的均值与标准差。取 $Q=\\mathcal{N}(0,1)$
即变分自编码器（VAE）中的 KL 正则项（见
[高斯分布进阶](/0005_概率论_常见分布_高斯分布进阶)）。

**前向与反向 KL**：最小化 $D\_{\\mathrm{KL}}(P\\Vert Q\_\\theta)$（前向）迫使 $Q$ 覆盖
$P$ 的所有支撑（均值寻求，对应最大似然）；最小化 $D\_{\\mathrm{KL}}(Q\_\\theta\\Vert
P)$（反向，变分推断）则让 $Q$ 集中在 $P$ 的某个峰（模式寻求）。

## 互信息

$$ I(X;Y)=D\_{\\mathrm{KL}}\\bigl(P\_{XY}\\Vert
P\_XP\_Y\\bigr)=\\sum\_{x,y}p(x,y)\\log\\frac{p(x,y)}{p(x)p(y)} $$

其中 $P\_{XY}$ 是联合分布，$P\_XP\_Y$ 是边缘分布的乘积（即“假设独立”时的联合分布）。等价形式：

$$ I(X;Y)=H(X)-H(X\\mid Y)=H(Y)-H(Y\\mid X)=H(X)+H(Y)-H(X,Y) $$

其中 $H$ 是熵（见 [熵](/0085_信息论_熵)）。含义：知道 $Y$ 后 $X$ 的不确定性减少多少。性质：

  - $I(X;Y)\\ge0$，等号当且仅当 $X,Y$ 独立；对称 $I(X;Y)=I(Y;X)$；$I(X;X)=H(X)$
  - 与相关系数对比：相关系数只反映线性相关，互信息捕捉任意（包括非线性）依赖。例：$Y=X^2$ 且 $X$ 对称分布，相关系数为 0，但
    $I(X;Y)\>0$（见 [多维随机变量与协方差](/0065_概率论_多维随机变量与协方差)）
  - 二元正态：$I(X;Y)=-\\tfrac12\\ln(1-\\rho^2)$，其中 $\\rho$ 是相关系数

熵与互信息的关系（可用集合图直观记忆）：

| 量             | 对应                 | 集合图解释       |
| ------------- | ------------------ | ----------- |
| $H(X)$        | 圆 $X$ 的总面积         | 全部不确定性      |
| $H(X\\mid Y)$ | $X$ 圆去掉与 $Y$ 重叠的部分 | $Y$ 无法解释的部分 |
| $I(X;Y)$      | 两圆重叠               | 共享的信息       |
| $H(X,Y)$      | 两圆的并               | 联合不确定性      |

表中依次为信息量、对应的区域和含义，用两个相交的圆表示 $X,Y$：$H(X,Y)=H(X)+H(Y)-I(X;Y)$。

## 数据处理不等式

若 $X\\to Y\\to Z$ 构成马尔可夫链（$Z$ 只通过 $Y$ 依赖于 $X$，见
[随机过程初步](/0067_概率论_随机过程初步)），则：

$$ I(X;Z)\\le I(X;Y) $$

其中 $Z$ 是对 $Y$ 的任何（随机）处理结果。含义：对数据做任何加工都不会增加关于 $X$
的信息，只能保持或丢失。这是特征提取、压缩和神经网络逐层处理的信息论约束（信息瓶颈理论）。

## 其他散度

  - **JS 散度**：$\\mathrm{JS}(P,Q)=\\tfrac12D\_{\\mathrm{KL}}(P\\Vert
    M)+\\tfrac12D\_{\\mathrm{KL}}(Q\\Vert
    M)$，$M=\\tfrac{P+Q}2$。对称、有界（$\\le\\ln2$），原始 GAN
    的目标等价于最小化它。
  - **$f$-散度**：$D\_f(P\\Vert
    Q)=\\mathbb{E}\_Q\[f(p/q)\]$，KL、总变差、卡方散度都是特例。
  - **Wasserstein 距离**：考虑支撑之间的几何距离，分布不重叠时仍有梯度。

## 与费希尔信息的联系

当 $Q$ 与 $P$ 很接近时：

$$ D\_{\\mathrm{KL}}(p\_\\theta\\Vert
p\_{\\theta+\\delta})\\approx\\tfrac12,\\delta^\\top I(\\theta),\\delta
$$

其中 $I(\\theta)$ 是费希尔信息矩阵（见 [点估计](/0070_数理统计_点估计)），$\\delta$
是参数的微小变化（二阶泰勒展开，见
[中值定理与泰勒公式](/0051_微积分_中值定理与泰勒公式)）。这就是自然梯度、信赖域策略优化（TRPO）里用
KL 约束步长的依据。

## 应用

  - 机器学习：最大似然等价于最小化 KL（见 [交叉熵与损失函数](/0087_信息论_交叉熵与损失函数)）、VAE 的
    ELBO、知识蒸馏、强化学习中的策略约束
  - 特征选择：按特征与标签的互信息排序；InfoNCE 等对比学习目标是互信息的下界
  - 通信：信道容量 $=\\max I(X;Y)$（见 [信道容量](/0089_信息论_信道容量)）
  - 统计：独立性检验、模型选择（AIC 来自 KL 的估计）

## 几种距离 / 散度对比

| 度量                         | 对称？ | 是否满足三角不等式 | 特点                              |
| -------------------------- | --- | --------- | ------------------------------- |
| KL 散度 $D\_{KL}(P\\Vert Q)$ | 否   | 否         | 非负，$P=Q$ 时为 0；要求 $P$ 对 $Q$ 绝对连续 |
| JS 散度                      | 是   | 平方根满足     | 有界，GAN 的原始目标                    |
| Wasserstein 距离             | 是   | 是         | 考虑样本空间的几何，分布无重叠时仍有意义            |
| 总变差距离                      | 是   | 是         | 概率差的最大值                         |

表中：对比结论：KL 不是距离；需要对称、有界或几何感知时选 JS、Wasserstein。

## 常见误区

  - $D\_{KL}(P\\Vert Q)\\ne D\_{KL}(Q\\Vert P)$：前者倾向于覆盖 $P$
    的所有模式（均值寻求），后者倾向于集中在 $Q$ 的单个模式（模式寻求）
  - 互信息度量**任意形式**的依赖（含非线性），相关系数只度量线性；互信息为 0 当且仅当独立
  - 若 $Q(x)=0$ 而 $P(x)\>0$，$D\_{KL}(P\\Vert Q)=\\infty$，实践中需要平滑
