# 测度论基础

测度论把「长度、面积、概率」推广为一般的**测度**，并在此基础上定义更强的积分（勒贝格积分）。概率论的严格基础就是测度论：概率是总测度为 1
的测度，随机变量是可测函数，期望是勒贝格积分。概率空间见
[概率空间与公理](https://github.com/junxnone/math/issues/60)，积分见
[积分](https://github.com/junxnone/math/issues/52)。

## 概念关系图

``` mermaid
flowchart LR
    S[集合 Omega] --> A[sigma 代数 可测集的族]
    A --> M[测度 mu 满足可数可加]
    M --> F[可测函数 保持可测性]
    F --> I[勒贝格积分 对测度积分]
    M --> P[概率测度 总测度为 1]
    F --> R[随机变量 期望即积分]
```

图中：在集合上选定
$\\sigma$-代数规定哪些子集可测，再定义满足可数可加的测度；对可测函数可以定义勒贝格积分；概率测度与随机变量、期望是其特例。

## 基本定义

**$\\sigma$-代数** $\\mathcal{F}$ 是 $\\Omega$ 的子集族，满足：包含
$\\Omega$、对补集封闭、对可数并封闭。**测度**是满足下面条件的函数
$\\mu:\\mathcal{F}\\to\[0,\\infty\]$：

$$ \\mu(\\varnothing)=0,\\qquad
\\mu\\Bigl(\\bigsqcup\_{i=1}^{\\infty}A\_i\\Bigr)=\\sum\_{i=1}^{\\infty}\\mu(A\_i)\\
\\ (\\text{不相交的 }A\_i\\in\\mathcal{F}) $$

其中：$\\bigsqcup$ 表示不相交并；第二个性质称为**可数可加性**。例：勒贝格测度（长度 / 面积 /
体积）、计数测度、概率测度（$\\mu(\\Omega)=1$）。

## 可测函数与勒贝格积分

函数 $f$ 可测，指任意区间的原像都是可测集。勒贝格积分对「**值域**」分层求和，而不是像黎曼积分那样对定义域分割：

$$ \\int f,d\\mu=\\sup\\Bigl{\\int s,d\\mu\\ :\\ 0\\le s\\le f,\\ s\\
\\text{为简单函数}\\Bigr},\\qquad \\int s,d\\mu=\\sum\_{k}c\_k,\\mu(E\_k) $$

其中：简单函数 $s=\\sum c\_k\\mathbf{1}\_{E\_k}$ 在每个可测集 $E\_k$ 上取常数
$c\_k$；积分是用简单函数从下方逼近的上确界。

## 与黎曼积分对比

| 对比项     | 黎曼积分            | 勒贝格积分           |
| ------- | --------------- | --------------- |
| 分割对象    | 定义域（区间）         | 值域              |
| 可积函数类   | 要求几乎处处连续        | 更广（如狄利克雷函数）     |
| 极限与积分交换 | 条件苛刻            | 有强定理（单调收敛、控制收敛） |
| 适用空间    | $\\mathbb{R}^n$ | 任意测度空间（含概率空间）   |

表中：对比结论：勒贝格积分对极限运算更友好，因此是概率论、泛函分析的标准积分。

## 三大收敛定理

设 $f\_n\\to f$ 几乎处处：

  - **单调收敛**：$0\\le f\_n\\uparrow f\\Rightarrow\\int f\_n,d\\mu\\to\\int
    f,d\\mu$
  - **Fatou 引理**：$\\int\\liminf f\_n,d\\mu\\le\\liminf\\int f\_n,d\\mu$
  - **控制收敛**：若 $\\lvert f\_n\\rvert\\le g$ 且 $\\int g,d\\mu\<\\infty$，则
    $\\int f\_n,d\\mu\\to\\int f,d\\mu$

其中：$g$ 称为控制函数；这些定理说明什么时候可以**交换极限与积分**，是证明期望的极限性质（如大数定律）的关键，见
[大数定律与中心极限定理](https://github.com/junxnone/math/issues/66)。

## 在概率论中的对应

| 测度论                                | 概率论                                            |
| ---------------------------------- | ---------------------------------------------- |
| 测度空间 $(\\Omega,\\mathcal{F},\\mu)$ | 概率空间 $(\\Omega,\\mathcal{F},P)$，$P(\\Omega)=1$ |
| 可测函数                               | 随机变量 $X$                                       |
| 勒贝格积分 $\\int X,dP$                 | 期望 $\\mathbb{E}\[X\]$                          |
| 几乎处处（a.e.）                         | 几乎必然（a.s.）                                     |
| 绝对连续与 Radon–Nikodym 导数             | 概率密度函数                                         |

表中：对比结论：离散与连续分布、混合分布都可以统一用测度表达，不必分别处理，见
[随机变量与分布](https://github.com/junxnone/math/issues/62)。

## 在机器学习中的作用

  - 严格定义条件期望、鞅、随机过程，是随机分析的基础，见
    [随机过程进阶](https://github.com/junxnone/math/issues/13)
  - 理解「几乎处处」「概率为 0 的事件」，以及密度函数的本质（对参考测度的导数）
  - 概率分布间的 KL 散度、变量替换公式都以测度之间的绝对连续为前提，见
    [互信息与KL散度](https://github.com/junxnone/math/issues/86)

## 常见误区

  - 概率为 0 的事件可以发生（如连续分布取到某个具体值）；「几乎必然」不是「必然」
  - 不是所有子集都可测（Vitali 集），所以必须用 $\\sigma$-代数限定可测集
  - 勒贝格积分与黎曼积分在黎曼可积时数值相同；二者的差别在于可积函数类和极限交换性质
