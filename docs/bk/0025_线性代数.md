# 线性代数

  - [3DKG](https://junxnone.github.io/jstools/md3dkg/?md=https://junxnone.github.io/tmdkg/docs/0011_%E7%BA%BF%E6%80%A7%E4%BB%A3%E6%95%B0.md)

线性代数研究**向量空间**以及空间之间的**线性映射**，是机器学习、图形学、点云/SLAM、信号处理等领域的基础工具。

## 核心思想

  - “线性”首先体现在向量的两种运算上：向量加法和数乘。满足这两种运算封闭且遵守运算规则的集合称为向量空间，这些规则构成一种代数结构。
  - 线性映射（线性变换）是保持加法与数乘的映射，在选定基之后可以用矩阵表示。矩阵既是线性方程组的系数表，也是空间变换的“操作”。矩阵之间有加法、乘法，并存在单位矩阵、逆矩阵等概念，这些都属于代数研究的范畴。

线性映射的定义：

$$ f(a\\mathbf{x} + b\\mathbf{y}) = a f(\\mathbf{x}) + b f(\\mathbf{y})
$$

其中：

  - $f$：线性映射，把一个向量空间中的向量映射到另一个向量空间
  - $\\mathbf{x}, \\mathbf{y}$：向量空间中的任意向量
  - $a, b$：任意标量（实数或复数），用于数乘
  - 含义：“先线性组合再变换”与“先变换再线性组合”结果一致；在选定基后 $f(\\mathbf{x}) =
    A\\mathbf{x}$，$A$ 即该映射对应的矩阵

## 向量空间、基与维数

详见 [向量空间](/0034_线性代数_向量空间)。

向量空间中的任意向量都可以由一组基线性表示：

$$ \\mathbf{v} = c\_1 \\mathbf{e}\_1 + c\_2 \\mathbf{e}\_2 + \\dots +
c\_n \\mathbf{e}\_n $$

其中：

  - $\\mathbf{v}$：空间中的任意向量
  - $\\mathbf{e}\_1,\\dots,\\mathbf{e}\_n$：一组基，即线性无关且能张成整个空间的向量组（见
    [线性相关无关](/0024_线性代数_线性相关无关)）
  - $c\_i$：$\\mathbf{v}$ 在该基下的坐标，换一组基坐标会变，向量本身不变
  - $n$：基中向量的个数，称为空间的维数，与基的选取无关

线性方程组也是线性代数最经典的问题：

$$ A\\mathbf{x} = \\mathbf{b} $$

其中：

  - $A \\in \\mathbb{R}^{m\\times n}$：系数矩阵，$m$ 个方程、$n$ 个未知数
  - $\\mathbf{x} \\in \\mathbb{R}^{n}$：待求的未知向量
  - $\\mathbf{b} \\in \\mathbb{R}^{m}$：右端常数向量
  - 解的存在性与唯一性由 $A$ 的秩、行列式、可逆性决定（见下文各主题）

## 关键概念速览

三个最常被混淆的矩阵乘法：

$$ C = AB,\\qquad C = A \\odot B,\\qquad C = A \\otimes B $$

其中：

  - $AB$：矩阵乘积，要求 $A$ 的列数等于 $B$ 的行数，$C\_{ij} = \\sum\_k
    A\_{ik}B\_{kj}$，对应线性映射的复合
  - $A \\odot B$：哈达玛乘积，要求 $A,B$ 同型，逐元素相乘，$C\_{ij} = A\_{ij}B\_{ij}$
  - $A \\otimes B$：克罗内克积，把 $A$ 的每个元素 $a\_{ij}$ 替换为分块
    $a\_{ij}B$，结果维度为两者维度之积

方阵可逆的等价条件（节选）：

$$ A \\text{ 可逆} \\iff \\det A \\neq 0 \\iff \\operatorname{rank}(A) = n
\\iff A\\mathbf{x}=\\mathbf{0} \\text{ 只有零解} $$

其中：

  - $A \\in \\mathbb{R}^{n\\times n}$：$n$ 阶方阵
  - $\\det A$：$A$ 的行列式
  - $\\operatorname{rank}(A)$：$A$
    的秩，即线性无关的行（列）向量的最大个数；$\\operatorname{rank}(A)=n$
    称满秩
  - 此时 $A\\mathbf{x}=\\mathbf{b}$ 有唯一解 $\\mathbf{x} = A^{-1}\\mathbf{b}$

秩与零空间之间的关系（秩-零化度定理）：

$$ \\operatorname{rank}(A) + \\dim\\operatorname{Null}(A) = n $$

其中：

  - $A \\in \\mathbb{R}^{m\\times n}$：系数矩阵，$n$ 为列数（未知数个数）
  - $\\operatorname{Null}(A) = {\\mathbf{x} \\mid
    A\\mathbf{x}=\\mathbf{0}}$：零空间，齐次方程组所有解的集合
  - $\\dim$：空间维数；该式说明“有效约束个数 + 自由度 = 未知数个数”

行列式的几何意义：

$$ \\operatorname{vol}\\bigl(A(\\text{单位立方体})\\bigr) = |\\det A| $$

其中：

  - $A \\in \\mathbb{R}^{n\\times n}$：被视为 $\\mathbb{R}^n$ 上的线性变换
  - 单位立方体：由标准基张成的体积为 1 的立方体
  - $|\\det A|$：变换后体积（二维为面积）的缩放倍数；$\\det A\<0$ 表示方向翻转（含反射），$\\det A=0$
    表示空间被压扁、不可逆

特征值与特征向量：

$$ A\\mathbf{v} = \\lambda \\mathbf{v},\\qquad \\mathbf{v}\\neq
\\mathbf{0} $$

其中：

  - $A \\in \\mathbb{R}^{n\\times n}$：方阵
  - $\\mathbf{v}$：特征向量，经 $A$ 变换后方向不变（仅被拉伸/压缩）的非零向量
  - $\\lambda$：特征值，对应的缩放倍数；由 $\\det(A-\\lambda I)=0$ 求得
  - SVD 可视为对非方阵、非对称矩阵的推广：奇异值 $\\sigma\_i$ 是 $A^\\top A$ 特征值
    $\\lambda\_i$ 的平方根，即 $\\sigma\_i=\\sqrt{\\lambda\_i}$

正交矩阵与 SVD：

$$ Q^\\top Q = I,\\qquad A = U \\Sigma V^\\top $$

其中：

  - $Q$：正交矩阵，列向量两两正交且长度为 1，因此 $Q^{-1}=Q^\\top$，作为变换保持长度和夹角（旋转/反射）
  - $I$：单位矩阵
  - $A \\in \\mathbb{R}^{m\\times n}$：任意矩阵
  - $U \\in \\mathbb{R}^{m\\times m}$、$V \\in \\mathbb{R}^{n\\times
    n}$：正交矩阵，分别是左、右奇异向量组成的矩阵
  - $\\Sigma \\in \\mathbb{R}^{m\\times n}$：对角线上为非负奇异值 $\\sigma\_1 \\ge
    \\sigma\_2 \\ge \\dots \\ge 0$，其余元素为 0；非零奇异值的个数等于
    $\\operatorname{rank}(A)$

## 常见误区

  - 矩阵乘法一般不满足交换律：$AB \\neq BA$（但满足结合律
    $(AB)C=A(BC)$）；转置与逆会反转乘积顺序：$(AB)^\\top =
    B^\\top A^\\top$，$(AB)^{-1}=B^{-1}A^{-1}$。
  - 只有方阵且满秩才有逆；非方阵或奇异矩阵可用伪逆（由 SVD 得到）求最小二乘解。
  - 哈达玛乘积、克罗内克积与矩阵乘积不同，不要混用符号。
  - 范数不止 $L\_2$：$L\_1$ 倾向产生稀疏解，$L\_2$ 对应欧氏长度，选择需结合场景。

## 应用方向

  - 机器学习：特征降维（PCA 依赖 SVD/特征分解）、线性回归与最小二乘、神经网络中的矩阵运算（见
    [最小二乘](/0006_Math_LeastSquares)）
  - 计算机图形与视觉：坐标变换、旋转矩阵（正交矩阵）、四元数（见 [Quaternion](/0016_Math_Quaternion)）
  - 点云与 SLAM：用 SVD 求解两组点之间的刚体变换（见 SVD 文章中的示例）
  - 数值与优化：范数用于正则化与误差度量，雅可比矩阵用于局部线性化
