# 卡尔曼滤波

卡尔曼滤波是**线性高斯**系统的最优递归状态估计：已知系统如何演化（状态方程）以及观测带噪声（观测方程），它在每个时刻把「预测」与「新观测」按各自的可信度加权融合，得到最小均方误差的状态估计。导航、目标跟踪、传感器融合都用到它。滤波器总览见
[滤波器](https://github.com/junxnone/math/issues/104)，高斯分布见
[高斯分布进阶](https://github.com/junxnone/math/issues/5)，HMM
的连续版本见 [隐马尔可夫模型](https://github.com/junxnone/math/issues/142)。

## 概念关系图

``` mermaid
flowchart LR
    X[状态方程 x_k = F x_k-1 + 噪声] --> P[预测 先验估计与协方差]
    Z[观测方程 z_k = H x_k + 噪声] --> U[更新 融合观测]
    P --> U
    U --> P2[后验估计 作为下一步的起点]
    P2 --> P
    U --> K[卡尔曼增益 权衡预测与观测]
```

图中：每个时刻先用动力学模型做预测，再用观测更新；卡尔曼增益决定更相信预测还是观测；更新后的后验是下一步预测的起点，形成递归。

## 模型

$$
\\mathbf{x}*k=F\\mathbf{x}*{k-1}+B\\mathbf{u}\_k+\\mathbf{w}\_k,\\quad
\\mathbf{w}\_k\\sim\\mathcal{N}(0,Q);\\qquad
\\mathbf{z}\_k=H\\mathbf{x}\_k+\\mathbf{v}\_k,\\quad
\\mathbf{v}\_k\\sim\\mathcal{N}(0,R) $$

其中：

  - $\\mathbf{x}\_k$：状态（如位置、速度）；$F$：状态转移矩阵；$B,\\mathbf{u}\_k$：控制输入
  - $\\mathbf{z}\_k$：观测；$H$：观测矩阵，把状态映射到观测空间
  - $\\mathbf{w}\_k$：过程噪声（协方差 $Q$）；$\\mathbf{v}\_k$：观测噪声（协方差 $R$），二者互相独立
  - 假设线性、噪声为高斯，使得状态的后验始终保持高斯，只需要跟踪均值与协方差

## 预测与更新

**预测（时间更新）**：

$$
\\hat{\\mathbf{x}}*{k|k-1}=F\\hat{\\mathbf{x}}*{k-1|k-1}+B\\mathbf{u}*k,\\qquad
P*{k|k-1}=FP\_{k-1|k-1}F^{\\top}+Q $$

**更新（观测更新）**：

$$
K\_k=P\_{k|k-1}H^{\\top}\\bigl(HP\_{k|k-1}H^{\\top}+R\\bigr)^{-1},\\quad
\\hat{\\mathbf{x}}*{k|k}=\\hat{\\mathbf{x}}*{k|k-1}+K\_k\\bigl(\\mathbf{z}*k-H\\hat{\\mathbf{x}}*{k|k-1}\\bigr),\\quad
P\_{k|k}=(I-K\_kH)P\_{k|k-1} $$

其中：

  - $\\hat{\\mathbf{x}}*{k|k-1}$、$P*{k|k-1}$：预测（先验）的均值与协方差；$\\hat{\\mathbf{x}}*{k|k}$、$P*{k|k}$：更新（后验）
  - $\\mathbf{z}*k-H\\hat{\\mathbf{x}}*{k|k-1}$：**新息（innovation）**，观测与预测观测之差
  - $K\_k$：卡尔曼增益。$R$ 大（观测不可信）时 $K$ 小，更相信预测；$Q$ 大（模型不可信）时 $K$ 大，更相信观测

## 贝叶斯解释

卡尔曼滤波是线性高斯情形下的递归**贝叶斯滤波**：先验
$\\mathcal{N}(\\hat{\\mathbf{x}}*{k|k-1},P*{k|k-1})$ 乘以似然
$\\mathcal{N}(\\mathbf{z}\_k;H\\mathbf{x},R)$，得到仍是高斯的后验，其均值与协方差就是上面的更新公式。推导用到高斯分布的条件分布公式，见
[高斯分布进阶](https://github.com/junxnone/math/issues/5)；估计量是最小均方误差意义下最优的，也等价于递推的最小二乘，见
[最小二乘进阶](https://github.com/junxnone/math/issues/6)。

## 变体

| 方法          | 适用       | 做法                                                                             |
| ----------- | -------- | ------------------------------------------------------------------------------ |
| 扩展卡尔曼滤波 EKF | 非线性系统    | 对 $f,h$ 在当前估计处线性化（雅可比矩阵，见 [雅可比矩阵](https://github.com/junxnone/math/issues/44)） |
| 无迹卡尔曼 UKF   | 强非线性     | 用 sigma 点传播均值与协方差，不需要雅可比                                                       |
| 粒子滤波        | 非高斯、强非线性 | 用加权样本近似后验，见 [蒙特卡洛与MCMC](https://github.com/junxnone/math/issues/145)           |
| 平方根形式       | 数值稳定     | 传播协方差的 Cholesky 因子，见 [Cholesky分解](https://github.com/junxnone/math/issues/131) |

表中：对比结论：线性高斯用标准卡尔曼，轻度非线性用 EKF / UKF，严重非线性或多峰用粒子滤波。

## 在机器学习中的作用

  - 目标跟踪、SLAM 与传感器融合（IMU + GPS + 视觉）
  - 时间序列的状态空间模型（结构时间序列、动态线性模型）；与神经状态空间模型的结合
  - 强化学习与机器人控制中的状态估计，见 aiwiki 的 [RL Robot
    Control](https://github.com/junxnone/aiwiki/issues/796)

## 常见误区

  - 噪声协方差 $Q,R$ 通常**未知**，选取不当会使滤波过度自信或迟钝（滤波发散），需要整定或自适应估计
  - 标准卡尔曼要求线性与高斯；对非线性系统直接套用会产生偏差
  - 协方差更新要保持对称正定；数值上用 Joseph 形式或平方根形式，否则可能因舍入失去正定性
