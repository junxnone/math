# 线性相关和线性无关

## 线性相关

  - **定义**：设 $\\alpha\_{1},\\alpha\_{2},\\cdots,\\alpha\_{n}$
    是一组向量，如果存在不全为零的数
    $k\_{1},k\_{2},\\cdots,k\_{n}$ ，使得
    $k\_{1}\\alpha\_{1}+k\_{2}\\alpha\_{2}+\\cdots
    +k\_{n}\\alpha\_{n}=0$ ，则称向量组
    $\\alpha\_{1},\\alpha\_{2},\\cdots,\\alpha\_{n}$ 线性相关。
  - **几何意义（以二维或三维向量为例）**：在二维平面中，如果两个向量线性相关，那么它们是共线的；在三维空间中，如果三个向量线性相关，那么它们是共面的。例如，对于向量
    $\\alpha\_{1}=(1,2)$ 和 $\\alpha\_{2}=(2,4)$ ，存在 $k\_{1} =
    2,k\_{2}=-1$ ，使得 $2\\alpha\_{1}-\\alpha\_{2}=2(1,2)-(2,4)=(0,0)$ ，所以
    $\\alpha\_{1}$ 和 $\\alpha\_{2}$ 线性相关，在几何上它们是共线的。
  - **性质和应用场景**：在线性方程组中，如果系数矩阵的列向量组线性相关，那么方程组有非零解。在向量空间的研究中，线性相关的向量组可以通过其中部分向量来表示其他向量，这有助于简化向量空间的结构分析。

## 线性无关

  - **定义**：如果向量组 $\\alpha\_{1},\\alpha\_{2},\\cdots,\\alpha\_{n}$ 满足当且仅当
    $k\_{1}=k\_{2}=\\cdots =k\_{n}=0$ 时，
    $k\_{1}\\alpha\_{1}+k\_{2}\\alpha\_{2}+\\cdots
    +k\_{n}\\alpha\_{n}=0$ 才成立，那么称向量组
    $\\alpha\_{1},\\alpha\_{2},\\cdots,\\alpha\_{n}$ 线性无关。
  - **几何意义（以二维或三维向量为例）**：在二维平面中，两个不共线的向量就是线性无关的；在三维空间中，三个不共面的向量是线性无关的。例如，向量
    $\\beta\_{1}=(1,0)$ 和 $\\beta\_{2}=(0,1)$ 是线性无关的，因为只有当
    $k\_{1}=k\_{2}=0$ 时，
    $k\_{1}\\beta\_{1}+k\_{2}\\beta\_{2}=k\_{1}(1,0)+k\_{2}(0,1)=(k\_{1},k\_{2})=(0,0)$
    才成立，在几何上它们分别是 $x$ 轴和 $y$ 轴正方向上的单位向量，不共线。
  - **性质和应用场景**：线性无关的向量组可以作为向量空间的一组基，通过这组基可以表示向量空间中的任意向量。在机器学习中的特征选择等方面，如果特征向量是线性无关的，那么这些特征可以提供更独立的信息，有助于提高模型的性能。在求解线性变换的特征向量时，也需要判断向量组的线性无关性，以确定特征子空间的维数等。

## 判定方法

把向量组按列排成矩阵 $A=\[\\alpha\_1\\ \\alpha\_2\\ \\cdots\\
\\alpha\_n\]$，则「线性相关」等价于齐次方程 $A\\mathbf{k}=0$ 有非零解
$\\mathbf{k}=(k\_1,\\dots,k\_n)^\\top$：

| 方法                 | 线性无关的条件                          | 说明                                                           |
| ------------------ | -------------------------------- | ------------------------------------------------------------ |
| 秩                  | $\\operatorname{rank}(A)=n$（列满秩） | 向量个数等于秩，见 [矩阵的秩](https://github.com/junxnone/math/issues/29) |
| 行列式（$n$ 个 $n$ 维向量） | $\\det A\\ne0$                   | 方阵才能用，见 [行列式](https://github.com/junxnone/math/issues/3)     |
| 格拉姆矩阵              | $G=A^\\top A$ 可逆（$\\det G\\ne0$） | 对任意形状的 $A$ 都适用                                               |
| 初等变换               | 化为行阶梯形后没有自由变量                    | 手算常用，见 [初等变换](https://github.com/junxnone/math/issues/38)    |

表中：

  - $n$ 为向量个数；$G=A^{\\top}A$ 的元素 $G\_{ij}=\\alpha\_i\\cdot\\alpha\_j$
    称为格拉姆矩阵（Gram 矩阵）
  - 对比结论：判断方阵用行列式，一般情形用秩或行阶梯形

## 常用结论

  - 含有**零向量**的向量组一定线性相关
  - 单个向量 $\\alpha$ 线性无关当且仅当 $\\alpha\\ne0$；两个向量线性相关当且仅当它们**成比例**（共线）
  - 在 $\\mathbb{R}^{m}$ 中，**多于 $m$ 个**向量一定线性相关（方程个数少于未知数个数）
  - 线性无关向量组的任何部分组也线性无关；线性相关向量组再添加向量仍线性相关
  - 若向量组线性相关，则其中至少有一个向量可以由其余向量线性表示

$$ \\alpha\_j=-\\frac{1}{k\_j}\\sum\_{i\\ne
j}k\_i\\alpha\_i\\quad(k\_j\\ne0) $$

其中：$k\_i$ 为使线性组合为零的系数，且 $k\_j\\ne0$；这说明向量 $\\alpha\_j$ 是冗余的，可以被其余向量表示出来。

## 与基、维数的联系

  - **基**：向量空间中一组线性无关且能够张成整个空间的向量，见
    [向量空间](https://github.com/junxnone/math/issues/34)
  - **维数**：基中向量的个数；空间的任何基含有的向量个数相同
  - 一个向量组中**最大线性无关组**所含向量的个数就是该向量组的秩
  - 线性无关给出**唯一表示**：用一组基表示任意向量，系数是唯一的

## 在机器学习中的作用

  - 共线性：特征之间线性相关（或近似相关）会使 $X^\\top X$ 奇异或病态，线性回归的参数估计不稳定，见
    [最小二乘进阶](https://github.com/junxnone/math/issues/6)
  - 降维：PCA 去掉线性相关（冗余）的方向，保留独立的主成分，见
    [PCA](https://github.com/junxnone/math/issues/46)
  - 神经网络：权重矩阵的秩亏意味着某些方向的信息被丢弃，低秩结构是参数高效微调（LoRA）的前提

## 常见误区

  - 线性相关是对**整个向量组**而言的，不是对某一对向量；三个向量两两不共线，仍可能整体线性相关（共面）
  - 「线性无关」不等于「正交」：正交（非零）向量一定线性无关，反之不成立
  - 线性相关与「相关系数」不同：后者是随机变量之间的统计量，见
    [多维随机变量与协方差](https://github.com/junxnone/math/issues/65)
