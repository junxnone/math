# 泊松过程

泊松过程是描述**随机事件按时间发生**的基本模型：顾客到达、系统故障、网络分组、放射性衰变。它是计数过程、独立增量过程和马尔可夫过程的典型。总览见
[随机过程初步](https://github.com/junxnone/math/issues/67)，更一般的理论见
[随机过程进阶](https://github.com/junxnone/math/issues/13)，指数分布见
[常见分布](https://github.com/junxnone/math/issues/63)。

## 概念关系图

``` mermaid
flowchart LR
    P[泊松过程 N t] --> C[计数 N t 服从泊松分布]
    P --> I[到达间隔 独立同分布 指数分布]
    P --> S[性质 独立平稳增量 无记忆]
    P --> M[叠加与稀释 仍是泊松过程]
    P --> E[推广 非齐次 复合泊松]
```

图中：泊松过程同时有两种等价描述——「区间内的计数服从泊松分布」与「到达间隔服从指数分布」；它具有独立平稳增量与无记忆性；叠加、稀释后仍是泊松过程；可推广为非齐次与复合形式。

## 定义

计数过程 ${N(t),t\\ge0}$（$N(t)$ 为 $\[0,t\]$ 内的事件数）是速率为 $\\lambda$
的**齐次泊松过程**，若：

$$ N(0)=0,\\qquad
N(t)-N(s)\\sim\\mathrm{Pois}\\bigl(\\lambda(t-s)\\bigr),\\ \\
\\text{且不相交区间上的增量相互独立} $$

其中：$\\lambda\>0$ 为事件发生的**速率**（单位时间的平均事件数）；增量的分布只依赖区间长度（平稳增量）。于是：

$$ P\\bigl(N(t)=k\\bigr)=\\frac{(\\lambda t)^{k}e^{-\\lambda
t}}{k\!},\\qquad
\\mathbb{E}\[N(t)\]=\\operatorname{Var}\[N(t)\]=\\lambda t $$

其中：均值与方差都等于 $\\lambda t$，是泊松分布的标志。

## 等价刻画：到达间隔

设第 $n$ 个事件的发生时刻为 $S\_n$，间隔 $T\_n=S\_n-S\_{n-1}$，则

$$ T\_n\\overset{\\text{i.i.d.}}{\\sim}\\mathrm{Exp}(\\lambda),\\qquad
S\_n\\sim\\mathrm{Gamma}(n,\\lambda) $$

其中：指数分布密度为 $\\lambda e^{-\\lambda t}$，均值 $1/\\lambda$；到第 $n$ 个事件的等待时间是
$n$ 个指数变量之和，服从 Gamma（Erlang）分布。指数分布的**无记忆性** $P(T\>s+t\\mid
T\>s)=P(T\>t)$ 使得过程在任意时刻重新开始。

## 重要性质

| 性质     | 内容                                                                         |
| ------ | -------------------------------------------------------------------------- |
| 叠加     | 独立泊松过程（速率 $\\lambda\_1,\\lambda\_2$）之和仍是泊松过程，速率 $\\lambda\_1+\\lambda\_2$  |
| 稀释（分解） | 每个事件以概率 $p$ 独立标记，被标记的事件构成速率为 $p\\lambda$ 的泊松过程                             |
| 条件均匀性  | 已知 $\[0,t\]$ 内有 $n$ 个事件，它们的发生时刻是 $n$ 个独立均匀分布变量的顺序统计量                       |
| 马尔可夫性  | 是连续时间马尔可夫链，只向上跳 1，见 [马尔可夫过程进阶](https://github.com/junxnone/math/issues/18) |

表中：对比结论：这些性质使泊松过程极易分析，是排队论的出发点。

## 推广

  - **非齐次泊松过程**：速率随时间变化
    $\\lambda(t)$，$N(t)-N(s)\\sim\\mathrm{Pois}\\bigl(\\int\_s^t\\lambda(u),du\\bigr)$
  - **复合泊松过程**：$X(t)=\\sum\_{i=1}^{N(t)}Y\_i$，每次事件带随机大小
    $Y\_i$（如保险理赔额）；均值 $\\lambda
    t,\\mathbb{E}\[Y\]$，方差 $\\lambda t,\\mathbb{E}\[Y^2\]$
  - **Cox 过程 / Hawkes 过程**：速率本身随机或受历史事件激励（事件有「自激」效应）

## 在机器学习中的作用

  - 事件序列建模：时序点过程（Hawkes、神经点过程）用于用户行为、金融事件预测
  - 排队与负载模型：请求到达（M/M/1 队列）、系统容量规划
  - 计数数据的泊松回归（广义线性模型），见
    [指数族分布](https://github.com/junxnone/math/issues/138)

## 常见误区

  - 泊松过程要求事件**独立、不会同时发生**；有「成团」到达的现象需用其他模型
  - 速率不是概率：$\\lambda$ 可以大于 1；在极短时间 $dt$ 内发生一次事件的概率约为 $\\lambda,dt$
  - 无记忆性是指数分布的特点，不能推广到一般等待时间分布（如固定间隔、Weibull）
