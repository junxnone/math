# 采样定理

采样把连续信号变成离散序列。奈奎斯特-香农采样定理回答关键问题：采样率要多高，才不会丢失信息？答案是：高于信号最高频率的两倍。

## 理想采样

以周期 $T\_s$（采样率 $f\_s=1/T\_s$，$\\omega\_s=2\\pi f\_s$）对 $x(t)$
采样，等价于乘以冲激串：

$$
x\_s(t)=x(t)\\sum\_{n=-\\infty}^{\\infty}\\delta(t-nT\_s)=\\sum\_nx(nT\_s),\\delta(t-nT\_s)
$$

其中 $x(nT\_s)=x\[n\]$ 是采样值，$\\delta$ 是冲激（见
[信号与线性系统](/0099_信号与傅里叶变换_信号与线性系统)）。

## 频谱的周期延拓

冲激串的傅里叶变换仍是冲激串，时域相乘对应频域卷积（见
[连续傅里叶变换](/0101_信号与傅里叶变换_连续傅里叶变换)、[卷积](/0100_信号与傅里叶变换_卷积)）：

$$
X\_s(\\omega)=\\frac1{T\_s}\\sum\_{k=-\\infty}^{\\infty}X(\\omega-k\\omega\_s)
$$

其中 $X(\\omega)$ 是原信号频谱，$X\_s(\\omega)$ 是采样后的频谱。含义：**采样使频谱每隔 $\\omega\_s$
复制一份**。

设信号带限：$X(\\omega)=0$，$|\\omega|\>\\omega\_m$（最高频率
$f\_m=\\omega\_m/2\\pi$）。

``` mermaid
flowchart LR
    A["原频谱：[−ωm, ωm]"] --> B["采样：复制到 k·ωs"]
    B --> C{"ωs > 2ωm ？"}
    C -- 是 --> D["各副本不重叠，可用低通滤波恢复"]
    C -- 否 --> E["副本重叠：混叠，信息丢失"]
```

图中：

  - 从左到右是采样对频谱的影响：原频谱被周期性复制，复制间隔是 $\\omega\_s$。
  - 判断菱形比较复制间隔与频谱宽度：当 $\\omega\_s\>2\\omega\_m$
    时副本互不重叠，用理想低通滤波器截取基带即可无失真恢复；否则副本相互叠加，高频成分被“折叠”到低频，这就是混叠（aliasing）。

## 奈奎斯特-香农采样定理

$$ f\_s\>2f\_m,\\qquad
x(t)=\\sum\_{n=-\\infty}^{\\infty}x\[n\],\\mathrm{sinc}\\Bigl(\\frac{t-nT\_s}{T\_s}\\Bigr),\\qquad
\\mathrm{sinc}(u)=\\frac{\\sin\\pi u}{\\pi u} $$

其中：

  - $f\_m$：信号最高频率（带宽）；$2f\_m$ 称为**奈奎斯特速率**，$f\_s/2$ 是**奈奎斯特频率**
  - 第二式是**重建公式**（Whittaker-Shannon 插值）：每个样本乘以一个 sinc 核再叠加，sinc
    是理想低通滤波器的冲激响应（因为矩形频谱的逆变换是 sinc，见
    [连续傅里叶变换](/0101_信号与傅里叶变换_连续傅里叶变换)）
  - 结论：带限信号被其样本**完全**确定，无需额外假设
  - 实际中理想低通不可实现，需要略高于 $2f\_m$ 的采样率并配合实际滤波器（过采样）

## 混叠

当 $f\_s\<2f\_m$ 时，频率 $f$ 的成分被折叠成表观频率：

$$ f\_{\\text{alias}}=\\bigl|f-m f\_s\\bigr|\\quad\\text{（取 $m$ 使结果落在
}\[0,f\_s/2\]\\text{ 内）} $$

其中 $m$ 是整数，$f\_s$ 是采样率。例：$5$ kHz 正弦以 $f\_s=8$ kHz 采样（奈奎斯特频率 $4$
kHz）：$|5-8|=3$ kHz，采样得到的序列与 $3$ kHz 正弦完全相同，无法区分。

| 现象               | 原因          |
| ---------------- | ----------- |
| 车轮在视频中倒转（“车轮效应”） | 帧率相对旋转频率不足  |
| 图像摩尔纹、锯齿         | 空间采样不足      |
| 音频里出现尖锐的“假音”     | 高频未滤除就降采样   |
| 神经网络下采样导致的平移不稳定  | 步长卷积/池化引起混叠 |

表中左列是现象，右列是原因：都是信号含有高于 $f\_s/2$ 的成分。**对策**：采样前加**抗混叠滤波器**（低通滤波，截止频率
$\\le f\_s/2$，见 [滤波器](/0104_信号与傅里叶变换_滤波器)），降采样前同样要先低通。

## 实用参数

| 应用      | 带宽                | 采样率                 |
| ------- | ----------------- | ------------------- |
| 电话语音    | $\\approx3.4$ kHz | $8$ kHz             |
| CD 音频   | $20$ kHz（人耳）      | $44.1$ kHz          |
| 专业音频/视频 | 20 kHz            | $48$ kHz / $96$ kHz |
| 图像      | 光学传递函数截止          | 像素间距 $\\le$ 最小细节的一半 |

表中依次为应用、信号带宽和采样率；CD 的 $44.1$ kHz 略高于 $2\\times20=40$ kHz，给抗混叠滤波器留出过渡带。

## 量化

采样之后还要把幅度离散化为 $b$ 位整数（量化）。量化误差近似均匀分布于一个量化间隔，均方误差 $\\Delta^2/12$（见
[常见分布](/0063_概率论_常见分布)），信号量化噪声比：

$$ \\mathrm{SQNR}\\approx6.02,b+1.76\\ \\text{dB} $$

其中 $b$ 是比特数（满幅正弦输入）。每多 $1$ 位约增加 $6$ dB：$16$ 位音频约 $98$ dB 动态范围。

## 与信息论的联系

带宽 $B$ 的信号每秒有 $2B$ 个独立样本，因此信道容量 $C=B\\log\_2(1+\\mathrm{SNR})$ 中“每个样本
$\\tfrac12\\log\_2(1+\\mathrm{SNR})$”乘以 $2B$（见
[信道容量](/0089_信息论_信道容量)）；采样定理给出自由度数，香农公式给出每个自由度承载的信息量。

## 压缩感知（简介）

奈奎斯特速率针对一般带限信号。若信号在某个基下**稀疏**，则远低于奈奎斯特速率的随机测量也可以通过 $L\_1$
最小化精确重建：$\\min\\lVert\\mathbf{s}\\rVert\_1$ s.t.
$\\Phi\\Psi\\mathbf{s}=\\mathbf{y}$，其中 $\\Phi$ 是测量矩阵，$\\Psi$
是稀疏基，$\\mathbf{s}$ 是稀疏系数（见
[norm](/0011_线性代数_norm)、[线性规划](/0080_优化理论_线性规划)）。应用于
MRI 加速、单像素相机。

## 应用

  - 数字音频/视频/通信系统的采样率设计
  - 模数转换器（ADC）选型、过采样与 $\\Sigma\\Delta$ 调制
  - 图像缩放与降采样（先滤波后抽取）
  - 传感器数据采集、振动分析

## 在机器学习中的作用

  - 图像与音频的采样率、下采样与抗混叠：缩放图像前要先低通滤波，否则产生摩尔纹
  - 卷积网络中的步幅（stride）与池化相当于下采样，会引入混叠，影响平移不变性
  - 压缩感知：利用稀疏性在低于奈奎斯特速率下恢复信号

## 常见误区

  - 采样率必须**大于**信号最高频率的 2 倍（不是等于），并且采样前要先抗混叠低通滤波
  - 采样定理的恢复要用理想低通（sinc 插值）；实际的保持器与滤波器只能近似
  - 混叠一旦发生**不可逆**：采样后高频成分与低频成分混在一起，无法区分
