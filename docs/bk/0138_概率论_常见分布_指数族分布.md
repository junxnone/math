# 指数族分布

指数族是一大类分布的统一形式：高斯、伯努利、二项、泊松、指数、Gamma、Beta、Dirichlet
等都属于它。统一的形式带来统一的结论：**充分统计量、共轭先验、最大似然、对数配分函数的导数**。常见分布见
[常见分布](https://github.com/junxnone/math/issues/63)，最大熵推导见
[最大熵原理](https://github.com/junxnone/math/issues/90)。

## 概念关系图

``` mermaid
flowchart LR
    E[指数族 p x given eta] --> S[充分统计量 T x]
    E --> A[对数配分函数 A eta 矩与方差]
    E --> M[最大似然 矩匹配]
    E --> C[共轭先验 后验仍是同族]
    E --> X[最大熵推导 约束下最大熵]
    E --> G[广义线性模型 逻辑回归 泊松回归]
```

图中：指数族由自然参数 $\\eta$ 与充分统计量 $T(x)$
定义；对数配分函数的导数给出期望与方差；最大似然等价于矩匹配；它同时拥有共轭先验，并可由最大熵原理推导，进而推广出广义线性模型。

## 标准形式

$$
p(x\\mid\\boldsymbol\\eta)=h(x)\\exp\\bigl(\\boldsymbol\\eta^{\\top}T(x)-A(\\boldsymbol\\eta)\\bigr)
$$

其中：

  - $\\boldsymbol\\eta$：自然参数；$T(x)$：充分统计量；$h(x)$：基测度（与参数无关）
  - $A(\\boldsymbol\\eta)=\\ln\\int h(x)\\exp(\\boldsymbol\\eta^\\top
    T(x)),dx$：**对数配分函数**，保证归一化
  - 「充分」指样本中关于参数的全部信息都包含在 $T(x)$ 中

## 常见分布的对应

| 分布                                | $T(x)$         | 自然参数 $\\eta$                                                            |
| --------------------------------- | -------------- | ----------------------------------------------------------------------- |
| 伯努利 $\\mathrm{Bern}(p)$           | $x$            | $\\ln\\dfrac{p}{1-p}$（对数几率）                                             |
| 高斯 $\\mathcal{N}(\\mu,\\sigma^2)$ | $(x,\\ x^{2})$ | $\\bigl(\\dfrac{\\mu}{\\sigma^{2}},\\ -\\dfrac{1}{2\\sigma^{2}}\\bigr)$ |
| 泊松 $\\mathrm{Pois}(\\lambda)$     | $x$            | $\\ln\\lambda$                                                          |
| 类别分布                              | one-hot        | $\\ln p\_k$（softmax 的来源）                                                |

表中：对比结论：伯努利的自然参数是对数几率，所以 sigmoid 是它的逆链接函数；类别分布对应 softmax，见
[常见分布](https://github.com/junxnone/math/issues/63)。

## 对数配分函数的性质

$$
\\nabla\_{\\boldsymbol\\eta}A(\\boldsymbol\\eta)=\\mathbb{E}\[T(x)\],\\qquad
\\nabla^{2}\_{\\boldsymbol\\eta}A(\\boldsymbol\\eta)=\\operatorname{Cov}\[T(x)\]
$$

其中：一阶导数是充分统计量的期望，二阶导数是其协方差（半正定），所以 $A(\\boldsymbol\\eta)$ 是**凸函数**，见
[凸集与凸函数](https://github.com/junxnone/math/issues/77)。这使指数族的参数估计成为凸优化问题。

## 最大似然

对独立样本 $x\_1,\\dots,x\_n$，对数似然为
$\\boldsymbol\\eta^\\top\\sum\_iT(x\_i)-nA(\\boldsymbol\\eta)$。令梯度为零：

$$
\\mathbb{E}*{\\hat{\\boldsymbol\\eta}}\[T(x)\]=\\frac{1}{n}\\sum*{i=1}^{n}T(x\_i)
$$

其中：最大似然估计等价于**矩匹配**：模型的期望充分统计量等于样本的经验平均。见
[点估计](https://github.com/junxnone/math/issues/70)。

## 共轭先验

对似然 $p(x\\mid\\boldsymbol\\eta)$，取先验
$p(\\boldsymbol\\eta\\mid\\boldsymbol\\chi,\\nu)\\propto\\exp(\\boldsymbol\\eta^\\top\\boldsymbol\\chi-\\nu
A(\\boldsymbol\\eta))$，后验仍是同一族，超参数更新为 $(\\boldsymbol\\chi+\\sum
T(x\_i),\\ \\nu+n)$：

| 似然       | 共轭先验      |
| -------- | --------- |
| 伯努利 / 二项 | Beta      |
| 类别 / 多项  | Dirichlet |
| 泊松       | Gamma     |
| 高斯（均值）   | 高斯        |

表中：对比结论：共轭使后验更新成为「把统计量加起来」，见
[贝叶斯推断进阶](https://github.com/junxnone/math/issues/8)、[贝叶斯统计](https://github.com/junxnone/math/issues/74)。

## 在机器学习中的作用

  - 广义线性模型（GLM）：把响应变量设为指数族，用链接函数连接线性预测，逻辑回归、泊松回归、线性回归都是特例
  - 变分推断与图模型中的指数族近似、自然梯度，见
    [变分推断](https://github.com/junxnone/math/issues/146)
  - softmax 分类、对数配分函数的计算（归一化常数）

## 常见误区

  - 不是所有分布都属于指数族（如均匀分布、柯西分布、$t$ 分布的支撑 / 形式不满足）
  - 自然参数与常用参数不同：例如高斯的自然参数是 $(\\mu/\\sigma^2,-1/2\\sigma^2)$，不是
    $(\\mu,\\sigma^2)$
  - 对数配分函数 $A(\\boldsymbol\\eta)$ 往往难以计算（如图模型中），这是许多推断问题困难的根源
