# 短时傅里叶与小波

傅里叶变换给出信号包含哪些频率，却不说这些频率何时出现。对于语音、音乐、心电这类频率随时间变化的非平稳信号，需要同时刻画时间和频率：短时傅里叶变换（STFT）和小波变换是两种主要方法。

## 傅里叶变换的局限

$X(\\omega)=\\int x(t)e^{-j\\omega t}dt$
对整个时间轴积分：两段信号“先低频后高频”与“先高频后低频”的幅度谱完全相同，区别只藏在相位里（见
[连续傅里叶变换](/0101_信号与傅里叶变换_连续傅里叶变换)）。要定位事件发生的时间，必须局部化。

## 短时傅里叶变换（STFT）

$$
\\mathrm{STFT}{x}(\\tau,\\omega)=\\int\_{-\\infty}^{+\\infty}x(t),w(t-\\tau),e^{-j\\omega
t},dt $$

其中：

  - $w(t)$：窗函数（如高斯、Hann），只在 $t=0$ 附近非零；$\\tau$：窗的中心位置
  - 含义：用窗口截取 $\\tau$ 附近的一小段信号，再对它做傅里叶变换，窗口沿时间滑动得到时间-频率二维表示
  - 高斯窗时称 Gabor 变换，在不确定性原理下时频局部化最优

**频谱图**（spectrogram）：$|\\mathrm{STFT}(\\tau,\\omega)|^2$，横轴时间、纵轴频率、颜色表示能量，是分析语音/音乐/振动的标准图。离散实现：把信号分成长度
$N$、跳步 $H$ 的重叠帧，每帧乘窗做 FFT（见 [离散傅里叶变换与
FFT](/0102_信号与傅里叶变换_离散傅里叶变换与FFT)）。语音识别中常再取梅尔刻度并取对数得到
log-mel 谱。

## 时频分辨率的权衡

窗越长，频率分辨率越高（$\\Delta f\\sim1/T\_w$）但时间定位越模糊；窗越短则相反。这是不确定性原理的体现（见
[连续傅里叶变换](/0101_信号与傅里叶变换_连续傅里叶变换)）：

$$ \\Delta t\\cdot\\Delta\\omega\\ge\\frac12 $$

其中 $\\Delta t,\\Delta\\omega$ 是窗函数在时间和频率上的扩展；时频平面上每个分析“原子”的面积至少为常数
$1/2$。STFT 的窗固定，因此所有频率的时间/频率分辨率相同——时频平面被划分成等大的矩形格子。

## 小波变换

$$
W(a,b)=\\frac1{\\sqrt{a}}\\int\_{-\\infty}^{+\\infty}x(t),\\psi^\*\\Bigl(\\frac{t-b}a\\Bigr)dt
$$

其中：

  - $\\psi(t)$：母小波，一个有限长、均值为零的振荡函数（要求容许条件 $\\int\\psi=0$）；$\\psi^\*$ 是共轭
  - $a\>0$：尺度（伸缩）参数，大 $a$ 对应拉宽的小波（低频），小 $a$
    对应压缩的小波（高频）；$b$：平移参数，决定在时间轴上的位置
  - $\\frac1{\\sqrt a}$：保持能量的归一化因子
  - 含义：用一组由母小波伸缩平移得到的“探针”扫描信号，$W(a,b)$ 是信号与探针的相似度

与 STFT
的关键区别：小波的“窗”随尺度自动变化——**高频处时间分辨率高（窗窄）、低频处频率分辨率高（窗宽）**。更适合“低频缓变、高频短促”的信号（如瞬态冲击、边缘）。

| 变换   | 基函数              | 时间分辨率 | 频率分辨率 | 适合       |
| ---- | ---------------- | ----- | ----- | -------- |
| 傅里叶  | $e^{j\\omega t}$ | 无     | 最高    | 平稳信号     |
| STFT | 加窗复指数            | 固定    | 固定    | 语音、音乐    |
| 小波   | 伸缩平移的 $\\psi$    | 高频高   | 低频高   | 瞬态、多尺度信号 |

表中依次为变换、基函数、时间/频率分辨率和适用信号。

常用母小波：

  - **Haar**：$\\psi(t)=\\begin{cases}1&0\\le
    t\<\\tfrac12\\-1&\\tfrac12\\le
    t\<1\\0&\\text{其他}\\end{cases}$，最简单，不连续。
  - **Daubechies（db$N$）**：紧支撑、正交，消失矩为 $N$（可抑制 $N-1$ 次多项式趋势）。
  - **Morlet**：高斯包络的复指数 $e^{j\\omega\_0t}e^{-t^2/2}$，常用于连续小波分析。
  - **Mexican hat**：高斯函数的二阶导数的负值。

## 离散小波变换与多分辨率分析

取 $a=2^j,\\ b=k2^j$，用一对滤波器（低通 $h$、高通 $g$）和下采样做多级分解（Mallat 算法）：

$$ a\_{j+1}\[k\]=\\sum\_nh\[n-2k\],a\_j\[n\],\\qquad
d\_{j+1}\[k\]=\\sum\_ng\[n-2k\],a\_j\[n\] $$

其中：

  - $a\_j$：第 $j$ 级的近似（低频）系数，$a\_0$ 是原信号；$d\_j$：细节（高频）系数
  - $h$：低通分解滤波器，$g$：高通分解滤波器；$n-2k$ 表示卷积后再取偶数项（下采样 $\\downarrow2$）
  - 每一级把近似部分继续分解，信号被拆成 $d\_1,d\_2,\\dots,d\_J,a\_J$ 多个频带，系数总个数与原信号相同

``` mermaid
flowchart LR
    X["x = a0"] --> L1["低通 h ↓2"] --> A1["a1"] --> L2["低通 ↓2"] --> A2["a2"]
    X --> H1["高通 g ↓2"] --> D1["d1：高频细节"]
    A1 --> H2["高通 ↓2"] --> D2["d2：中频细节"]
```

图中：

  - 自左向右是两级分解：每级把信号同时送入低通和高通滤波器并下采样（↓2），低通分支得到粗略的近似 $a\_j$，高通分支得到细节
    $d\_j$。
  - 近似继续被分解，所以频带按
    $\[0,\\pi/2^J\],\\dots,\[\\pi/4,\\pi/2\],\[\\pi/2,\\pi\]$
    呈倍频程划分：低频分辨率细，高频分辨率粗。
  - 重构用对应的合成滤波器和上采样，完美重构（见 [滤波器](/0104_信号与傅里叶变换_滤波器) 的 FIR 设计）。

## 例：Haar 分解

信号 $x=\[4,6,10,12\]$：近似（相邻平均，已缩放前）$(5,11)$，细节（相邻半差）$(-1,-1)$；在正交归一的 Haar
小波下
$a\_1=\\bigl(\\tfrac{4+6}{\\sqrt2},\\tfrac{10+12}{\\sqrt2}\\bigr)$，$d\_1=\\bigl(\\tfrac{4-6}{\\sqrt2},\\tfrac{10-12}{\\sqrt2}\\bigr)$。细节系数小说明信号平滑，可以被舍弃——这是压缩的基础。

## 应用

  - **压缩**：JPEG 2000、指纹压缩标准（FBI WSQ）
  - **去噪**：对小波系数做软阈值 $\\mathrm{sign}(d)\\max(|d|-\\lambda,0)$
    去除小的（噪声）系数，再重构（与 Lasso 的软阈值同源，见
    [一阶方法与随机梯度](/0081_优化理论_一阶方法与随机梯度)）
  - **特征提取**：语音/音乐的 log-mel 谱、EEG/ECG 时频特征、机械故障诊断
  - **边缘与奇异性检测**、地震与金融时间序列分析
  - 深度学习：小波散射网络、频谱图作为卷积网络的输入

## 变换对比

| 变换    | 时间分辨 | 频率分辨 | 特点                     |
| ----- | ---- | ---- | ---------------------- |
| 傅里叶变换 | 无    | 极好   | 只知有哪些频率，不知何时出现         |
| STFT  | 固定窗长 | 固定   | 时间与频率分辨率由窗长折中，两者不能同时最优 |
| 小波变换  | 高频好  | 低频好  | 多分辨率，窗宽随频率自适应          |

表中：对比结论：非平稳信号（语音、心电）需要时频分析，选择 STFT 简单直观，选择小波对瞬态与多尺度特征更友好。

## 在机器学习中的作用

  - 语音识别中的对数梅尔谱图就是 STFT 的结果，作为神经网络输入
  - 小波散射网络、多尺度特征；图像压缩（JPEG 2000 使用小波）
  - 时间序列的多分辨率分解与去噪

## 常见误区

  - 时间分辨率与频率分辨率受**不确定性原理**限制，不可能同时任意好，见
    [连续傅里叶变换](https://github.com/junxnone/math/issues/101)
  - 小波不是单一变换：基函数的选择（Haar、Daubechies 等）影响结果，要与信号特征匹配
  - STFT 的窗函数、窗长、重叠率都会影响频谱图，不同设置结果不同
