# 微积分

微积分研究“变化”与“累积”：**微分**描述一个量在某点附近变化得多快，**积分**描述变化累积起来的总量，二者通过微积分基本定理联系在一起。它是物理、优化、概率统计和机器学习（梯度下降、反向传播）的基础语言。

## 核心思想

  - **极限**：用“无限逼近”精确地定义瞬时变化和无穷累加，是整座大厦的地基。
  - **微分**（局部线性化）：光滑函数在一点附近可以用线性函数近似，这与线性代数的联系见
    [雅可比矩阵](/0044_线性代数_Matrix_雅可比矩阵)。
  - **积分**（累积求和）：把无穷多个无穷小量相加，得到面积、体积、总量。
  - **基本定理**：微分与积分互为逆运算。

微积分基本定理：

$$ \\int\_a^b f'(x),dx=f(b)-f(a) $$

其中：

  - $f$：区间 $\[a,b\]$ 上连续可导的函数；$f'(x)$：$f$ 在 $x$ 处的导数（瞬时变化率）
  - $\\int\_a^b\\cdots dx$：从 $a$ 到 $b$ 的定积分，即把所有“微小变化 $f'(x)dx$”累加
  - 含义：总变化量等于各处瞬时变化的累积，只需知道端点的值，不用逐点相加
  - 后续各种高维定理（格林、斯托克斯、高斯）都是它的推广

## 关键概念速览

导数的定义：

$$ f'(x\_0)=\\lim\_{\\Delta x\\to0}\\frac{f(x\_0+\\Delta
x)-f(x\_0)}{\\Delta x} $$

其中：

  - $x\_0$：考察点；$\\Delta x$：自变量的微小增量
  - 分子是函数值的增量，分子除以分母是平均变化率，取极限后得到瞬时变化率，即切线斜率

泰勒展开（一元）：

$$ f(x)=\\sum\_{k=0}^{n}\\frac{f^{(k)}(a)}{k\!}(x-a)^k+R\_n(x) $$

其中 $f^{(k)}(a)$ 是 $f$ 在 $a$ 处的 $k$ 阶导数，$k\!$ 是阶乘，$R\_n(x)$ 是余项（误差）。多项式在
$a$ 附近逼近函数，阶数越高越准。

梯度与多元链式法则（见 [多元函数微分](/0054_微积分_多元函数微分)）：

$$ \\nabla f=\\Bigl(\\frac{\\partial f}{\\partial
x\_1},\\dots,\\frac{\\partial f}{\\partial x\_n}\\Bigr)^\\top $$

其中 $f:\\mathbb{R}^n\\to\\mathbb{R}$ 是标量函数，$\\partial f/\\partial x\_i$
是对第 $i$ 个变量的偏导数；梯度指向函数上升最快的方向，模长就是最大方向导数。

## 与线性代数的对应

| 微积分概念                                     | 线性代数对应                      | 说明                                                  |
| ----------------------------------------- | --------------------------- | --------------------------------------------------- |
| 一元导数 $f'(x)$                              | 雅可比矩阵 $J$                   | 局部线性近似的斜率 → 矩阵（见 [雅可比矩阵](/0044_线性代数_Matrix_雅可比矩阵)）  |
| 二阶导数 $f''$                                | Hessian 矩阵 $H$              | 曲率；正定对应极小（见 [对称正定与二次型](/0041_线性代数_Matrix_对称正定与二次型)） |
| 泰勒展开                                      | 多项式逼近 / 二次型                 | 一阶线性、二阶二次型                                          |
| 定积分换元                                     | 行列式 $\\lvert\\det J\\rvert$ | 体积缩放因子（见 [重积分](/0055_微积分_重积分)）                      |
| 傅里叶级数                                     | 正交基展开                       | 三角函数系是函数空间的标准正交基                                    |
| 线性微分方程组 $\\dot{\\mathbf{x}}=A\\mathbf{x}$ | 特征值 / 矩阵指数                  | 稳定性由特征值实部决定（见 [特征值与特征向量](/0036_线性代数_特征值与特征向量)）      |
| 最小二乘极值                                    | 投影 / 正规方程                   | 令梯度为零 → 求解线性方程组（见 [投影](/0042_线性代数_投影)）              |

表中依次为微积分概念、对应的线性代数概念和说明，可以看出微积分负责“局部线性化”，线性代数负责“处理线性化之后的问题”。

## 常用符号

| 符号                        | 含义            |
| ------------------------- | ------------- |
| $\\lim$                   | 极限            |
| $f'$、$\\dfrac{df}{dx}$    | 导数            |
| $\\partial$               | 偏导数           |
| $\\nabla$                 | 梯度（nabla 算子）  |
| $\\int$、$\\iint$、$\\oint$ | 定积分、重积分、闭曲线积分 |
| $\\sum$                   | 求和（级数）        |
| $o(\\cdot)$、$O(\\cdot)$   | 高阶无穷小、同阶      |

表中左列为符号，右列为含义。

## 应用方向

  - 机器学习：损失函数的梯度、反向传播（链式法则）、梯度下降、Adam 等优化器
  - 概率统计：概率密度的积分、期望与方差、最大似然（对数似然求导，见 [Gaussian
    Distribution](/0005_Math_GaussianDistribution)）
  - 物理与工程：运动学（位置→速度→加速度）、场（电磁场、流体）、微分方程建模
  - 图形与视觉：曲线曲面的切线法线、泰勒近似、积分渲染方程
