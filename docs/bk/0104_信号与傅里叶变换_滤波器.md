# 滤波器

滤波器是一类 LTI 系统，用来让某些频率成分通过、抑制另一些成分。它在去噪、平滑、边缘检测、信道均衡中无处不在。

## 频率响应与滤波器类型

LTI 系统对频率 $\\omega$ 的作用由频率响应 $H(\\omega)$ 描述（见
[信号与线性系统](/0099_信号与傅里叶变换_信号与线性系统)）：

$$ Y(\\omega)=H(\\omega)X(\\omega),\\qquad |H(\\omega)|\\
\\text{幅度响应},\\quad \\arg H(\\omega)\\ \\text{相位响应} $$

其中 $X,Y$ 是输入、输出的频谱，$|H|$ 决定各频率被放大/衰减多少，$\\arg H$ 决定被延迟多少。群延迟
$-\\dfrac{d\\arg H}{d\\omega}$ 恒定（线性相位）时波形不失真。

| 类型        | 通过   | 抑制   | 用途                 |
| --------- | ---- | ---- | ------------------ |
| 低通（LP）    | 低频   | 高频   | 去噪、平滑、抗混叠          |
| 高通（HP）    | 高频   | 低频   | 去直流、边缘检测           |
| 带通（BP）    | 某一频段 | 其余   | 收音机选台、心电提取         |
| 带阻（BS/陷波） | 其余   | 某一频段 | 去除 $50/60$ Hz 工频干扰 |

表中依次为类型、通过频段、抑制频段和用途。幅度以分贝 $20\\log\_{10}|H|$ 表示，$-3$ dB 点（幅度降为
$1/\\sqrt2$）常定义为截止频率。理想滤波器是矩形频响（砖墙），其冲激响应是无限长的 sinc，不可实现，只能逼近。

## FIR 滤波器

有限冲激响应：输出是有限个输入的加权和（卷积，见 [卷积](/0100_信号与傅里叶变换_卷积)）：

$$ y\[n\]=\\sum\_{k=0}^{M-1}b\_k,x\[n-k\],\\qquad
H(\\omega)=\\sum\_{k=0}^{M-1}b\_ke^{-j\\omega k} $$

其中 $b\_k$ 是滤波器系数（即冲激响应 $h\[k\]$），$M$
是阶数加一。特点：永远稳定；系数对称时具有严格线性相位；缺点是要达到陡峭的截止需要较多系数。

例：长度 $M=3$ 的移动平均 $b=\[\\tfrac13,\\tfrac13,\\tfrac13\]$：

$$
H(\\omega)=\\frac13\\bigl(1+e^{-j\\omega}+e^{-j2\\omega}\\bigr)=e^{-j\\omega},\\frac{1+2\\cos\\omega}3
$$

其中 $e^{-j\\omega}$ 是 $1$ 个样本的延迟（线性相位），幅度
$\\dfrac{1+2\\cos\\omega}3$：$\\omega=0$ 时为 $1$（直流无衰减），$\\omega=\\pi$
时为 $-\\tfrac13$（强烈衰减），在 $\\omega=2\\pi/3$ 处恰为零。所以移动平均是粗糙的低通滤波器。

**设计方法**：窗函数法（把理想低通的 sinc 乘窗截短）、频率采样法、Parks-McClellan（等纹波最优）。

## IIR 滤波器

无限冲激响应：输出还依赖过去的输出（递归/反馈）：

$$ y\[n\]=\\sum\_{k=0}^{M}b\_kx\[n-k\]-\\sum\_{k=1}^{N}a\_ky\[n-k\] $$

其中 $a\_k$ 是反馈系数。用 z 变换（$z=e^{j\\omega}$）写成传递函数 $H(z)=\\dfrac{\\sum
b\_kz^{-k}}{1+\\sum a\_kz^{-k}}$。**稳定性**：所有极点（分母的根）位于单位圆内
$|z|\<1$——与差分方程特征根的稳定判据一致（见
[递推与生成函数](/0097_离散数学_递推与生成函数)、[常微分方程](/0057_微积分_常微分方程)）。

例（指数平滑，一阶 IIR）：

$$ y\[n\]=\\alpha x\[n\]+(1-\\alpha),y\[n-1\],\\qquad 0\<\\alpha\\le1 $$

其中 $\\alpha$ 是平滑系数，$y\[n\]$ 是当前估计。极点在 $z=1-\\alpha$，$|1-\\alpha|\<1$
故稳定。$\\alpha$ 小则平滑强但响应慢，时间常数约
$-1/\\ln(1-\\alpha)$。这就是指数移动平均（EMA），也是深度学习优化器中动量与
Adam 的一阶/二阶矩估计（见 [一阶方法与随机梯度](/0081_优化理论_一阶方法与随机梯度)）。

经典设计：

| 类型   | 特点                                                                          |
| ---- | --------------------------------------------------------------------------- |
| 巴特沃斯 | 通带最平坦，幅度 $\\lvert H\\rvert^2=\\dfrac1{1+(\\omega/\\omega\_c)^{2N}}$，$N$ 为阶数 |
| 切比雪夫 | 过渡带更陡，通带（I 型）或阻带（II 型）有纹波                                                   |
| 椭圆   | 过渡带最陡，通带阻带都有纹波                                                              |

表中依次为设计名称和特点，其中 $\\omega\_c$ 是截止频率，$N$ 越大过渡带越陡。IIR
用较低阶数就能得到陡峭的响应，但相位非线性，且需要检查稳定性。

## FIR 与 IIR 比较

| 比较项      | FIR    | IIR        |
| -------- | ------ | ---------- |
| 稳定性      | 总是稳定   | 需保证极点在单位圆内 |
| 相位       | 可严格线性  | 非线性        |
| 同样指标所需阶数 | 高      | 低          |
| 计算       | 卷积，易并行 | 递归，有状态     |

表中依次为比较项、FIR 与 IIR 的特点。

## 频域实现

对长信号和长滤波器，用 FFT 实现快速卷积：补零后做 FFT，频域相乘，再做逆 FFT（重叠相加/重叠保留法，见 [离散傅里叶变换与
FFT](/0102_信号与傅里叶变换_离散傅里叶变换与FFT)）。注意循环卷积的混叠问题。

## 高斯滤波与图像

高斯滤波器是用高斯函数作冲激响应的低通滤波器，频响也是高斯函数（见
[连续傅里叶变换](/0101_信号与傅里叶变换_连续傅里叶变换)），没有振铃，且可分离（见
[Gaussian Filter](/0021_信号与傅里叶变换_滤波器_高斯滤波器进阶)）。图像中：

  - 低通：均值、高斯滤波去噪；中值滤波（非线性）去椒盐噪声
  - 高通：拉普拉斯、Sobel 提取边缘；拉普拉斯算子的频响 $-(\\omega\_x^2+\\omega\_y^2)$ 随频率增大（见
    [曲线曲面积分与场论](/0056_微积分_曲线曲面积分与场论)）
  - 卷积神经网络的卷积核可以看作可学习的滤波器组

## 最优滤波

  - **维纳滤波**：在均方误差意义下最优的线性滤波，频域增益
    $H(\\omega)=\\dfrac{S\_{xx}(\\omega)}{S\_{xx}(\\omega)+S\_{nn}(\\omega)}$，其中
    $S\_{xx},S\_{nn}$ 是信号与噪声的功率谱，信噪比高的频率保留、低的抑制。
  - **卡尔曼滤波**：对线性高斯状态空间模型的递推最优估计，是维纳滤波的时变推广（见 [Gaussian
    Filter](/0021_信号与傅里叶变换_滤波器_高斯滤波器进阶)、[贝叶斯统计](/0074_数理统计_贝叶斯统计)）。

## 应用

  - 音频：均衡器、降噪、语音增强
  - 图像：去噪、锐化、边缘检测、金字塔
  - 通信：匹配滤波、信道均衡、脉冲整形
  - 传感与控制：传感器数据平滑、互补滤波、PID 中的微分滤波
