# 凸集与凸函数

凸性是优化中最重要的结构：凸问题的任何局部最优解都是全局最优解，因此可以用简单的迭代算法可靠求解。判断一个问题是否凸，是选择优化方法的第一步。

## 凸集

集合 $C\\subseteq\\mathbb{R}^n$ 是凸集，当且仅当任意两点间的线段仍在集合内：

$$ \\mathbf{x},\\mathbf{y}\\in C,\\ \\theta\\in\[0,1\]\\
\\Longrightarrow\\ \\theta\\mathbf{x}+(1-\\theta)\\mathbf{y}\\in C $$

其中 $\\theta$ 是凸组合系数，$\\theta\\mathbf{x}+(1-\\theta)\\mathbf{y}$ 是
$\\mathbf{x}$ 与 $\\mathbf{y}$ 连线上的点。

常见凸集：

| 凸集   | 定义                                                              |
| ---- | --------------------------------------------------------------- |
| 超平面  | ${\\mathbf{x}\\mid\\mathbf{a}^\\top\\mathbf{x}=b}$              |
| 半空间  | ${\\mathbf{x}\\mid\\mathbf{a}^\\top\\mathbf{x}\\le b}$          |
| 多面体  | 有限个半空间的交 ${\\mathbf{x}\\mid A\\mathbf{x}\\le\\mathbf{b}}$       |
| 球    | ${\\mathbf{x}\\mid\\lVert\\mathbf{x}-\\mathbf{c}\\rVert\\le r}$ |
| 半正定锥 | ${X\\in\\mathbb{S}^n\\mid X\\succeq0}$                          |

表中依次为凸集名称和定义，其中 $\\mathbf{a}\\ne\\mathbf{0}$ 是法向量，$b$
是常数，$\\mathbf{c},r$ 是球心和半径（范数见
[norm](https://github.com/junxnone/math/issues/11)），$\\mathbb{S}^n$ 是
$n$ 阶对称矩阵空间（半正定见
[对称正定与二次型](https://github.com/junxnone/math/issues/41)）。

保持凸性的运算：任意个凸集的交、仿射变换的像与原像、笛卡尔积。注意：凸集的**并**一般不是凸集。

## 凸函数

$f:C\\to\\mathbb{R}$（$C$ 为凸集）是凸函数，当且仅当：

$$ f\\bigl(\\theta\\mathbf{x}+(1-\\theta)\\mathbf{y}\\bigr)\\le\\theta
f(\\mathbf{x})+(1-\\theta)f(\\mathbf{y}),\\qquad
\\forall\\mathbf{x},\\mathbf{y}\\in C,\\ \\theta\\in\[0,1\] $$

其中不等号含义：函数图像上任意两点的连线（弦）在图像之上。严格凸时取严格不等号。$-f$ 凸则 $f$ 为凹。

**一阶条件**（$f$ 可微）：

$$ f(\\mathbf{y})\\ge f(\\mathbf{x})+\\nabla
f(\\mathbf{x})^\\top(\\mathbf{y}-\\mathbf{x}),\\qquad
\\forall\\mathbf{x},\\mathbf{y} $$

其中右端是 $f$ 在 $\\mathbf{x}$ 处的一阶泰勒近似（切平面）。含义：切平面处处在函数图像下方，是全局下界（见
[中值定理与泰勒公式](https://github.com/junxnone/math/issues/51)）。推论：$\\nabla
f(\\mathbf{x}^*)=\\mathbf{0}$ 时 $\\mathbf{x}^*$ 是全局最小点。

**二阶条件**（$f$ 二阶可微）：

$$ \\nabla^2f(\\mathbf{x})\\succeq0,\\qquad \\forall\\mathbf{x}\\in C $$

其中 $\\nabla^2f$ 是 Hessian 矩阵，$\\succeq0$ 表示半正定（见
[多元函数微分](https://github.com/junxnone/math/issues/54)）。一元时即
$f''\\ge0$。

## 常见凸函数

  - 仿射函数 $\\mathbf{a}^\\top\\mathbf{x}+b$（既凸又凹）；二次函数
    $\\frac12\\mathbf{x}^\\top A\\mathbf{x}$，当且仅当 $A\\succeq0$ 时凸
  - 指数 $e^{ax}$；幂函数 $x^p$（$x\>0,p\\ge1$ 或 $p\\le0$）；负对数 $-\\ln x$；负熵
    $x\\ln x$
  - 任意范数 $\\lVert\\mathbf{x}\\rVert$；最大值
    $\\max(x\_1,\\dots,x\_n)$；log-sum-exp
    $\\ln\\sum\_ie^{x\_i}$（softmax 的归一化项）
  - 最小二乘 $\\lVert A\\mathbf{x}-\\mathbf{b}\\rVert\_2^2$（Hessian
    $2A^\\top A\\succeq0$，见
    [投影](https://github.com/junxnone/math/issues/42)）；逻辑回归的交叉熵损失

保持凸性的运算：非负加权和 $\\sum w\_if\_i$（$w\_i\\ge0$）、逐点最大 $\\max\_if\_i$、与仿射函数复合
$f(A\\mathbf{x}+\\mathbf{b})$。

## 局部最优即全局最优

**定理**：凸函数在凸集上的任何局部极小点都是全局极小点。

证明思路：设 $\\mathbf{x}$ 是局部极小但存在 $\\mathbf{y}$ 使
$f(\\mathbf{y})\<f(\\mathbf{x})$，则
$\\mathbf{z}*\\theta=\\theta\\mathbf{y}+(1-\\theta)\\mathbf{x}$ 满足
$f(\\mathbf{z}*\\theta)\\le\\theta
f(\\mathbf{y})+(1-\\theta)f(\\mathbf{x})\<f(\\mathbf{x})$；令
$\\theta\\to0$，$\\mathbf{z}\_\\theta$ 任意接近 $\\mathbf{x}$
却函数值更小，与局部极小矛盾。严格凸函数的最小点唯一。

## 强凸与光滑

| 性质     | 定义                                                                                                       | 含义                                      |
| ------ | -------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| $m$-强凸 | $\\nabla^2f\\succeq mI$                                                                                  | 曲率至少为 $m\>0$，有唯一最小点，下界为二次函数             |
| $L$-光滑 | $\\lVert\\nabla f(\\mathbf{x})-\\nabla f(\\mathbf{y})\\rVert\\le L\\lVert\\mathbf{x}-\\mathbf{y}\\rVert$ | 梯度变化不超过 $L$，等价于 $\\nabla^2f\\preceq LI$ |
| 条件数    | $\\kappa=L/m$                                                                                            | 梯度下降收敛速度的关键                             |

表中依次为性质、定义和含义。$m,L$ 分别是 Hessian 最小、最大特征值的界；条件数越大，等值线越细长，梯度下降越慢（见
[范数与条件数](https://github.com/junxnone/math/issues/45)、[无约束优化](https://github.com/junxnone/math/issues/78)）。

## 上境图与詹森不等式

$f$ 是凸函数当且仅当其上境图 $\\mathrm{epi}f={(\\mathbf{x},t)\\mid
f(\\mathbf{x})\\le t}$
是凸集，这把函数的凸性归结为集合的凸性。詹森不等式：$f(\\mathbb{E}\[\\mathbf{X}\])\\le\\mathbb{E}\[f(\\mathbf{X})\]$（见
[期望方差与矩](https://github.com/junxnone/math/issues/64)）。

## 例

  - $f(x)=x^2$：$f''=2\>0$，严格凸，$m=L=2$。
  - $f(x,y)=x^2+3y^2$：$H=\\mathrm{diag}(2,6)\\succ0$，强凸，$m=2,L=6,\\kappa=3$。
  - $f(x,y)=xy$：$H=\\begin{bmatrix}0&1\\1&0\\end{bmatrix}$ 特征值
    $\\pm1$，不定，不是凸函数（$(0,0)$ 是鞍点）。

## 应用

  - 判断问题可否用凸优化求解：线性回归、岭回归、Lasso、SVM、逻辑回归都是凸问题
  - 建模技巧：把非凸问题松弛成凸问题（凸松弛）
  - 理论分析：收敛速率依赖于强凸系数和光滑系数
