# 集合与关系

集合是现代数学的基本语言；关系和函数刻画集合元素之间的联系。理解关系的性质（自反、对称、传递）就能识别等价关系和偏序，这是分类、排序、数据库设计的基础。

## 集合与运算

集合是不同对象的无序整体；$x\\in A$ 表示 $x$ 属于 $A$。常用记号与运算：

| 运算   | 记号                | 定义                                          |
| ---- | ----------------- | ------------------------------------------- |
| 并    | $A\\cup B$        | ${x\\mid x\\in A\\ \\text{或}\\ x\\in B}$    |
| 交    | $A\\cap B$        | ${x\\mid x\\in A\\ \\text{且}\\ x\\in B}$    |
| 差    | $A\\setminus B$   | ${x\\mid x\\in A\\ \\text{且}\\ x\\notin B}$ |
| 补    | $\\overline A$    | $U\\setminus A$（$U$ 是全集）                    |
| 对称差  | $A\\oplus B$      | $(A\\setminus B)\\cup(B\\setminus A)$       |
| 笛卡尔积 | $A\\times B$      | ${(a,b)\\mid a\\in A,\\ b\\in B}$           |
| 幂集   | $\\mathcal{P}(A)$ | $A$ 的全部子集构成的集合                              |

表中依次为运算、记号和定义。重要事实：

  - 德摩根律：$\\overline{A\\cup B}=\\overline A\\cap\\overline
    B$，$\\overline{A\\cap B}=\\overline A\\cup\\overline B$
  - 分配律：$A\\cap(B\\cup C)=(A\\cap B)\\cup(A\\cap C)$
  - 计数：$|A\\times
    B|=|A||B|$，$|\\mathcal{P}(A)|=2^{|A|}$（每个元素选或不选）；$|A\\cup
    B|=|A|+|B|-|A\\cap B|$（见
    [组合计数](https://github.com/junxnone/math/issues/94)）

概率中的事件运算与集合运算一一对应（见
[概率空间与公理](https://github.com/junxnone/math/issues/60)）。

## 基数与可数性

  - 有限集的基数是元素个数。
  - 两个集合之间存在双射，则基数相同。$\\mathbb{N},\\mathbb{Z},\\mathbb{Q}$
    都是**可数**无穷集（可以与 $\\mathbb{N}$ 一一对应）。
  - $\\mathbb{R}$ 不可数（康托对角线论证）；$|\\mathcal{P}(A)|\>|A|$ 对任何集合成立（康托定理）。

## 二元关系

$A$ 到 $B$ 的关系 $R\\subseteq A\\times B$，$(a,b)\\in R$ 记作 $aRb$。$A$
上的关系性质：

| 性质  | 定义                               | 例子                  |
| --- | -------------------------------- | ------------------- |
| 自反  | $\\forall a:\\ aRa$              | $\\le$、整除           |
| 对称  | $aRb\\Rightarrow bRa$            | 同学关系、$=$            |
| 反对称 | $aRb\\wedge bRa\\Rightarrow a=b$ | $\\le$、$\\subseteq$ |
| 传递  | $aRb\\wedge bRc\\Rightarrow aRc$ | $\<$、整除             |

表中依次为性质、定义和例子，其中 $\\wedge$ 表示“且”。有限集上的关系可以用**布尔矩阵** $M\_R$
表示（$M\_{ij}=1$ 当且仅当 $a\_iRa\_j$），关系的复合对应布尔矩阵乘积（见
[矩阵乘积](https://github.com/junxnone/math/issues/27)），传递闭包可以通过矩阵幂（Warshall
算法）计算。

## 等价关系与划分

自反 + 对称 + 传递 =
**等价关系**。每个等价关系把集合分成互不相交的**等价类**，这些类构成集合的一个**划分**；反过来每个划分也确定一个等价关系。

例：整数上的“模 $n$ 同余”：$a\\sim b\\iff n\\mid(a-b)$，等价类就是 $n$ 个剩余类
$\[0\],\[1\],\\dots,\[n-1\]$（见
[数论基础](https://github.com/junxnone/math/issues/96)）。其他例子：图的连通关系、聚类（簇）、对象的同构。

## 偏序与哈斯图

自反 + 反对称 + 传递 = **偏序**，记作
$(S,\\preceq)$。例：集合的包含、整数的整除、任务的依赖。用哈斯图表示：省略自反与传递边，小元素在下，大元素在上。

下图是 ${1,2,3,6}$ 上整除关系的哈斯图：

``` mermaid

    N1 --> N3["3"]
    N2 --> N6["6"]
    N3 --> N6
```

图中：

  - 节点是元素，箭头从较小元素指向“恰好覆盖”它的较大元素（$a\\mid b$ 且之间没有其他元素），自下向上阅读。
  - $1$ 是最小元（整除所有数），$6$ 是最大元；$2$ 与 $3$
    互相不整除，是不可比较的——这就是“偏”序（不是所有元素对都可比）。
  - 全序（任意两元素可比，如 $\\le$）是偏序的特例；偏序可通过拓扑排序扩展为全序，用于任务调度。

偏序上的最大/最小元、极大/极小元、上确界/下确界，在格（lattice）和布尔代数中有重要作用。

## 函数

$f:A\\to B$ 是一种特殊关系（每个 $a\\in A$ 恰好对应一个 $b\\in B$）：

| 类型 | 条件                                  | 含义         |
| -- | ----------------------------------- | ---------- |
| 单射 | $f(a)=f(a')\\Rightarrow a=a'$       | 不同输入对应不同输出 |
| 满射 | $\\forall b\\ \\exists a:\\ f(a)=b$ | 每个输出都被取到   |
| 双射 | 既单又满                                | 一一对应，存在逆函数 |

表中依次为类型、条件和含义。有限集 $|A|=|B|$ 时单射、满射、双射等价；$|A|\>|B|$ 时不存在单射（鸽巢原理）。函数的复合
$g\\circ f$ 对应关系复合；线性映射是保持向量空间结构的函数（见
[线性变换](https://github.com/junxnone/math/issues/39)）。

## 例

  - 关系 $R={(1,1),(2,2),(3,3),(1,2),(2,1)}$ 在 ${1,2,3}$
    上：自反、对称、传递，是等价关系，划分
    ${{1,2},{3}}$。
  - ${1,2,3}$ 的幂集有 $2^3=8$
    个元素：$\\varnothing,{1},{2},{3},{1,2},{1,3},{2,3},{1,2,3}$，按包含关系构成偏序（哈斯图是立方体）。

## 应用

  - 数据库：关系模型（表就是关系）、主键与函数依赖
  - 编程：哈希（函数）、集合类型、拓扑排序（偏序）
  - 机器学习与聚类：等价类与划分、相似关系
  - 图论：图就是对称的二元关系（见 [图论](https://github.com/junxnone/math/issues/22)）
