# 线性规划

线性规划（Linear
Programming，LP）是目标函数和约束都是线性的优化问题，是运筹学中应用最广的模型：生产计划、运输、配餐、网络流都可以表示为
LP。

## 概念关系图

``` mermaid
flowchart LR
    LP[线性规划 线性目标与线性约束] --> ST[标准形 松弛变量]
    ST --> G[几何 可行域是多面体 最优在顶点]
    G --> SP[单纯形法 沿顶点移动]
    LP --> DU[对偶问题 强对偶]
    LP --> IP[内点法 多项式时间]
```

图中：线性规划化为标准形后，可行域是多面体，最优解在顶点上；单纯形法沿顶点移动找最优，内点法从可行域内部逼近；每个 LP 都有对偶问题。

## 标准形

$$ \\min\_{\\mathbf{x}}\\
\\mathbf{c}^\\top\\mathbf{x}\\quad\\text{s.t.}\\
A\\mathbf{x}=\\mathbf{b},\\ \\mathbf{x}\\ge\\mathbf{0} $$

其中：

  - $\\mathbf{x}\\in\\mathbb{R}^n$：决策变量；$\\mathbf{c}\\in\\mathbb{R}^n$：成本系数
  - $A\\in\\mathbb{R}^{m\\times
    n}$：约束矩阵；$\\mathbf{b}\\in\\mathbb{R}^m$：资源/需求；$\\mathbf{x}\\ge\\mathbf{0}$
    逐分量非负
  - 任何 LP 都可化为标准形：不等式 $\\mathbf{a}^\\top\\mathbf{x}\\le b$ 加松弛变量
    $s\\ge0$ 变为 $\\mathbf{a}^\\top\\mathbf{x}+s=b$；自由变量写成两个非负变量之差；最大化取负

## 几何：顶点与基本可行解

可行域 ${\\mathbf{x}\\mid
A\\mathbf{x}=\\mathbf{b},\\mathbf{x}\\ge\\mathbf{0}}$ 是多面体（凸集，见
[凸集与凸函数](/0077_优化理论_凸集与凸函数)）。基本定理：若 LP
有最优解，则必在某个**顶点**取到。顶点对应**基本可行解**：取
$m$ 个线性无关的列作为基 $B$，令其余 $n-m$ 个变量为 $0$，解 $B\\mathbf{x}\_B=\\mathbf{b}$ 得
$\\mathbf{x}\_B=B^{-1}\\mathbf{b}\\ge\\mathbf{0}$（见
[线性方程组](/0035_线性代数_线性方程组)、[秩](/0029_线性代数_Matrix_秩)）。

## 例

某工厂生产两种产品，利润分别为 $3$ 与 $2$ 万元/件，资源约束
$x+y\\le4$，$x+3y\\le6$，$x,y\\ge0$。求最大利润：

$$ \\max\\ 3x+2y\\quad\\text{s.t.}\\ x+y\\le4,\\ \\ x+3y\\le6,\\ \\
x,y\\ge0 $$

其中 $x,y$ 是两种产品的产量。可行域的顶点及目标值：

| 顶点    | $(x,y)$ | 目标值  |
| ----- | ------- | ---- |
| 原点    | $(0,0)$ | $0$  |
| 横轴交点  | $(4,0)$ | $12$ |
| 两约束交点 | $(3,1)$ | $11$ |
| 纵轴交点  | $(0,2)$ | $4$  |

表中依次为顶点、坐标和目标函数值，比较得最优解 $(4,0)$，最大利润 $12$。$(3,1)$ 是 $x+y=4$ 与 $x+3y=6$
的交点（解线性方程组得到）。

## 单纯形法

从一个基本可行解（顶点）出发，沿目标改进的边移动到相邻顶点，直到无改进方向（最优）：

1.  找初始基本可行解（两阶段法）；
2.  计算检验数（简约成本）$\\bar c\_j=c\_j-\\mathbf{c}\_B^\\top
    B^{-1}\\mathbf{a}\_j$；
3.  若所有 $\\bar c\_j\\ge0$ 则最优；否则选一个负的 $\\bar c\_j$ 对应的变量入基；
4.  用最小比值法确定离基变量，更新基，回到 2。

其中 $\\mathbf{c}\_B$ 是基变量的成本，$\\mathbf{a}\_j$ 是第 $j$ 列。每次迭代本质是一次高斯消元（见
[初等变换](/0038_线性代数_Matrix_初等变换)）。实践中通常很快，最坏情形指数复杂度；内点法是多项式时间，适合超大规模。

## 对偶

原问题（P）与对偶问题（D）：

$$ \\text{(P)}\\ \\ \\min\\mathbf{c}^\\top\\mathbf{x}\\ \\text{s.t.}\\
A\\mathbf{x}\\ge\\mathbf{b},\\mathbf{x}\\ge\\mathbf{0}\\qquad
\\text{(D)}\\ \\ \\max\\mathbf{b}^\\top\\mathbf{y}\\ \\text{s.t.}\\
A^\\top\\mathbf{y}\\le\\mathbf{c},\\mathbf{y}\\ge\\mathbf{0} $$

其中 $\\mathbf{y}\\in\\mathbb{R}^m$
是对偶变量，每个原约束对应一个对偶变量，每个原变量对应一个对偶约束。**强对偶定理**：二者之一有有限最优解则另一个也有且最优值相等；**互补松弛**：$y\_i(A\\mathbf{x}-\\mathbf{b})\_i=0$
且 $x\_j(\\mathbf{c}-A^\\top\\mathbf{y})\_j=0$（见
[约束优化与对偶](/0079_优化理论_约束优化与对偶)）。

上例（max 形式）的对偶：$\\min4u+6v$ s.t. $u+v\\ge3$，$u+3v\\ge2$，$u,v\\ge0$。取
$(u,v)=(3,0)$ 得 $4\\times3=12$，与原问题最优值相等，验证强对偶；$u=3,v=0$
是资源的**影子价格**：第一种资源每增加一单位，利润增加
$3$，第二种资源没有用完（$4+3\\cdot0=4\<6$）所以价格为 $0$。

## 典型问题

  - 运输与指派问题、最短路与最大流（约束矩阵全单模，LP 的顶点解自动是整数）
  - 饮食问题：满足营养约束的最小成本
  - 数据拟合：$L\_1$ 回归与 $L\_\\infty$ 回归（Chebyshev）可化为 LP
  - 整数规划：加整数约束后是 NP 难；常用 LP 松弛 + 分支定界

## 内点法（简介）

沿可行域内部的“中心路径”逼近最优解：用对数障碍
$\\min\\mathbf{c}^\\top\\mathbf{x}-\\tfrac1t\\sum\_j\\ln
x\_j$，$t\\to\\infty$ 时趋于 LP 解。每步用牛顿法求解线性方程组（见
[二阶方法与拟牛顿](/0082_优化理论_二阶方法与拟牛顿)），迭代次数约
$O(\\sqrt n\\ln(1/\\varepsilon))$，大规模稀疏问题的主流选择。

## 应用

  - 运筹管理：生产计划、库存、排班、物流
  - 机器学习：线性 SVM 的 LP 形式、稀疏恢复（基追踪）
  - 博弈论：零和博弈的混合策略可用 LP 求解

## 求解方法对比

| 方法   | 思路            | 复杂度       | 特点              |
| ---- | ------------- | --------- | --------------- |
| 单纯形法 | 沿顶点边移动        | 最坏指数，实际很快 | 给出基本可行解，便于灵敏度分析 |
| 内点法  | 在可行域内部沿中心路径逼近 | 多项式时间     | 适合大规模问题         |

表中：对比结论：中小规模和需要灵敏度分析用单纯形法，大规模用内点法。

## 在机器学习中的作用

  - 稀疏恢复与 $L\_1$ 范数最小化可以化为线性规划（基追踪）
  - 最优传输（Wasserstein 距离）是一个线性规划
  - 支持向量机的一些变体、鲁棒回归（最小一乘）可写成 LP

## 常见误区

  - LP 的最优解可能不唯一（目标函数与某条边平行）、可能无界、也可能不可行，求解前要判断
  - 整数规划不是线性规划：加上整数约束后是 NP 难问题，不能简单地把 LP 解四舍五入
  - 对偶问题的变量个数等于原问题的约束个数，互换了「变量」与「约束」的角色
