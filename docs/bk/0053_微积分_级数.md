# 级数

级数是无穷多项的和。它把“无限累加”变成可以研究的对象，幂级数和傅里叶级数则把函数表示成简单函数的无穷和，是函数逼近、信号处理的基础。

## 数项级数与收敛

$$ \\sum\_{n=1}^{\\infty}a\_n=\\lim\_{N\\to\\infty}S\_N,\\qquad
S\_N=\\sum\_{n=1}^{N}a\_n $$

其中：

  - $a\_n$：通项；$S\_N$：前 $N$ 项的部分和
  - 极限存在称级数收敛，该极限值为级数的和；否则发散
  - 必要条件：收敛 $\\Rightarrow a\_n\\to0$（反之不成立，如调和级数 $\\sum1/n$ 发散）

两个基本例子：

| 级数                                         | 结论                                              |
| ------------------------------------------ | ----------------------------------------------- |
| 几何级数 $\\sum\_{n=0}^\\infty q^n$            | $\\lvert q\\rvert\<1$ 时收敛于 $\\dfrac1{1-q}$，否则发散 |
| $p$-级数 $\\sum\_{n=1}^\\infty\\dfrac1{n^p}$ | $p\>1$ 收敛，$p\\le1$ 发散                           |

表中左列是级数，右列是收敛条件与和，其中 $q$ 为公比，$p$ 为指数。它们常作为比较判别法的参照。

## 判别法

| 判别法   | 适用                 | 结论                                                                |
| ----- | ------------------ | ----------------------------------------------------------------- |
| 比较法   | 正项级数               | $0\\le a\_n\\le b\_n$：$\\sum b\_n$ 收敛 $\\Rightarrow\\sum a\_n$ 收敛 |
| 比值法   | 含阶乘、指数             | $\\lim\\dfrac{a\_{n+1}}{a\_n}=\\rho$：$\\rho\<1$ 收敛，$\\rho\>1$ 发散  |
| 根值法   | 含 $n$ 次方           | $\\lim\\sqrt\[n\]{a\_n}=\\rho$：同上                                 |
| 积分判别法 | $a\_n=f(n)$，$f$ 单调 | $\\sum a\_n$ 与 $\\int^\\infty f$ 同敛散                              |
| 莱布尼茨法 | 交错级数               | $a\_n$ 单调趋于 0 $\\Rightarrow\\sum(-1)^na\_n$ 收敛                    |

表中依次是判别法、适用对象和结论，$\\rho=1$ 时比值/根值法失效。绝对收敛（$\\sum|a\_n|$
收敛）蕴含收敛，且可任意重排；仅条件收敛的级数重排后和可以改变。

## 幂级数

$$ \\sum\_{n=0}^\\infty c\_n(x-a)^n $$

其中：

  - $c\_n$：系数；$a$：展开中心；$x$：变量
  - 收敛半径
    $R=\\lim\\Bigl|\\dfrac{c\_n}{c\_{n+1}}\\Bigr|$（极限存在时）：$|x-a|\<R$
    内绝对收敛，$|x-a|\>R$ 发散，端点单独检验
  - 在收敛域内可逐项求导、逐项积分，因此把函数展开成幂级数，就可以像多项式一样运算
  - 若 $c\_n=f^{(n)}(a)/n\!$，就是泰勒级数（见
    [中值定理与泰勒公式](https://github.com/junxnone/math/issues/51)）

例：$\\dfrac1{1-x}=\\sum x^n\\ (|x|\<1)$，两边积分得
$-\\ln(1-x)=\\sum\\dfrac{x^{n}}{n}$，两边逐项求导则得 $\\dfrac1{(1-x)^2}=\\sum
nx^{n-1}$。

欧拉公式（由幂级数比较得到）：

$$ e^{ix}=\\cos x+i\\sin x $$

其中 $i$ 是虚数单位，$x$ 为实数（弧度）。它把指数与三角函数统一起来，是傅里叶分析的基础。

## 傅里叶级数

周期为 $2\\pi$ 的函数 $f$ 可展开为：

$$ f(x)\\sim\\frac{a\_0}2+\\sum\_{n=1}^\\infty\\bigl(a\_n\\cos
nx+b\_n\\sin nx\\bigr) $$

$$ a\_n=\\frac1\\pi\\int\_{-\\pi}^{\\pi}f(x)\\cos nx,dx,\\qquad
b\_n=\\frac1\\pi\\int\_{-\\pi}^{\\pi}f(x)\\sin nx,dx $$

其中：

  - $n$：谐波次数（频率为基频的 $n$ 倍）；$a\_n,b\_n$：第 $n$ 次余弦、正弦分量的幅度（傅里叶系数）
  - 系数公式来自三角函数系的正交性：$\\int\_{-\\pi}^{\\pi}\\cos nx\\cos mx,dx=0\\ (n\\ne
    m)$，类似线性代数里标准正交基上的投影（见
    [向量空间](https://github.com/junxnone/math/issues/34)）
  - 狄利克雷条件下（分段光滑）级数在连续点收敛于 $f(x)$，在间断点收敛于左右极限的平均值
  - 把离散化后的版本称为 DFT/FFT，是信号处理的核心

## 例题

**判敛**：

  - $\\sum\\dfrac{n\!}{n^n}$：比值 $\\dfrac{a\_{n+1}}{a\_n}=\\Bigl(\\dfrac
    n{n+1}\\Bigr)^n\\to\\dfrac1e\<1$，收敛。
  - $\\sum\\dfrac{(-1)^n}{n}$：交错调和级数，由莱布尼茨法收敛（条件收敛，因为 $\\sum\\dfrac1n$
    发散），和为 $-\\ln2$。
  - $\\sum\\dfrac1{n\\ln
    n}$（$n\\ge2$）：积分判别法，$\\int^\\infty\\dfrac{dx}{x\\ln
    x}=\\ln\\ln x\\to\\infty$，发散。

**收敛半径**：$\\sum\\dfrac{x^n}{n\!}$ 中
$\\Bigl|\\dfrac{c\_n}{c\_{n+1}}\\Bigr|=n+1\\to\\infty$，$R=\\infty$，对应
$e^x$ 的展开（见 [中值定理与泰勒公式](https://github.com/junxnone/math/issues/51)）。

**傅里叶级数——方波**：$f(x)=\\begin{cases}1&0\<x\<\\pi\\-1&-\\pi\<x\<0\\end{cases}$
是奇函数，$a\_n=0$，$b\_n=\\dfrac2\\pi\\displaystyle\\int\_0^\\pi\\sin
nx,dx=\\dfrac{2(1-(-1)^n)}{n\\pi}$，所以：

$$ f(x)\\sim\\frac4\\pi\\Bigl(\\sin
x+\\frac{\\sin3x}3+\\frac{\\sin5x}5+\\cdots\\Bigr) $$

其中：

  - 只含奇次谐波，幅度按 $1/n$ 衰减；取更多项逼近更好，但在间断点附近总有约 9% 的过冲（吉布斯现象）
  - 取 $x=\\pi/2$ 得
    $1=\\dfrac4\\pi\\bigl(1-\\tfrac13+\\tfrac15-\\cdots\\bigr)$，即
    $\\dfrac\\pi4=1-\\dfrac13+\\dfrac15-\\cdots$（莱布尼茨级数）

## 应用

  - 函数逼近与数值计算：用泰勒/傅里叶截断近似 $\\sin x$、$e^x$ 等
  - 信号处理：频谱分析、滤波、压缩（JPEG 的 DCT）
  - 微分方程：级数解法与分离变量法（见
    [常微分方程](https://github.com/junxnone/math/issues/57)）
  - 概率：生成函数、特征函数
