# 一阶方法与随机梯度

当数据量大、参数多时，每步都计算精确梯度或 Hessian 太贵。一阶方法只用梯度，随机梯度法更是只用一小批数据估计梯度，是深度学习训练的主力。

## 经验风险最小化与随机梯度

训练目标通常是样本损失的平均：

$$ F(\\mathbf{w})=\\frac1N\\sum\_{i=1}^N\\ell\_i(\\mathbf{w}),\\qquad
\\mathbf{w}\_{k+1}=\\mathbf{w}\_k-\\eta\_k,\\mathbf{g}\_k,\\quad
\\mathbf{g}*k=\\frac1{|B\_k|}\\sum*{i\\in
B\_k}\\nabla\\ell\_i(\\mathbf{w}\_k) $$

其中：

  - $\\mathbf{w}$：模型参数；$N$：样本数；$\\ell\_i$：第 $i$ 个样本的损失
  - $B\_k$：第 $k$ 步随机抽取的小批量（mini-batch），$|B\_k|$
    是批量大小；$\\mathbf{g}\_k$：小批量梯度
  - $\\eta\_k$：学习率；$\\mathbf{g}\_k$ 是真实梯度 $\\nabla F$
    的无偏估计：$\\mathbb{E}\[\\mathbf{g}\_k\]=\\nabla
    F(\\mathbf{w}\_k)$
  - 每步计算量与 $N$ 无关，只取决于 $|B|$；方差随批量按 $1/|B|$ 下降（见
    [大数定律与中心极限定理](https://github.com/junxnone/math/issues/66)）

## SGD 的收敛

| 设定      | 学习率                          | 收敛速率                             |
| ------- | ---------------------------- | -------------------------------- |
| 凸，固定步长  | 常数 $\\eta$                   | 收敛到最优附近的“噪声球”，半径 $\\propto\\eta$ |
| 凸，递减步长  | $\\eta\_k\\propto1/\\sqrt k$ | $O(1/\\sqrt k)$                  |
| 强凸，递减步长 | $\\eta\_k\\propto1/k$        | $O(1/k)$                         |

表中依次为设定、学习率设置和收敛速率。对比确定性梯度下降（凸 $O(1/k)$，强凸线性），SGD
单步便宜得多但需要递减学习率才能收敛到精确解；噪声也有好处：能帮助逃离鞍点和尖锐的局部极小（见
[非凸优化](https://github.com/junxnone/math/issues/83)）。

## 动量

$$ \\mathbf{v}\_{k+1}=\\beta\\mathbf{v}\_k+\\mathbf{g}*k,\\qquad
\\mathbf{w}*{k+1}=\\mathbf{w}*k-\\eta\\mathbf{v}*{k+1} $$

其中：

  - $\\mathbf{v}$：速度（梯度的指数滑动累积）；$\\beta\\in\[0,1)$：动量系数（常取 $0.9$）
  - 效果：在梯度方向一致的维度加速，在来回振荡的维度相互抵消，缓解“峡谷”形目标（条件数大）的锯齿路径（见
    [范数与条件数](https://github.com/junxnone/math/issues/45)）
  - **Nesterov 加速梯度**：在“前瞻点”处计算梯度 $\\nabla
    F(\\mathbf{w}\_k-\\eta\\beta\\mathbf{v}\_k)$；对凸 $L$-光滑问题达到最优的
    $O(1/k^2)$ 速率

## 自适应学习率

| 方法      | 更新                                                                                                                                                                                                                                              |
| ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AdaGrad | $G\_k=G\_{k-1}+\\mathbf{g}\_k^{\\odot2}$，$\\ \\mathbf{w}\\leftarrow\\mathbf{w}-\\dfrac{\\eta}{\\sqrt{G\_k}+\\epsilon}\\odot\\mathbf{g}\_k$                                                                                                      |
| RMSProp | $G\_k=\\rho G\_{k-1}+(1-\\rho)\\mathbf{g}\_k^{\\odot2}$，其余同上                                                                                                                                                                                    |
| Adam    | $\\mathbf{m}*k=\\beta\_1\\mathbf{m}*{k-1}+(1-\\beta\_1)\\mathbf{g}*k$，$\\ G\_k=\\beta\_2G*{k-1}+(1-\\beta\_2)\\mathbf{g}\_k^{\\odot2}$，$\\ \\mathbf{w}\\leftarrow\\mathbf{w}-\\eta\\dfrac{\\hat{\\mathbf{m}}\_k}{\\sqrt{\\hat G\_k}+\\epsilon}$ |

表中依次为方法与更新式，其中：

  - $\\odot2$ 表示逐元素平方；除法、开方也是逐元素；$G\_k$ 是梯度平方的累积/滑动平均，用来衡量每个参数的“历史梯度尺度”
  - 含义：梯度大的参数学习率变小，梯度小的参数学习率变大，相当于对每个坐标做对角预条件（对角近似的二阶信息，见
    [二阶方法与拟牛顿](https://github.com/junxnone/math/issues/82)）
  - Adam 同时用一阶矩 $\\mathbf{m}$（动量）和二阶矩 $G$；$\\hat{\\mathbf{m}},\\hat G$
    是偏差修正后的值（$\\hat{\\mathbf{m}}=\\mathbf{m}/(1-\\beta\_1^k)$）；常用
    $\\beta\_1=0.9,\\beta\_2=0.999,\\epsilon=10^{-8}$
  - 经验上 Adam 收敛快、调参容易，SGD+动量在某些视觉任务上泛化更好

## 学习率调度

  - 阶梯衰减、指数衰减、余弦退火
    $\\eta\_k=\\eta\_{\\min}+\\tfrac12(\\eta\_{\\max}-\\eta\_{\\min})\\bigl(1+\\cos\\tfrac{\\pi
    k}K\\bigr)$（$K$ 是总步数）
  - 预热（warm-up）：训练初期线性增大学习率，避免初始不稳定
  - 学习率与批量大小联动：批量增大 $k$ 倍时，学习率通常也线性增大（线性缩放规则）

## 近端梯度法

对复合目标 $F(\\mathbf{w})=f(\\mathbf{w})+r(\\mathbf{w})$（$f$ 光滑，$r$
凸但可能不可导，如 $L\_1$ 范数）：

$$ \\mathbf{w}*{k+1}=\\mathrm{prox}*{\\eta
r}\\bigl(\\mathbf{w}\_k-\\eta\\nabla f(\\mathbf{w}*k)\\bigr),\\qquad
\\mathrm{prox}*{\\eta\\lambda\\lVert\\cdot\\rVert\_1}(\\mathbf{z})\_i=\\mathrm{sign}(z\_i)\\max\\bigl(|z\_i|-\\eta\\lambda,\\
0\\bigr) $$

其中 $\\mathrm{prox}$ 是近端算子，$L\_1$ 范数对应的近端算子是**软阈值**：每个分量向零收缩
$\\eta\\lambda$，不足则直接置零。这就是 ISTA 算法，用于 Lasso 等稀疏学习问题（见
[回归分析](https://github.com/junxnone/math/issues/73)）；加上 Nesterov
加速得 FISTA，速率 $O(1/k^2)$。

## 实践要点

  - 梯度裁剪：$\\mathbf{g}\\leftarrow\\mathbf{g}\\cdot\\min(1,c/\\lVert\\mathbf{g}\\rVert)$，防止梯度爆炸
  - 权重衰减 $\\leftrightarrow$ $L\_2$ 正则化（见
    [贝叶斯统计](https://github.com/junxnone/math/issues/74)
    中的高斯先验）
  - 批量大小：小批量噪声大但泛化好，大批量并行效率高
  - 用学习率扫描（LR range test）选初值；监控训练损失曲线

## 应用

  - 深度学习训练：SGD、Adam、AdamW
  - 大规模线性模型、推荐系统（稀疏特征）
  - 在线学习：数据流上的逐样本更新
