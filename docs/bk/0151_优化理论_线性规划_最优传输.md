# 最优传输

最优传输研究：把一个概率分布「搬运」成另一个，**最小的总搬运代价**是多少。它给出了比 KL
散度更适合分布间几何比较的距离——Wasserstein
距离，在生成模型、域适应、图像检索中应用广泛。它的离散形式是一个线性规划，见
[线性规划](https://github.com/junxnone/math/issues/80)，分布差异的另一种度量见
[互信息与KL散度](https://github.com/junxnone/math/issues/86)。

## 概念关系图

``` mermaid
flowchart LR
    M[Monge 问题 传输映射 T] --> K[Kantorovich 松弛 传输方案 gamma]
    K --> LP[离散形式 线性规划]
    K --> W[Wasserstein 距离]
    K --> Du[Kantorovich 对偶 势函数]
    LP --> S[熵正则 Sinkhorn 算法]
    W --> A[应用 WGAN 域适应 重心]
```

图中：从 Monge 的传输映射放宽为 Kantorovich 的传输方案，得到线性规划与 Wasserstein
距离；对偶形式给出势函数；加熵正则后用 Sinkhorn 迭代高效求解，应用于
WGAN 等。

## 离散最优传输

两个离散分布
$\\mu=\\sum\_ia\_i\\delta\_{x\_i}$、$\\nu=\\sum\_jb\_j\\delta\_{y\_j}$（$a,b$
为质量，各自和为 1），代价矩阵 $C\_{ij}=c(x\_i,y\_j)$。**传输方案**
$\\gamma\\in\\mathbb{R}\_{\\ge0}^{m\\times n}$ 满足边缘约束：

$$ \\min\_{\\gamma\\ge0}\\ \\langle
C,\\gamma\\rangle=\\sum\_{i,j}C\_{ij}\\gamma\_{ij}\\quad\\text{s.t.}\\quad
\\gamma\\mathbf{1}=a,\\ \\ \\gamma^{\\top}\\mathbf{1}=b $$

其中：$\\gamma\_{ij}$ 是从 $x\_i$ 运往 $y\_j$ 的质量；约束要求每个源点运出的总量等于其质量
$a\_i$、每个目标点收到的总量等于 $b\_j$；这是线性目标、线性约束的 **线性规划**，可以用单纯形法求解，见
[线性规划](https://github.com/junxnone/math/issues/80)。

## Wasserstein 距离

取代价 $c(x,y)=\\lVert x-y\\rVert^{p}$，$p$-Wasserstein 距离为：

$$
W\_p(\\mu,\\nu)=\\Bigl(\\min\_{\\gamma\\in\\Pi(\\mu,\\nu)}\\sum\_{i,j}\\gamma\_{ij},\\lVert
x\_i-y\_j\\rVert^{p}\\Bigr)^{1/p} $$

其中：$\\Pi(\\mu,\\nu)$ 为所有满足边缘约束的传输方案集合；$W\_p$
是真正的**距离**（对称、满足三角不等式），且考虑了样本空间的几何。**一维情形**有闭式：$W\_1=\\int\\lvert
F\_\\mu(t)-F\_\\nu(t)\\rvert,dt$（累积分布函数之差的面积），见
[随机变量与分布](https://github.com/junxnone/math/issues/62)。

## Kantorovich 对偶

$$ W\_1(\\mu,\\nu)=\\sup\_{\\lVert f\\rVert\_{L}\\le1}\\
\\mathbb{E}*{x\\sim\\mu}\[f(x)\]-\\mathbb{E}*{y\\sim\\nu}\[f(y)\] $$

其中：$f$ 取遍 1-Lipschitz 函数（斜率不超过 1）；这个对偶形式正是 WGAN 的判别器（critic）目标：用神经网络逼近
$f$ 并约束其 Lipschitz 常数。对偶理论见
[约束优化与对偶](https://github.com/junxnone/math/issues/79)。

## Sinkhorn 算法（熵正则）

线性规划规模大时代价高。加入熵正则：

$$ \\min\_{\\gamma}\\ \\langle C,\\gamma\\rangle-\\varepsilon
H(\\gamma),\\quad
H(\\gamma)=-\\sum\_{ij}\\gamma\_{ij}(\\ln\\gamma\_{ij}-1) $$

其中：$\\varepsilon\>0$ 为正则强度；解的形式为
$\\gamma=\\operatorname{diag}(u)K\\operatorname{diag}(v)$，其中
$K\_{ij}=e^{-C\_{ij}/\\varepsilon}$；通过**交替归一化**行与列（Sinkhorn
迭代）$u=a/(Kv)$、$v=b/(K^\\top u)$ 就能求出，每步只需矩阵 – 向量乘法，见
[矩阵乘积](https://github.com/junxnone/math/issues/27)，并且易于在 GPU
上并行与自动微分。

## 与 KL 散度对比

| 对比项          | KL 散度     | Wasserstein 距离 |
| ------------ | --------- | -------------- |
| 是否对称 / 是否为距离 | 否 / 否     | 是 / 是          |
| 两分布支撑不重叠     | 无穷（或不连续）  | 仍有有限且随距离平滑变化的值 |
| 是否利用样本空间几何   | 否（逐点比较概率） | 是（搬运的代价）       |
| 计算           | 解析或简单     | 需要求解优化问题       |

表中：对比结论：分布没有重叠（如生成图像与真实图像）时，KL / JS 的梯度会消失，而 Wasserstein 距离仍能提供有意义的梯度，这是
WGAN 的动机。

## 在机器学习中的作用

  - 生成模型：Wasserstein GAN；评估指标（FID 与高斯 Wasserstein 距离相关）
  - 域适应、点云配准、颜色 / 风格迁移、重心（barycenter）与聚类
  - 图像检索与词嵌入的 Word Mover's Distance

## 常见误区

  - 离散最优传输的变量规模是 $m\\times n$，样本很多时直接求解代价高，应使用 Sinkhorn、切片 Wasserstein
    或小批量近似
  - Sinkhorn 中 $\\varepsilon$ 太小会数值不稳定（要在对数域计算），太大会使传输方案过于模糊
  - Wasserstein 距离依赖于代价（度量）的选择；换度量得到的几何不同
