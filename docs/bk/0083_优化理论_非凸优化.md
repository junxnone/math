# 非凸优化

深度学习、矩阵分解、聚类等问题的目标函数通常是非凸的：存在多个局部极小、鞍点和平坦区域。凸优化的“局部即全局”不再成立，但实践中简单的一阶方法仍然有效，理论也在逐步解释这一点。

## 非凸地形中的关键点

驻点（$\\nabla f=\\mathbf{0}$）按 Hessian 分类（见 [无约束优化](/0078_优化理论_无约束优化)）：

| 类型     | Hessian 特征值 | 特点            |
| ------ | ----------- | ------------- |
| 局部极小   | 全部 $\\ge0$  | 周围没有更低点       |
| 局部极大   | 全部 $\\le0$  | 梯度下降会远离       |
| 鞍点     | 有正有负        | 某些方向下降、某些方向上升 |
| 平坦区/高原 | 接近 $0$      | 梯度极小，进展缓慢     |

表中依次为类型、Hessian 特征值符号和特点（Hessian 见 [多元函数微分](/0054_微积分_多元函数微分)，特征值见
[特征值与特征向量](/0036_线性代数_特征值与特征向量)）。高维空间中随机的驻点绝大多数是鞍点而非局部极小，因为所有
$n$ 个特征值同号的概率随 $n$ 指数下降。

## 严格鞍点性质

若所有鞍点都是“严格鞍点”（存在负曲率方向：$\\lambda\_{\\min}(\\nabla^2f)\<0$），则带噪声的梯度法可以逃离：

$$
\\lambda\_{\\min}\\bigl(\\nabla^2f(\\mathbf{x})\\bigr)\\le-\\gamma\<0\\
\\Longrightarrow\\ \\text{扰动后沿负曲率方向下降} $$

其中 $\\gamma\>0$ 是负曲率的下界。已证明：对严格鞍点函数，加随机扰动的梯度下降（或 SGD
本身的噪声）能在多项式时间内收敛到二阶驻点（近似局部极小）。矩阵补全、相位恢复、张量分解、字典学习等问题已被证明“没有虚假局部极小，所有局部极小都是全局极小”，只有严格鞍点。

## 为什么神经网络训练有效

  - **过参数化**：参数远多于样本时，存在大量全局最优解，且从随机初始化出发的梯度法容易找到；损失曲面更“平滑”。
  - **PL 条件**（Polyak-Łojasiewicz）：$\\tfrac12\\lVert\\nabla
    f(\\mathbf{x})\\rVert^2\\ge\\mu\\bigl(f(\\mathbf{x})-f^\*\\bigr)$，其中
    $\\mu\>0$ 是常数。满足时即使非凸，梯度下降也线性收敛到全局最优；过参数化网络在一定条件下满足。
  - **平坦极小**：SGD 的噪声倾向于收敛到曲率小（平坦）的极小点，通常泛化更好。
  - 局限：这些结论多是特定条件下的，通用的非凸优化仍是 NP 难问题。

## 全局优化方法

  - **多起点（multi-start）**：从多个随机初值运行局部算法，取最好结果。简单有效，成本线性增长。
  - **模拟退火**：以概率 $\\exp(-\\Delta f/T)$ 接受变差的移动，温度 $T$ 逐渐降低，从而有机会跳出局部极小（见
    [模拟退火](/0014_优化理论_非凸优化_模拟退火进阶)）。其中 $\\Delta f$ 是目标函数的增量。
  - **进化算法/粒子群**：维护一个种群，通过选择、交叉、变异（或速度更新）搜索，无需梯度。
  - **贝叶斯优化**：用高斯过程为昂贵的黑盒函数建代理模型，用采集函数选择下一个评估点（见 [Gaussian
    Process](/0020_概率论_随机过程初步_高斯过程进阶)）。
  - **分支定界**：对低维 Lipschitz 函数给出全局最优保证，但维数增大代价指数增长。

## 凸松弛

把非凸约束或目标替换为其凸包络，得到可全局求解的下界问题：

  - 秩最小化 $\\min\\operatorname{rank}(X)\\to$ 核范数最小化 $\\min\\lVert
    X\\rVert\_\*$（见 [范数与条件数](/0045_线性代数_Matrix_范数与条件数)）
  - $L\_0$ 稀疏 $\\min\\lVert\\mathbf{x}\\rVert\_0\\to$ $L\_1$ 范数
    $\\min\\lVert\\mathbf{x}\\rVert\_1$（见 [norm](/0011_线性代数_norm)）
  - 整数规划 $\\to$ 线性规划松弛（见 [线性规划](/0080_优化理论_线性规划)）
  - 半定松弛（SDP）：把二次约束二次规划放松成半正定约束

松弛解不一定可行，常需取整或投影；在一定条件下（如 RIP 条件）松弛解恰是原问题解。

## 例

$f(x)=x^4-3x^2+x$：$f'=4x^3-6x+1$，有三个驻点（约 $x=-1.30,\\ 0.17,\\ 1.13$），其中
$f''=12x^2-6$：$x=-1.30$ 时 $f''\>0$ 为全局极小，$x=1.13$ 时 $f''\>0$
为局部极小（较高），$x=0.17$ 时 $f''\<0$ 为局部极大。从 $x\_0=2$
出发的梯度下降会落入 $x\\approx1.13$ 的局部极小，而不是全局最小，这说明初值的重要性。

  - 矩阵分解与推荐系统、聚类（$k$-means）
  - 机器人运动规划、结构设计、组合优化
