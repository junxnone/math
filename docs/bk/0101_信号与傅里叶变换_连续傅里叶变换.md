# 连续傅里叶变换

傅里叶变换把时间函数分解成各种频率的复指数之和，并告诉我们每个频率的幅度与相位。它把卷积变成乘法、微分变成乘以
$j\\omega$，使许多难题变得简单。

## 概念关系图

``` mermaid
flowchart LR
    FS[傅里叶级数 周期信号] --> FT[傅里叶变换 非周期信号]
    FT --> P[变换对 性质 线性 平移 缩放 卷积定理]
    FT --> E[帕塞瓦尔定理 能量守恒]
    FT --> U[不确定性原理 时间与频率不能同时集中]
    FT --> D[应用 频谱分析 滤波]
```

图中：傅里叶变换是傅里叶级数在周期趋于无穷时的推广；有一整套变换对与性质，帕塞瓦尔定理说明能量在两个域守恒，不确定性原理限制时间与频率的同时集中。

## 从傅里叶级数到傅里叶变换

周期为 $T$ 的信号的复指数傅里叶级数（见 [级数](/0053_微积分_级数)）：

$$ x(t)=\\sum\_{k=-\\infty}^{\\infty}c\_ke^{jk\\omega\_0t},\\qquad
c\_k=\\frac1T\\int\_0^Tx(t)e^{-jk\\omega\_0t}dt,\\qquad
\\omega\_0=\\frac{2\\pi}T $$

其中 $\\omega\_0$ 是基频，$k\\omega\_0$ 是第 $k$ 次谐波，$c\_k$ 是其复系数（$|c\_k|$
幅度、$\\arg c\_k$ 相位）。令周期 $T\\to\\infty$，谐波间隔
$\\omega\_0\\to0$，离散的谱线变成连续的频谱，求和变积分，得到傅里叶变换。

## 定义

$$
X(\\omega)=\\mathcal{F}{x}(\\omega)=\\int\_{-\\infty}^{+\\infty}x(t),e^{-j\\omega
t},dt,\\qquad
x(t)=\\frac1{2\\pi}\\int\_{-\\infty}^{+\\infty}X(\\omega),e^{j\\omega
t},d\\omega $$

其中 $\\omega$ 是角频率（rad/s）；用频率 $f$（Hz）时 $X(f)=\\int x(t)e^{-j2\\pi
ft}dt$，逆变换无需 $\\frac1{2\\pi}$。存在条件：$x$
绝对可积（或平方可积、或在广义函数意义下）。含义：$X(\\omega)$
是 $x$ 与复指数 $e^{j\\omega t}$ 的“内积”，度量 $x$ 中含有多少频率 $\\omega$
的成分，类似函数空间中向正交基的投影（见
[向量空间](/0034_线性代数_向量空间)）。

## 常见变换对

| 时域 $x(t)$                             | 频域 $X(\\omega)$                                                                           |
| ------------------------------------- | ----------------------------------------------------------------------------------------- |
| $\\delta(t)$                          | $1$                                                                                       |
| $1$                                   | $2\\pi\\delta(\\omega)$                                                                   |
| $e^{j\\omega\_0t}$                    | $2\\pi\\delta(\\omega-\\omega\_0)$                                                        |
| $\\cos\\omega\_0t$                    | $\\pi\\bigl\[\\delta(\\omega-\\omega\_0)+\\delta(\\omega+\\omega\_0)\\bigr\]$             |
| 矩形 $1$（$\\lvert t\\rvert\<T/2$）否则 $0$ | $T,\\mathrm{sinc}\\bigl(\\tfrac{\\omega T}2\\bigr)=\\dfrac{2\\sin(\\omega T/2)}{\\omega}$ |
| $e^{-at}u(t)$（$a\>0$）                 | $\\dfrac1{a+j\\omega}$                                                                    |
| $e^{-t^2/(2\\sigma^2)}$               | $\\sigma\\sqrt{2\\pi},e^{-\\sigma^2\\omega^2/2}$                                          |

表中左列是时域信号，右列是其傅里叶变换，其中 $\\mathrm{sinc}(x)=\\sin x/x$，$u(t)$ 是单位阶跃（见
[信号与线性系统](/0099_信号与傅里叶变换_信号与线性系统)）。重要观察：

  - 冲激在时域无限集中，频域均匀分布（包含所有频率）；单一频率的正弦在频域是一对冲激。
  - 时域窄 $\\Leftrightarrow$ 频域宽：矩形越窄，sinc 主瓣越宽。
  - 高斯函数的变换仍是高斯函数，宽度互为倒数。

## 基本性质

| 性质     | 时域                     | 频域                                                          |
| ------ | ---------------------- | ----------------------------------------------------------- |
| 线性     | $ax+by$                | $aX+bY$                                                     |
| 时移     | $x(t-t\_0)$            | $e^{-j\\omega t\_0}X(\\omega)$                              |
| 频移（调制） | $e^{j\\omega\_0t}x(t)$ | $X(\\omega-\\omega\_0)$                                     |
| 尺度     | $x(at)$                | $\\dfrac1{\\lvert a\\rvert}X\\bigl(\\tfrac\\omega a\\bigr)$ |
| 微分     | $x'(t)$                | $j\\omega X(\\omega)$                                       |
| 积分     | $\\int\_{-\\infty}^tx$ | $\\dfrac{X(\\omega)}{j\\omega}+\\pi X(0)\\delta(\\omega)$   |
| 卷积     | $x\*h$                 | $X\\cdot H$                                                 |
| 乘积     | $x\\cdot h$            | $\\dfrac1{2\\pi}X\*H$                                       |
| 对偶     | $X(t)$                 | $2\\pi x(-\\omega)$                                         |

表中依次为性质、时域操作和频域对应，$a,b,t\_0,\\omega\_0$ 是常数。要点：

  - **时移只改变相位、不改变幅度谱**；幅度 $|X(\\omega)|$ 对平移不变，所以频谱适合识别“有哪些成分”而不关心出现的位置。
  - **微分变乘法**：线性常系数微分方程变成代数方程，$\\sum a\_k(j\\omega)^kY=\\sum
    b\_k(j\\omega)^kX$，得 $H(j\\omega)=\\dfrac{\\sum
    b\_k(j\\omega)^k}{\\sum a\_k(j\\omega)^k}$（见
    [常微分方程](/0057_微积分_常微分方程)）。
  - **卷积定理**：见 [卷积](/0100_信号与傅里叶变换_卷积)。
  - 实信号的频谱共轭对称：$X(-\\omega)=X^\*(\\omega)$，幅度偶、相位奇；所以只需看 $\\omega\\ge0$。

## 帕塞瓦尔定理与能量谱

$$
\\int\_{-\\infty}^{+\\infty}|x(t)|^2dt=\\frac1{2\\pi}\\int\_{-\\infty}^{+\\infty}|X(\\omega)|^2d\\omega
$$

其中 $|X(\\omega)|^2$
称为能量谱密度，描述能量在频率上的分布。该式表示傅里叶变换是（缩放后）酉变换，保持内积和能量，类似正交矩阵保持长度（见
[正交矩阵](/0032_线性代数_Matrix_正交矩阵)）。

## 不确定性原理

时域扩展 $\\Delta t$ 与频域扩展 $\\Delta\\omega$（按标准差度量）满足：

$$ \\Delta t\\cdot\\Delta\\omega\\ge\\frac12 $$

其中 $\\Delta t,\\Delta\\omega$ 分别是 $|x(t)|^2$ 与 $|X(\\omega)|^2$
的标准差。含义：信号不可能同时在时间和频率上都任意集中；等号仅在高斯函数时取到。这与量子力学的海森堡不确定性原理是同一个数学事实，也是时频分析必须在时间与频率分辨率之间取舍的原因（见
[短时傅里叶与小波](/0105_信号与傅里叶变换_短时傅里叶与小波)）。

## 例：RC 低通的频率响应

$h(t)=\\dfrac1{RC}e^{-t/RC}u(t)$，由表 $H(\\omega)=\\dfrac1{1+j\\omega
RC}$，幅度 $|H|=\\dfrac1{\\sqrt{1+(\\omega RC)^2}}$。在截止频率
$\\omega\_c=1/(RC)$ 处 $|H|=1/\\sqrt2\\approx0.707$（$-3$
dB），低频通过、高频衰减，这就是低通滤波（见
[滤波器](/0104_信号与傅里叶变换_滤波器)）。若输入 $x(t)=\\cos\\omega
t$，输出稳态为 $|H(\\omega)|\\cos(\\omega t+\\arg H(\\omega))$。

## 与概率论的联系

概率密度 $f$ 的傅里叶变换就是特征函数 $\\varphi(t)=\\mathbb{E}\[e^{itX}\]$（见
[期望方差与矩](/0064_概率论_期望方差与矩)）。独立变量和的密度是卷积，特征函数是乘积；高斯变换仍是高斯，是中心极限定理证明的核心（见
[大数定律与中心极限定理](/0066_概率论_大数定律与中心极限定理)）。

## 应用

  - 频谱分析：识别信号中的频率成分（音高、机械振动故障）
  - 系统分析与滤波：在频域设计滤波器
  - 偏微分方程：热方程、波动方程的求解（分离变量/傅里叶法）
  - 成像：MRI、X 射线衍射、光学（透镜是傅里叶变换器）

## 在机器学习中的作用

  - 频域视角理解卷积与滤波：卷积 = 频域乘积，见
    [卷积](https://github.com/junxnone/math/issues/100)
  - 傅里叶特征与位置编码：把低维输入映射到高频正弦余弦特征，帮助网络拟合高频函数
  - 谱归一化、频域正则化；FNet、FFT 加速的卷积与注意力

## 常见误区

  - 傅里叶变换的约定不统一（$\\omega$ 还是 $f$，$\\tfrac1{2\\pi}$ 放在哪），使用公式前要确认
  - 频谱的幅度谱与相位谱同样重要：只保留幅度会丢失信号的时间结构
  - 时域越窄、频域越宽：不能同时让信号在时间和频率上都任意集中（不确定性原理）
