# 希尔伯特空间与核方法

希尔伯特空间是**完备的内积空间**：它把有限维向量空间中的「长度、夹角、正交、投影」推广到无穷维（如函数空间）。核方法利用**再生核希尔伯特空间（RKHS）**，把数据隐式映射到高维特征空间，在不显式计算特征的情况下完成线性方法。基础见
[向量空间](https://github.com/junxnone/math/issues/34)，内积与正交基见
[向量](https://github.com/junxnone/math/issues/2)。

## 概念关系图

``` mermaid
flowchart LR
    V[向量空间] --> I[内积空间 内积 范数 正交]
    I --> H[希尔伯特空间 完备]
    H --> P[投影定理 正交基展开]
    H --> R[再生核希尔伯特空间 RKHS]
    R --> K[核函数 k x y = phi x 内积 phi y]
    K --> M[核方法 SVM 核岭回归 高斯过程]
```

图中：内积空间加上完备性得到希尔伯特空间；其中一类函数空间配有「再生核」（RKHS），核函数等于特征映射的内积，使线性算法可以通过核函数处理非线性问题。

## 内积空间与希尔伯特空间

内积 $\\langle\\cdot,\\cdot\\rangle$ 满足对称性、线性性与正定性；由它定义范数与距离：

$$ \\lVert x\\rVert=\\sqrt{\\langle x,x\\rangle},\\qquad d(x,y)=\\lVert
x-y\\rVert,\\qquad \\lvert\\langle x,y\\rangle\\rvert\\le\\lVert
x\\rVert\\lVert y\\rVert $$

其中：最后一个是 Cauchy–Schwarz
不等式。**完备性**指空间中任何柯西列都收敛到空间内的点；有限维内积空间自动完备，无穷维则不一定。典型例子：

| 空间                | 元素     | 内积                      |
| ----------------- | ------ | ----------------------- |
| $\\mathbb{R}^{n}$ | 向量     | $x^\\top y$             |
| $\\ell^{2}$       | 平方可和序列 | $\\sum\_ix\_iy\_i$      |
| $L^{2}\[a,b\]$    | 平方可积函数 | $\\int\_a^bf(t)g(t),dt$ |

表中：对比结论：函数空间 $L^2$ 中的「向量」是函数，傅里叶级数就是函数在正交基 ${\\sin,\\cos}$ 上的展开，见
[级数](https://github.com/junxnone/math/issues/53)、[连续傅里叶变换](https://github.com/junxnone/math/issues/101)。

## 投影定理与正交基

对希尔伯特空间 $\\mathcal{H}$ 的闭子空间 $\\mathcal{M}$，任意 $x$ 存在唯一的最佳逼近
$P\_{\\mathcal{M}}x\\in\\mathcal{M}$，且残差
$x-P\_{\\mathcal{M}}x\\perp\\mathcal{M}$。若 ${e\_k}$ 是标准正交基：

$$ x=\\sum\_{k}\\langle x,e\_k\\rangle,e\_k,\\qquad \\lVert
x\\rVert^{2}=\\sum\_{k}\\lvert\\langle x,e\_k\\rangle\\rvert^{2}\\ \\
(\\text{帕塞瓦尔}) $$

其中：系数 $\\langle x,e\_k\\rangle$ 就是在各基向量上的投影长度，这是最小二乘（见
[投影](https://github.com/junxnone/math/issues/42)）和傅里叶分析的共同几何本质。

## 再生核希尔伯特空间（RKHS）

核函数 $k(x,y)$ 若对任意点集生成的核矩阵都对称半正定，则存在一个特征映射 $\\phi$ 使

$$ k(x,y)=\\langle\\phi(x),\\phi(y)\\rangle\_{\\mathcal{H}},\\qquad
f(x)=\\langle f,,k(x,\\cdot)\\rangle\_{\\mathcal{H}}\\ \\ (\\text{再生性})
$$

其中：$\\phi$ 把输入映射到（可能无穷维的）特征空间 $\\mathcal{H}$；再生性说明「求函数在某点的值」等于与
$k(x,\\cdot)$ 做内积。常见核函数：

| 核          | 表达式                                         | 对应特征空间         |
| ---------- | ------------------------------------------- | -------------- |
| 线性核        | $x^\\top y$                                 | 原空间            |
| 多项式核       | $(x^\\top y+c)^{d}$                         | 阶数不超过 $d$ 的单项式 |
| 高斯 / RBF 核 | $\\exp(-\\lVert x-y\\rVert^{2}/2\\ell^{2})$ | 无穷维            |

表中：对比结论：核技巧让我们只需计算 $k(x,y)$，而不用显式写出（可能无穷维的）$\\phi$。

## 表示定理与核方法

对形如 $\\min\_{f\\in\\mathcal{H}}\\
\\sum\_i\\ell(y\_i,f(x\_i))+\\lambda\\lVert
f\\rVert\_{\\mathcal{H}}^{2}$ 的正则化问题，最优解可以写成

$$ f^{\*}(x)=\\sum\_{i=1}^{n}\\alpha\_i,k(x\_i,x) $$

其中：$\\alpha\_i$ 是系数；无穷维的优化问题化为有限的 $n$ 个系数的问题。对应的方法包括核岭回归、支持向量机（见
[支持向量机](https://github.com/junxnone/math/issues/150)）和高斯过程（见
[高斯过程进阶](https://github.com/junxnone/math/issues/20)）。

## 在机器学习中的作用

  - 核方法：SVM、核岭回归、核 PCA，用核技巧处理非线性
  - 高斯过程的协方差函数就是核；神经正切核把宽神经网络的训练对应到核方法
  - 最大均值差异（MMD）用 RKHS 距离比较两个分布，用于生成模型评估

## 常见误区

  - 并非任意相似度函数都是核：必须使核矩阵半正定（Mercer 条件）
  - 核方法计算涉及 $n\\times n$ 核矩阵，样本很多时代价大（$O(n^2)$ 存储，$O(n^3)$
    求解），需要近似（Nyström、随机特征）
  - 完备性在有限维下自动成立，不要把「希尔伯特空间」等同于「必须是无穷维」
