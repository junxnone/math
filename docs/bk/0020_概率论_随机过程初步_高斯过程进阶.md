# 高斯过程进阶

## 基础知识

  - [随机过程进阶](https://github.com/junxnone/math/issues/13)

  - [高斯分布进阶](https://github.com/junxnone/math/issues/5)

  - 高斯过程：符合高斯分布的变量的集合

  - GP 是特殊**随机过程**：任意有限个变量的联合分布都是多元高斯分布

  - GP 即「函数上的高斯分布」：用它作为函数的先验，再用数据更新为后验

  - 本文是 [随机过程初步](https://github.com/junxnone/math/issues/67)
    的进阶：高斯过程的定义、核函数、回归（GPR）的后验公式、超参数学习与计算复杂度。

## 定义

$$ f(\\mathbf{x})\\sim\\mathcal{GP}\\bigl(m(\\mathbf{x}),\\
k(\\mathbf{x},\\mathbf{x}')\\bigr) $$

其中：

  - **均值函数** $m(\\mathbf{x})=\\mathbb{E}\[f(\\mathbf{x})\]$：函数在
    $\\mathbf{x}$ 处的期望，常取 0
  - **核函数 / 协方差函数**
    $k(\\mathbf{x},\\mathbf{x}')=\\mathrm{Cov}\\bigl(f(\\mathbf{x}),f(\\mathbf{x}')\\bigr)$：描述任意两个输入点处函数值的相关性
  - 对任意有限个输入点 $X={\\mathbf{x}\_1,\\dots,\\mathbf{x}\_n}$，函数值向量服从多元高斯分布：

$$
\\mathbf{f}=\\bigl(f(\\mathbf{x}\_1),\\dots,f(\\mathbf{x}*n)\\bigr)^{\\top}\\sim\\mathcal{N}\\bigl(\\mathbf{m},\\
K\\bigr),\\qquad K*{ij}=k(\\mathbf{x}\_i,\\mathbf{x}\_j) $$

其中：$\\mathbf{m}$ 为均值向量；$K$ 称为核矩阵（Gram 矩阵），必须对称半正定，见
[对称正定与二次型](https://github.com/junxnone/math/issues/41)。

> **随机过程** - 确定性过程研究一个量随时间确定的变化，而随机过程描述的是一个量随时间可能的变化

## 核函数/协方差函数

  - 用于生成协方差矩阵, 衡量任意两个点之间的`距离`（相似度）
  - 平稳核函数 - RBF/周期：只依赖 $\\mathbf{x}-\\mathbf{x}'$
  - 非平稳核函数 - 线性

| 核函数                                              | 公式                                                                                                                                                                                    |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 常量<br>Constant                                   | $k(x,x')=c$                                                                                                                                                                           |
| 线性<br>Linear                                     | $k(x,x')=\\sigma\_b^{2}+\\sigma\_v^{2}(x-c)(x'-c)$                                                                                                                                    |
| 高斯噪声<br>Gaussian noise                           | $k(x,x')=\\sigma\_n^{2},\\delta\_{xx'}$                                                                                                                                               |
| 平方指数<br>SE-Squared exponential                   | $k(x,x')=\\sigma^{2}\\exp\!\\Bigl(-\\dfrac{(x-x')^{2}}{2\\ell^{2}}\\Bigr)$                                                                                                            |
| Ornstein–Uhlenbeck                               | $k(x,x')=\\sigma^{2}\\exp\!\\Bigl(-\\dfrac{\\lvert x-x'\\rvert}{\\ell}\\Bigr)$                                                                                                        |
| 马顿核<br>Matérn                                    | $k(r)=\\sigma^{2}\\dfrac{2^{1-\\nu}}{\\Gamma(\\nu)}\\Bigl(\\dfrac{\\sqrt{2\\nu},r}{\\ell}\\Bigr)^{\\nu}K\_\\nu\\Bigl(\\dfrac{\\sqrt{2\\nu},r}{\\ell}\\Bigr),\\ r=\\lvert x-x'\\rvert$ |
| 周期<br>Periodic                                   | $k(x,x')=\\sigma^{2}\\exp\!\\Bigl(-\\dfrac{2\\sin^{2}(\\pi\\lvert x-x'\\rvert/p)}{\\ell^{2}}\\Bigr)$                                                                                  |
| 有理二次方<br>Rational quadratic                      | $k(x,x')=\\sigma^{2}\\Bigl(1+\\dfrac{(x-x')^{2}}{2\\alpha\\ell^{2}}\\Bigr)^{-\\alpha}$                                                                                                |
| 高斯核/径向基函数<br>Gaussian/RBF(Radial Basis Function) | $k(\\mathbf{x},\\mathbf{x}')=\\exp\!\\Bigl(-\\dfrac{\\lVert\\mathbf{x}-\\mathbf{x}'\\rVert^{2}}{2\\ell^{2}}\\Bigr)$（与平方指数核相同）                                                         |

其中：

  - $\\ell$：长度尺度，控制函数「多快变化」，$\\ell$ 越大函数越平滑；$\\sigma^2$：信号方差，控制函数取值的幅度
  - $p$：周期；$\\nu$：Matérn 核的光滑度参数；$\\alpha$：有理二次核的尺度混合参数
  - 对比结论：SE 核给出无限光滑的函数；Matérn 核（$\\nu$ 小）给出更粗糙、更贴近真实物理过程的函数；周期核用于周期数据
  - 核之间可以相加（叠加成分）或相乘（交互成分），组合出更丰富的先验

## GPR - Gaussian Process Regression

  - **Regression Analysis/回归分析** - 分析变量之间的相关性/相关方向/强度，建立模型预测变量
  - 用高斯过程作为先验, 学习函数

**Pipeline**

``` mermaid
flowchart LR
    P[高斯过程先验 f ~ GP] --> L[观测 y = f + 噪声]
    L --> J[训练输入与测试输入的联合高斯]
    J --> C[用高斯条件公式得到后验]
    C --> O[预测均值和方差]
```

图中：把训练点和测试点的函数值看作一个联合高斯，已知训练点的观测值后，测试点的分布就是条件高斯，无需额外近似，见
[高斯分布进阶](https://github.com/junxnone/math/issues/5) 的条件分布公式。

模型：$y=f(\\mathbf{x})+\\varepsilon$，$\\varepsilon\\sim\\mathcal{N}(0,\\sigma\_n^{2})$。训练输入
$X$、观测 $\\mathbf{y}$，测试输入 $X\_\*$。联合分布：

$$
\\begin{bmatrix}\\mathbf{y}\\\\mathbf{f}*\*\\end{bmatrix}\\sim\\mathcal{N}\\Bigl(\\mathbf{0},\\begin{bmatrix}K(X,X)+\\sigma\_n^{2}I\&K(X,X**)\\K(X\_*,X)\&K(X\_*,X\_*)\\end{bmatrix}\\Bigr)
$$

其中：$K(X,X\_\*)$ 为训练点与测试点之间的核矩阵，其余同理。由条件高斯公式，预测后验为：

$$
\\bar{\\mathbf{f}}*\*=K(X**,X)\\bigl\[K(X,X)+\\sigma\_n^{2}I\\bigr\]^{-1}\\mathbf{y},\\qquad
\\mathrm{Cov}(\\mathbf{f}\_*)=K(X\_*,X\_*)-K(X\_*,X)\\bigl\[K(X,X)+\\sigma\_n^{2}I\\bigr\]^{-1}K(X,X\_*)
$$

其中：

  - $\\bar{\\mathbf{f}}\_\*$：预测均值，是训练观测值的**线性组合**，权重由核函数决定
  - $\\mathrm{Cov}(\\mathbf{f}\_\*)$：预测协方差，对角线给出每个测试点的预测**不确定性**（方差）；离训练点越远，方差越大，回到先验
  - 减号后面一项是「观测带来的信息」，使不确定性只会减小

## 超参数学习

核的超参数 $\\boldsymbol\\theta=(\\ell,\\sigma,\\sigma\_n,\\dots)$
通过最大化**对数边缘似然**确定：

$$ \\log p(\\mathbf{y}\\mid
X,\\boldsymbol\\theta)=-\\tfrac12\\mathbf{y}^{\\top}K\_y^{-1}\\mathbf{y}-\\tfrac12\\log\\lvert
K\_y\\rvert-\\tfrac n2\\log2\\pi,\\qquad K\_y=K+\\sigma\_n^{2}I $$

其中：第一项衡量数据拟合程度，第二项是对模型复杂度的惩罚（行列式越大模型越复杂），第三项为常数；两项自然地平衡了拟合与复杂度，相当于内置的奥卡姆剃刀，见
[贝叶斯推断进阶](https://github.com/junxnone/math/issues/8) 中的证据。

## 计算复杂度

  - 需要对 $n\\times n$ 矩阵求逆（通常用 Cholesky 分解，见
    [矩阵分解](https://github.com/junxnone/math/issues/40)），时间
    $O(n^{3})$，空间 $O(n^{2})$
  - 因此原生 GP 适合样本数在几千以内；更大规模用稀疏近似（诱导点）、结构化核或随机特征

## GPC - Gaussian Process Classification

  - 把高斯过程的输出 $f$ 经过 sigmoid / probit
    等链接函数得到类别概率，似然不再是高斯，后验没有闭式解，需要拉普拉斯近似、期望传播（EP）或变分推断

## 联系

| 视角   | 说明                                                                                                                                                    |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 权重空间 | 贝叶斯线性回归 $f=\\boldsymbol\\phi(\\mathbf{x})^\\top\\mathbf{w}$，$\\mathbf{w}$ 取高斯先验，得到核 $k=\\boldsymbol\\phi^\\top\\Sigma\_w\\boldsymbol\\phi$；核函数对应无限维特征 |
| 函数空间 | 直接在函数上放先验，由核决定函数的光滑性                                                                                                                                  |
| 核方法  | GPR 的均值与核岭回归、SVM 使用的核函数相同                                                                                                                             |

表中：对比结论：GP 可以看作「无限宽的单隐层神经网络」（在适当极限下），也是贝叶斯线性回归的非参数推广。

## 在机器学习中的作用

  - 小样本回归与不确定性估计
  - 贝叶斯优化：用 GP 做代理模型，用采集函数选下一点
  - 插值与时空建模（克里金法 kriging），见
    [插值与拟合](https://github.com/junxnone/math/issues/110)

## 常见误区

  - 先验均值取 0 并不表示预测均值是 0；预测均值由数据决定
  - 核函数的选择比算法本身更重要，选错核（如对非平稳数据用平稳核）会严重影响效果
  - 预测方差反映的是模型的不确定性，在核假设错误时可能过于自信
