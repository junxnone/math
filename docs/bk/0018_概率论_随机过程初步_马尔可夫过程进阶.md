# 马尔可夫过程进阶

  - 在概率论及统计学中，马可夫过程（英语：Markov process）是一个具备了马可夫性质的随机过程，因为俄国数学家安德雷·马可夫得名
  - 不具备记忆特质，仅与系统当前状态相关
  - 具备离散状态的马尔可夫过程称为 **马尔可夫链**
  - 本文是 [随机过程初步](https://github.com/junxnone/math/issues/67)
    中马尔可夫链的进阶：状态分类、极限与平稳分布、细致平衡、连续时间马尔可夫链、隐马尔可夫模型与马尔可夫决策过程。

## 马尔可夫性与转移矩阵

$$ P(X\_{n+1}=j\\mid X\_n=i,\\ X\_{n-1},\\dots,X\_0)=P(X\_{n+1}=j\\mid
X\_n=i)=p\_{ij} $$

其中：$p\_{ij}$ 为从状态 $i$ 一步转移到状态 $j$ 的概率；所有 $p\_{ij}$ 构成**转移矩阵**
$P$，每行元素之和为 1（行随机矩阵）。

$n$ 步转移概率由 Chapman–Kolmogorov 方程给出：

$$ P^{(n+m)}=P^{(n)}P^{(m)}\\ \\Longrightarrow\\ P^{(n)}=P^{n} $$

其中：$P^{(n)}\_{ij}$ 是 $n$ 步从 $i$ 到 $j$ 的概率；$n$ 步转移矩阵就是转移矩阵的 $n$ 次幂，见
[矩阵乘积](https://github.com/junxnone/math/issues/27)。若初始分布为行向量
$\\pi^{(0)}$，则 $\\pi^{(n)}=\\pi^{(0)}P^{n}$。

## 状态分类

``` mermaid
flowchart LR
    S[状态] --> T[暂态 以正概率永不返回]
    S --> R[常返态 以概率 1 返回]
    R --> PR[正常返 平均返回时间有限]
    R --> NR[零常返 平均返回时间无限]
    PR --> PE[周期 d 大于 1]
    PR --> AP[非周期]
```

图中：状态按「是否一定会回来」分成暂态与常返态；常返态再按平均返回时间、周期性细分。

| 概念      | 含义                                                  |
| ------- | --------------------------------------------------- |
| 可达 / 互通 | $i\\to j$ 可达：存在 $n$ 使 $p^{(n)}\_{ij}\>0$；互相可达称为互通   |
| 不可约     | 所有状态两两互通，即只有一个互通类                                   |
| 周期      | 状态 $i$ 的周期 $d=\\gcd{n:p^{(n)}\_{ii}\>0}$；$d=1$ 称非周期 |
| 吸收态     | $p\_{ii}=1$，一旦进入就不会离开                               |

表中：对比结论：不可约、非周期、正常返的链称为**遍历链（ergodic）**，是下一节收敛定理的条件。

## 平稳分布与收敛

平稳分布 $\\pi$ 满足：

$$ \\pi=\\pi P,\\qquad \\sum\_i\\pi\_i=1,\\ \\pi\_i\\ge0 $$

其中：$\\pi$ 是行向量；它是转移矩阵关于特征值 1 的**左特征向量**（归一化后），见
[特征值与特征向量](https://github.com/junxnone/math/issues/36)。若初始分布取
$\\pi$，则每一步的分布都保持为 $\\pi$。

**遍历定理**：对有限状态、不可约、非周期的马尔可夫链：

  - 平稳分布 $\\pi$ 存在且唯一，且所有 $\\pi\_i\>0$
  - 无论从哪个状态出发，$P^{n}\_{ij}\\to\\pi\_j$（$n\\to\\infty$）
  - 时间平均收敛于 $\\pi$：状态 $j$ 被访问的长期频率为 $\\pi\_j$

收敛速度由 $P$ 的**第二大特征值模** $\\lvert\\lambda\_2\\rvert$
决定：$\\lvert\\lambda\_2\\rvert$ 越小，收敛越快（谱间隙
$1-\\lvert\\lambda\_2\\rvert$ 越大）。

## 细致平衡

若存在分布 $\\pi$ 使得对所有 $i,j$：

$$ \\pi\_i,p\_{ij}=\\pi\_j,p\_{ji} $$

其中：左边是「在平稳状态下从 $i$ 流向 $j$」的概率流，右边是反方向的流；两者相等称为**细致平衡**。满足它的 $\\pi$
一定是平稳分布，这样的链称为**可逆链**。细致平衡是构造 MCMC（Metropolis–Hastings
算法）的关键：设计转移概率使目标分布满足细致平衡，链就会收敛到目标分布。

## 吸收链

含吸收态的链，把转移矩阵写成分块形式：

$$ P=\\begin{bmatrix}Q\&R\\0\&I\\end{bmatrix} $$

其中：$Q$ 是暂态之间的转移，$R$ 是暂态到吸收态的转移，$I$ 对应吸收态本身。**基本矩阵** $N=(I-Q)^{-1}$ 的元素
$N\_{ij}$ 是从暂态 $i$ 出发访问暂态 $j$ 的期望次数；$N\\mathbf{1}$ 给出被吸收前的期望步数；$B=NR$
给出最终被各吸收态吸收的概率，见
[矩阵的逆](https://github.com/junxnone/math/issues/31)。

## 连续时间马尔可夫链

状态在连续时间里跳转，由**速率矩阵（生成元）** $Q$ 描述：

$$ \\frac{d}{dt}P(t)=P(t),Q,\\qquad P(t)=e^{tQ} $$

其中：$Q\_{ij}\\ (i\\ne j)$ 是从 $i$ 跳到 $j$ 的速率，$Q\_{ii}=-\\sum\_{j\\ne
i}Q\_{ij}$；停留时间服从指数分布；泊松过程、排队模型（M/M/1）是典型例子。

## 隐马尔可夫模型（HMM）

状态序列 $z\_1,\\dots,z\_T$ 是马尔可夫链但**不可观测**，只能观察到由状态产生的输出 $x\_t$：

$$ p(x\_{1:T},z\_{1:T})=p(z\_1),p(x\_1\\mid
z\_1)\\prod\_{t=2}^{T}p(z\_t\\mid z\_{t-1}),p(x\_t\\mid z\_t) $$

其中：$p(z\_t\\mid z\_{t-1})$ 为转移概率，$p(x\_t\\mid z\_t)$ 为发射概率。三类经典问题：

| 问题           | 算法             | 说明                 |
| ------------ | -------------- | ------------------ |
| 评估：观察序列的概率   | 前向算法           | 动态规划，复杂度 $O(TN^2)$ |
| 解码：最可能的隐状态序列 | Viterbi 算法     | 动态规划取最大            |
| 学习：估计参数      | Baum–Welch（EM） | 迭代最大化似然            |

表中：$N$ 为隐状态数，$T$ 为序列长度；对比结论：三个问题都靠动态规划避免枚举 $N^T$ 条路径，见
[动态规划进阶](https://github.com/junxnone/math/issues/10)。

## 马尔可夫决策过程（MDP）

在马尔可夫链上加入**动作**和**奖励**，转移依赖于动作：$p(s'\\mid s,a)$，目标是找到使累计折扣奖励最大的策略
$\\pi$。MDP 是强化学习的数学基础；Bellman 方程把长期回报分解成「即时奖励 + 下一步的价值」。

## History

  - 1906 马尔可夫链
  - 1953 马尔可夫蒙特卡洛 (MCMC)
  - 1957 马尔可夫决策过程
  - 1966 HMM - `Hidden Markov Model` 隐马尔可夫模型
  - 1975\~ HMM 用于语音识别/DNA 分析
  - 1980 马尔可夫随机场
  - 1988 马尔可夫毯
  - 1991 POMDP
  - 2017 GibbsNet

## 在机器学习中的作用

  - 语言模型：$n$-gram 是马尔可夫假设；HMM 用于语音识别、词性标注
  - MCMC 采样：用链的平稳分布作为目标分布
  - PageRank：随机游走的平稳分布，见
    [谱图论](https://github.com/junxnone/math/issues/124)
  - 强化学习：MDP

## 常见误区

  - 马尔可夫性是「给定现在，未来与过去独立」，并不意味着状态之间互相独立
  - 平稳分布不一定唯一，也不一定被收敛到（可约或有周期的链）
  - 把高阶依赖放进状态定义里，高阶马尔可夫链也可以化为一阶（状态扩展）
