# 假设检验

假设检验用样本数据判断“关于总体的一个断言是否可信”。它把科学问题转化成一个概率问题：如果原假设成立，观察到当前（或更极端）数据的概率有多大？

## 基本概念

  - **原假设 $H\_0$**：默认成立、希望检验是否有足够证据推翻的断言（如“新药无效”：$\\mu=\\mu\_0$）。
  - **备择假设 $H\_1$**：与 $H\_0$ 对立（双侧 $\\mu\\ne\\mu\_0$，单侧
    $\\mu\>\\mu\_0$）。
  - **检验统计量**：在 $H\_0$ 下分布已知的样本函数。
  - **拒绝域**：使我们拒绝 $H\_0$ 的统计量取值范围。

## 两类错误与功效

| 真实情况 \\ 决策 | 不拒绝 $H\_0$            | 拒绝 $H\_0$              |
| ---------- | --------------------- | ---------------------- |
| $H\_0$ 为真  | 正确                    | 第一类错误（弃真），概率 $\\alpha$ |
| $H\_1$ 为真  | 第二类错误（取伪），概率 $\\beta$ | 正确，概率 $1-\\beta$（功效）   |

表中行是真实情况，列是检验决策，格子是对应结果。其中：

$$ \\alpha=P(\\text{拒绝 }H\_0\\mid H\_0\\text{ 真}),\\qquad
\\text{功效}=1-\\beta=P(\\text{拒绝 }H\_0\\mid H\_1\\text{ 真}) $$

$\\alpha$ 是显著性水平（常取 $0.05$），事先设定。样本量固定时 $\\alpha$ 与 $\\beta$
此消彼长；增大样本量、增大效应量可以提高功效。

## $p$ 值

$$ p=P\\bigl(\\text{统计量至少与观察值一样极端}\\mid H\_0\\bigr) $$

其中“极端”的方向由 $H\_1$ 决定。决策规则：$p\\le\\alpha$ 则拒绝 $H\_0$。注意：

  - $p$ 值**不是** $H\_0$ 为真的概率，也不是效应大小；它只衡量数据与 $H\_0$ 的不相容程度。
  - “不显著”不等于“证明了 $H\_0$”，可能只是样本太小、功效不足。
  - 统计显著不等于实际显著：样本量很大时微小的差异也能 $p\<0.05$，应同时报告效应量和置信区间（见
    [区间估计](/0071_数理统计_区间估计)）。

## $z$ 检验与 $t$ 检验

**单样本均值**（$H\_0:\\mu=\\mu\_0$）：

$$ z=\\frac{\\bar X-\\mu\_0}{\\sigma/\\sqrt
n}\\sim\\mathcal{N}(0,1),\\qquad t=\\frac{\\bar X-\\mu\_0}{S/\\sqrt
n}\\sim t(n-1) $$

其中 $\\sigma$ 已知用 $z$，未知用 $t$（统计量的分布来自 [抽样与统计量](/0069_数理统计_抽样与统计量)）。

例：$n=36$，$\\bar x=52$，$\\mu\_0=50$，$\\sigma=6$：$z=\\dfrac{2}{6/6}=2$，双侧
$p=2(1-\\Phi(2))\\approx0.0455\<0.05$，拒绝 $H\_0$。

**两样本均值**（Welch $t$ 检验）：$t=\\dfrac{\\bar X\_1-\\bar
X\_2}{\\sqrt{S\_1^2/n\_1+S\_2^2/n\_2}}$；配对数据先求差值再做单样本检验。

## 卡方检验

**拟合优度**（数据是否符合某分布）：

$$ \\chi^2=\\sum\_{i=1}^k\\frac{(O\_i-E\_i)^2}{E\_i}\\
\\overset{H\_0}{\\sim}\\ \\chi^2(k-1-m) $$

其中 $O\_i$ 是第 $i$ 类的观测频数，$E\_i$ 是 $H\_0$ 下的期望频数，$k$ 是类别数，$m$
是从数据中估计的参数个数。**独立性检验**（列联表）自由度为
$(r-1)(c-1)$。例：骰子掷 60 次，各点
$O\_i=(8,12,9,11,10,10)$，$E\_i=10$：$\\chi^2=(4+4+1+1+0+0)/10=1.0$，自由度
5，远小于临界值 $11.07$，没有证据说明骰子不均匀。

## 检验方法的选择

``` mermaid

    C -- "1 组" --> D["z / t 检验"]
    C -- "2 组" --> E["Welch t / 配对 t"]
    C -- "≥3 组" --> F["ANOVA（F 检验）"]
    B -- 否 --> G{"分类数据？"}
    G -- 是 --> H["卡方检验 / Fisher 精确检验"]

```

图中：

  - 菱形是判断，矩形是推荐的检验，自上而下阅读。
  - 连续数据按比较的组数选 $t$ 检验或 ANOVA；分类数据用卡方；正态假设不成立时改用秩检验（见
    [重采样与非参数方法](/0075_数理统计_重采样与非参数方法)）。

## 多重比较

同时做 $m$ 次检验，至少出现一次假阳性的概率可高达 $1-(1-\\alpha)^m$（$m=20$ 时约 $64%$）。校正：

  - 邦费罗尼：每次用 $\\alpha/m$；
  - 控制错误发现率（FDR，Benjamini–Hochberg）：更适用于基因组学等大规模检验。

## 奈曼-皮尔逊引理

对简单假设 $H\_0:\\theta\_0$ 与 $H\_1:\\theta\_1$，在显著性水平 $\\alpha$
下最大功效的检验是似然比检验：

$$ \\Lambda(x)=\\frac{L(\\theta\_1;x)}{L(\\theta\_0;x)}\>c $$

其中 $L$ 是似然函数（见 [点估计](/0070_数理统计_点估计)），临界值 $c$ 由 $\\alpha$
确定。大多数常用检验都是似然比检验的特例。

## 应用

  - A/B 测试：转化率差异是否显著（比例的 $z$ 检验）
  - 临床试验：新药疗效、样本量与功效设计
  - 机器学习：模型之间性能差异的显著性检验、特征选择

## 在机器学习中的作用

  - A/B 测试：比较两种模型 / 策略的指标差异是否显著
  - 模型比较：配对 $t$ 检验、McNemar 检验、置换检验，见
    [重采样与非参数方法](https://github.com/junxnone/math/issues/75)
  - 特征选择：卡方检验、方差分析筛选与目标相关的特征

## 常见误区

  - $p$ 值**不是**「原假设为真的概率」，而是「在原假设为真时，出现至少这么极端数据的概率」
  - 「不拒绝原假设」不等于「接受原假设」，可能只是样本量太小、功效不足
  - 统计显著不等于实际重要：样本量很大时，极小的差异也能显著；要同时看效应大小
  - 多次检验会使假阳性累积，需要做多重比较校正（Bonferroni、FDR）
