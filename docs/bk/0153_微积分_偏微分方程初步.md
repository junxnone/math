# 偏微分方程初步

偏微分方程（PDE）含有未知**多元函数**及其偏导数，描述随空间与时间同时变化的现象：热传导、波动、扩散、流体。常微分方程见
[常微分方程](https://github.com/junxnone/math/issues/57)，多元微分与场论见
[多元函数微分](https://github.com/junxnone/math/issues/54)、[曲线曲面积分与场论](https://github.com/junxnone/math/issues/56)。

## 概念关系图

``` mermaid
flowchart LR
    P[偏微分方程 PDE] --> C[分类 椭圆 抛物 双曲]
    C --> E[椭圆型 拉普拉斯 泊松 稳态]
    C --> Pa[抛物型 热方程 扩散]
    C --> H[双曲型 波动方程 传播]
    P --> B[定解条件 初值 边值]
    P --> M[求解 分离变量 傅里叶级数 数值方法]
    Pa --> D[与扩散模型 随机过程联系]
```

图中：PDE 按二阶线性方程的判别式分为椭圆、抛物、双曲三类，分别对应稳态、扩散、波动；需要初值 /
边值条件才能得到唯一解；常用分离变量与傅里叶级数求解，数值上用差分或有限元；抛物型方程与随机过程（扩散）紧密相关。

## 基本概念

  - **阶数**：方程中最高偏导数的阶；**线性**：未知函数及其导数线性出现
  - **定解条件**：初值条件（$t=0$
    时的函数值）与边值条件（Dirichlet：边界上函数值；Neumann：边界上法向导数；Robin：二者的线性组合）
  - **适定性（Hadamard）**：解存在、唯一，且连续依赖于数据

## 三个经典方程

| 方程      | 形式                                | 类型 | 物理意义                    |
| ------- | --------------------------------- | -- | ----------------------- |
| 热（扩散）方程 | $u\_t=\\kappa,\\Delta u$          | 抛物 | 热传导、扩散，使分布趋于平滑          |
| 波动方程    | $u\_{tt}=c^{2}\\Delta u$          | 双曲 | 弦 / 声波 / 电磁波，以速度 $c$ 传播 |
| 拉普拉斯方程  | $\\Delta u=0$（泊松方程：$\\Delta u=f$） | 椭圆 | 稳态温度、静电势、无旋无源场          |

表中：$u$ 为未知函数，$\\kappa$ 为扩散系数，$c$
为波速，$\\Delta=\\sum\_i\\partial^2/\\partial x\_i^2$
为拉普拉斯算子；对比结论：时间一阶（抛物）是扩散与平滑，二阶（双曲）是传播与振荡，无时间（椭圆）是平衡。

## 分离变量法

以一维热方程 $u\_t=\\kappa u\_{xx}$（$0\<x\<L$，端点为 0，初值
$u(x,0)=\\varphi(x)$）为例，设 $u(x,t)=X(x)T(t)$，得到
$X''/X=T'/(\\kappa T)=-\\lambda$。边界条件给出特征值与特征函数：

$$ X\_n(x)=\\sin\\frac{n\\pi x}{L},\\ \\
\\lambda\_n=\\Bigl(\\frac{n\\pi}{L}\\Bigr)^{2};\\qquad
u(x,t)=\\sum\_{n=1}^{\\infty}b\_n,e^{-\\kappa\\lambda\_nt}\\sin\\frac{n\\pi
x}{L} $$

其中：系数 $b\_n$ 由初值 $\\varphi$ 的**傅里叶正弦级数**确定，见
[级数](https://github.com/junxnone/math/issues/53)；每个模态随时间按
$e^{-\\kappa\\lambda\_nt}$ 衰减，**高频衰减更快**，所以热方程使解变得光滑。

## 热方程的基本解

无界空间中热方程的基本解是高斯核：

$$ G(x,t)=\\frac{1}{(4\\pi\\kappa t)^{d/2}}\\exp\\Bigl(-\\frac{\\lVert
x\\rVert^{2}}{4\\kappa t}\\Bigr),\\qquad u(x,t)=(G\_t\*\\varphi)(x) $$

其中：$d$ 为空间维数；解是初值与高斯核的卷积（见
[卷积](https://github.com/junxnone/math/issues/100)），标准差
$\\sqrt{2\\kappa t}$ 随时间增大——这就是**高斯滤波器**：图像高斯平滑等价于对图像求解一段时间的热方程，见
[高斯滤波器进阶](https://github.com/junxnone/math/issues/21)。

## 数值方法

  - **有限差分**：用差商代替导数，如 $u\_t\\approx\\frac{u\_i^{n+1}-u\_i^n}{\\Delta
    t}$，显式格式有稳定性条件（CFL / 扩散数 $\\kappa\\Delta t/\\Delta
    x^2\\le\\tfrac12$），见
    [常微分方程数值解](https://github.com/junxnone/math/issues/112)
  - **有限元 / 谱方法**：用基函数展开，转化为线性方程组，见
    [线性方程组的数值解法](https://github.com/junxnone/math/issues/109)
  - **神经网络求解器**：物理信息神经网络（PINN）把 PDE 残差放进损失函数

## 在机器学习中的作用

  - 扩散模型：前向加噪过程与热方程 / Fokker–Planck 方程对应，见
    [布朗运动与伊藤积分](https://github.com/junxnone/math/issues/141)
  - 图像处理：各向异性扩散（Perona–Malik）去噪、变分与水平集方法；图拉普拉斯平滑，见
    [谱图论](https://github.com/junxnone/math/issues/124)
  - 科学机器学习：PINN、神经算子（傅里叶神经算子）学习 PDE 的解算子

## 常见误区

  - 方程类型（椭圆 / 抛物 / 双曲）决定适合的条件和方法：不能给椭圆方程只给初值，也不能把双曲方程当作扩散处理
  - 边界条件不同，解完全不同；齐次与非齐次边界要分别处理（叠加原理）
  - 显式差分格式在步长不满足稳定性条件时会发散，不是步长越小误差越小就一定稳定（还有舍入）
