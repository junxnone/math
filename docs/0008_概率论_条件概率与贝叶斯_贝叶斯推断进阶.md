# 贝叶斯推断进阶

- 本文是 [条件概率与贝叶斯](https://github.com/junxnone/math/issues/61) 的进阶：把贝叶斯公式用于**参数推断**，讲清先验、似然、后验、证据，以及与最大似然（MLE）和最大后验（MAP）的关系；更系统的内容见 [贝叶斯统计](https://github.com/junxnone/math/issues/74)。

## 概念

- **先验/Prior** - 原因 ==> 结果, 事情发生之前, 根据以往经验和分析得到的
  - **先验概率/Prior Probability**
    - `e.g. 抛硬币正面向上的概率`
  - **先验分布/Prior Distribution** - 对参数 $\theta$ 在看到数据之前的信念分布
- **后验/Posterior** - 结果 ==> 原因 事情发生, 在相关结果或者背景给定并纳入考虑之后的
  - **后验概率/Posterior Probability**
  - **后验分布/Posterior Distribution** - 看到数据之后对参数的信念分布
- **似然/Likelihood** - 已知原因（参数 $\theta$），数据出现的可能性

## 贝叶斯公式

$$
\underbrace{p(\theta\mid x)}_{\text{后验}}=\frac{\overbrace{p(x\mid\theta)}^{\text{似然}}\ \overbrace{p(\theta)}^{\text{先验}}}{\underbrace{p(x)}_{\text{证据}}},\qquad p(x)=\int p(x\mid\theta)\,p(\theta)\,d\theta
$$

其中：

| 符号 | 名称 | 含义 |
| --- | --- | --- |
| $x$ | 数据 | 结果，观察得到的数据 |
| $\theta$ | 参数 | 原因，决定数据分布的参数 |
| $p(\theta)$ | 先验 | 观察数据前对参数的信念 |
| $p(x\mid\theta)$ | 似然 | 给定参数下数据出现的概率；视作 $\theta$ 的函数时不是概率分布 |
| $p(\theta\mid x)$ | 后验 | 观察数据后对参数的更新信念 |
| $p(x)$ | 证据 / 边缘似然 | 对 $\theta$ 积分后的归一化常数，使后验积分为 1 |

表中：对比结论：后验 ∝ 似然 × 先验，证据只起归一化作用。

事件形式（离散）：

$$
P(A\mid B)=\frac{P(B\mid A)\,P(A)}{P(B)}
$$

- $P(A\mid B)$：事件 $B$ 发生后 $A$ 发生的概率，即条件概率、后验概率
- $P(B\mid A)$：事件 $A$ 发生后 $B$ 发生的概率

## 序贯更新

```mermaid
flowchart LR
    P0[先验] --> D1[数据 1]
    D1 --> P1[后验 1 = 新先验]
    P1 --> D2[数据 2]
    D2 --> P2[后验 2]
```

图中：贝叶斯推断可以**逐步更新**：上一步的后验作为下一步的先验。无论数据一次性给出还是分批给出，只要独立，最终后验相同。

## 例：估计硬币正面概率

设正面概率为 $\theta$，先验 $\theta\sim\mathrm{Beta}(\alpha,\beta)$；抛 $n$ 次出现 $k$ 次正面，则似然 $p(x\mid\theta)\propto\theta^{k}(1-\theta)^{n-k}$：

$$
p(\theta\mid x)\propto\theta^{\alpha+k-1}(1-\theta)^{\beta+n-k-1}\ \Longrightarrow\ \theta\mid x\sim\mathrm{Beta}(\alpha+k,\ \beta+n-k)
$$

其中：

- $\alpha,\beta$：先验的超参数，可以理解为「先验中虚拟的正面、反面次数」
- 后验仍是 Beta 分布：先验与似然**共轭**，更新只是把次数加上去；后验均值 $\dfrac{\alpha+k}{\alpha+\beta+n}$ 是先验均值与样本频率 $k/n$ 的加权平均
- 数据越多，后验越由数据决定，先验的影响越小

## 与 MLE、MAP 的关系

| 方法 | 做法 | 结果 |
| --- | --- | --- |
| 最大似然 MLE | $\hat\theta=\arg\max_\theta p(x\mid\theta)$ | 点估计，不用先验 |
| 最大后验 MAP | $\hat\theta=\arg\max_\theta p(\theta\mid x)=\arg\max_\theta\,[\log p(x\mid\theta)+\log p(\theta)]$ | 点估计，先验起正则化作用 |
| 完全贝叶斯 | 保留整个后验 $p(\theta\mid x)$ | 分布估计，量化不确定性 |

表中：

- 先验取常数时 MAP 退化为 MLE
- 高斯先验的 MAP 等价于 L2 正则，拉普拉斯先验等价于 L1 正则，见 [回归分析](https://github.com/junxnone/math/issues/73)
- 对比结论：贝叶斯方法比点估计多回答「有多确定」这个问题

## 后验预测

预测新数据 $\tilde{x}$ 时，对参数的不确定性取平均：

$$
p(\tilde{x}\mid x)=\int p(\tilde{x}\mid\theta)\,p(\theta\mid x)\,d\theta
$$

其中：每个可能的参数 $\theta$ 按后验概率加权，所以预测分布比「代入点估计」更宽，反映了参数不确定性。

## 先验的选择

- **共轭先验**：与似然同族，后验有闭式解（Beta-二项、Gamma-泊松、高斯-高斯）
- **无信息先验**：如均匀分布，尽量少引入主观信息
- **弱信息先验**：给出合理范围，起温和的正则化作用

## 在机器学习中的作用

- 朴素贝叶斯分类器、贝叶斯线性回归、高斯过程（见 [高斯过程进阶](https://github.com/junxnone/math/issues/20)）
- 贝叶斯优化：用后验指导下一次超参数采样
- 变分推断、MCMC：后验没有闭式解时的近似方法

## 常见误区

- 似然 $p(x\mid\theta)$ 不是 $\theta$ 的概率分布，对 $\theta$ 积分不一定为 1
- 「基础比率谬误」：忽略先验会高估罕见事件在检测阳性后发生的概率，见 [条件概率与贝叶斯](https://github.com/junxnone/math/issues/61) 的疾病检测例子
- MAP 不是后验的「全部」，多峰后验下点估计会丢失信息
