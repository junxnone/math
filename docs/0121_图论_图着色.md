# 图着色

图着色给图的顶点涂色，要求相邻顶点颜色不同。它形式简单，却是调度、频率分配、寄存器分配等一大类“冲突避免”问题的抽象，也是 NP 难问题的代表。

## 定义

**正常着色**是映射 $c:V\to\{1,\dots,k\}$，使得 $\{u,v\}\in E\Rightarrow c(u)\ne c(v)$。能用 $k$ 种颜色着色的图称 **$k$-可着色**，最小的 $k$ 称**色数** $\chi(G)$。同色的顶点集合是一个**独立集**，所以着色就是把顶点划分为 $\chi$ 个独立集。

| 图 | 色数 $\chi$ |
| -- | -- |
| 空图（无边） | $1$ |
| 二分图（无奇环） | $2$（有边时） |
| 偶环 $C_{2k}$ | $2$ |
| 奇环 $C_{2k+1}$ | $3$ |
| 完全图 $K_n$ | $n$ |
| 平面图 | $\le4$（四色定理） |

表中依次为图类和色数，其中完全图每两点相邻必须用不同颜色。$\chi(G)=2$ 的判定即二分图判定，用 BFS $O(n+m)$（见 [图论 二分图](https://github.com/junxnone/math/issues/23)）；而判定 $\chi(G)\le3$ 就已经是 NP 完全的。

## 上下界

$$
\omega(G)\le\chi(G)\le\Delta(G)+1,\qquad \chi(G)\ge\frac{n}{\alpha(G)}
$$

其中：

- $\omega(G)$：最大团的大小（团：两两相邻的顶点集合）。团内每个顶点颜色互不相同，所以下界成立
- $\Delta(G)$：最大度；**贪心着色**：按任意顺序给顶点涂上“邻居未用过的最小颜色”，每个顶点至多有 $\Delta$ 个邻居，所以至多用 $\Delta+1$ 种颜色
- $\alpha(G)$：最大独立集大小；每个颜色类是独立集（至多 $\alpha$ 个顶点），所以颜色数至少 $\dfrac n\alpha$
- **Brooks 定理**：连通图若既不是完全图也不是奇环，则 $\chi(G)\le\Delta(G)$
- $\omega<\chi$ 的情形存在：奇环 $C_5$ 的 $\omega=2$，$\chi=3$；Mycielski 构造能构造出 $\omega=2$ 而 $\chi$ 任意大的图（无三角形）

## 贪心着色与顺序

贪心算法的颜色数依赖顶点顺序：对任意图存在某个顺序使贪心恰好得到 $\chi$，但找到它是 NP 难的。常用启发式：

- **Welsh-Powell**：按度从大到小排序；
- **DSATUR**：每次选“相邻已用颜色种类最多”（饱和度最大）的顶点，实际效果好；
- **退化序 (degeneracy ordering)**：反复删去最小度顶点，按逆序着色，得到 $\chi\le d+1$，其中 $d$ 是图的**退化度**（对平面图 $d\le5$，所以平面图 $6$-可着色，稍加改进即得 $5$-着色）。

例：$5$ 个顶点的环 $C_5$，贪心沿环依次涂 $1,2,1,2$，最后一个顶点的两个邻居分别是 $2$ 和 $1$，只能涂 $3$，所以 $\chi(C_5)=3$。

## 四色定理

**平面图总可以用 $4$ 种颜色着色**（对应：任何地图的相邻区域可用至多 $4$ 色区分，把区域看作顶点、相邻关系看作边，所得到的是平面图，见 [图论 平面图](https://github.com/junxnone/math/issues/123)）。1976 年 Appel 与 Haken 借助计算机证明（后来被简化并形式化验证）。更弱的结论如 $5$-色定理有简短的人工证明（基于欧拉公式推出平面图必有度 $\le5$ 的顶点）。

## 边着色与色多项式

- **边着色**：给边涂色使相邻边（共享顶点）颜色不同，色指数 $\chi'(G)$。**Vizing 定理**：$\Delta\le\chi'(G)\le\Delta+1$（只有两种可能）。二分图满足 $\chi'=\Delta$（König）。应用：循环赛的轮次安排。
- **色多项式** $P(G,k)$：用 $k$ 种颜色的正常着色方案数，由删除-收缩递推 $P(G,k)=P(G-e,k)-P(G/e,k)$ 得到，是关于 $k$ 的多项式（见 [组合计数](https://github.com/junxnone/math/issues/94)）。例：树有 $P=k(k-1)^{n-1}$；$K_n$ 有 $P=k(k-1)\cdots(k-n+1)$；三角形 $P=k(k-1)(k-2)$。$\chi(G)$ 是使 $P(G,k)>0$ 的最小正整数 $k$。

## 复杂度与近似

- 判定 $3$-着色 NP 完全；计算 $\chi(G)$ NP 难，且在多项式时间内很难近似（对任意 $\varepsilon>0$ 无 $n^{1-\varepsilon}$ 近似，除非 P=NP，见 [图论 NP难问题](https://github.com/junxnone/math/issues/125)）。
- 精确算法：回溯 + 剪枝、动态规划 $O(2.44^n)$、整数规划/SAT 求解器。
- 特殊图类可多项式求解：区间图、弦图（完美消除序上的贪心是最优的）、二分图。

## 应用

- **调度与排课**：考试/课程为顶点，有学生冲突的两门课连边，颜色代表时间段，$\chi$ 就是最少需要的时间段数
- **寄存器分配**：变量为顶点，生命周期重叠的变量连边（冲突图），颜色代表寄存器，图着色即编译器的核心优化
- **频率分配**：基站为顶点，距离近的连边，颜色是频道
- **数独**：每个格子为顶点，同行/列/宫的格子连边，$9$ 种颜色的着色
- **地图着色**、交通灯相位设计、并行计算中的任务冲突
