# 树

树是连通而无环的图，是最基本、应用最广的图结构：文件系统、组织结构、决策树、语法分析树、网络的生成树都是树。

## 等价定义

对 $n$ 个顶点的无向图 $T$，下列命题**两两等价**：

1. $T$ 连通且无环；
2. $T$ 连通且恰有 $n-1$ 条边；
3. $T$ 无环且恰有 $n-1$ 条边；
4. 任意两顶点之间有且仅有一条路径；
5. $T$ 连通，且删去任何一条边后不再连通（极小连通）；
6. $T$ 无环，且加入任何一条新边后恰产生一个环（极大无环）。

其中 $n-1$ 是树的边数，它来自对顶点个数的归纳：任何非平凡的树至少有两个叶子（度为 $1$ 的顶点），删去一个叶子及其边仍是树，边数与顶点数各减 $1$。**森林**是无环图，各连通分量都是树，边数 $=n-c$（$c$ 为连通分量个数）。

## 术语（有根树）

指定一个顶点为**根**后，树变成有层次的结构：

- **父/子**：与根距离更近的邻居是父，更远的是子；没有子的顶点是**叶子**，其余是内部顶点。
- **深度**：顶点到根的距离；**高度**：树中最大深度；**子树**：某顶点及其所有后代。
- **二叉树**：每个顶点至多 $2$ 个子顶点（左、右）；**满二叉树**：每个内部顶点恰有 $2$ 个子顶点；**完全二叉树**：除最后一层外各层全满、最后一层靠左（堆的结构）。

二叉树的计数性质：高度为 $h$ 的二叉树至多有 $2^{h+1}-1$ 个顶点；$n$ 个顶点的完全二叉树高度 $\lfloor\log_2n\rfloor$（所以平衡二叉搜索树的操作是 $O(\log n)$）；满二叉树若有 $i$ 个内部顶点则有 $i+1$ 个叶子、共 $2i+1$ 个顶点。

## 二叉树遍历

| 遍历 | 顺序 | 用途 |
| -- | -- | -- |
| 前序 | 根 → 左 → 右 | 复制树、序列化、前缀表达式 |
| 中序 | 左 → 根 → 右 | 二叉搜索树按序输出 |
| 后序 | 左 → 右 → 根 | 释放内存、求子树信息、后缀表达式 |
| 层序 | 逐层从左到右（BFS） | 按层处理 |

表中依次为遍历方式、访问顺序和用途。前三种是 DFS 的不同时机（见 [图论 图的表示与遍历](https://github.com/junxnone/math/issues/114)）。例：表达式 $(a+b)\times c$ 的表达式树，中序得 $(a+b)\times c$，后序得 $ab+c\times$（逆波兰表达式）。仅凭前序序列不能唯一确定树，但前序（或后序）+ 中序可以。

## 生成树与计数

连通图 $G$ 的**生成树**是包含所有顶点的树，由 $n-1$ 条边组成。$G$ 有生成树当且仅当连通。生成树计数：

$$
\tau(K_n)=n^{\,n-2}\ \ (\text{Cayley 公式}),\qquad \tau(G)=\det L^{(i)}\ \ (\text{矩阵树定理})
$$

其中：

- $\tau(G)$：图的生成树个数；$K_n$ 是 $n$ 个顶点的完全图（这等于 $n$ 个带标号顶点上的树的总数）
- $L=D-A$：拉普拉斯矩阵（$D$ 是度对角矩阵，$A$ 是邻接矩阵），$L^{(i)}$ 是删去第 $i$ 行第 $i$ 列后的 $(n-1)$ 阶子矩阵（任取 $i$ 结果相同）
- 例：三角形 $K_3$：$L^{(1)}=\begin{bmatrix}2&-1\\-1&2\end{bmatrix}$，$\det=3=3^{3-2}$ ✓（三棵生成树：去掉任一条边）

用最小权重选取生成树见 [图论 最小生成树](https://github.com/junxnone/math/issues/116)。

## Prüfer 序列

$n$ 个带标号顶点的树与长为 $n-2$、元素取自 $\{1,\dots,n\}$ 的序列一一对应，这个对应称为 Prüfer 编码。共 $n^{n-2}$ 个序列，因此 Cayley 公式得证。编码：反复删去编号最小的叶子，并记下它的邻居。例：树的边 $\{1\text{-}4,\ 2\text{-}4,\ 3\text{-}4,\ 4\text{-}5\}$：最小叶子 $1$（邻居 $4$）→ 记 $4$；删 $1$ 后最小叶子 $2$ → 记 $4$；删 $2$ 后最小叶子 $3$ → 记 $4$；序列为 $(4,4,4)$（长 $5-2=3$）。顶点的度 $=$ 它在序列中出现的次数 $+1$。

## 树上的常见问题

- **直径**：任取一点 BFS 找到最远点 $u$，再从 $u$ BFS 找到最远点 $v$，$d(u,v)$ 即直径（两次 BFS，$O(n)$）。
- **最近公共祖先 (LCA)**：倍增或欧拉序 + RMQ，$O(\log n)$ 或 $O(1)$ 查询。
- **树上动态规划**：对后序遍历自底向上合并子树信息（如树的最大独立集、树的重心）。
- **树的中心/重心**：删去重心后各子树大小不超过 $n/2$，用于分治。

## 重要的树结构

- **二叉搜索树 (BST)**：左子树键值小于根、右子树大于根；平衡变体（AVL、红黑树）保证 $O(\log n)$。
- **堆**：完全二叉树，父节点不小于（或不大于）子节点，用数组存储，实现优先队列（Dijkstra 中使用，见 [图论 最短路径](https://github.com/junxnone/math/issues/115)）。
- **Trie**（前缀树）、**线段树**、**树状数组**。
- **决策树**：每个内部顶点是一个特征判断，叶子是预测值，是机器学习的基本模型。

## 熵与编码树

Huffman 编码树是满二叉树，叶子对应符号，从根到叶的路径给出码字；码长满足 Kraft 不等式 $\sum2^{-\ell_i}\le1$（见 [信源编码](https://github.com/junxnone/math/issues/88)）。

## 应用

- 文件系统、DOM、组织结构图
- 数据结构：搜索、索引（B 树、数据库）、优先队列
- 网络：生成树协议避免环路、组播树
- 机器学习：决策树、随机森林、层次聚类树状图
- 语法分析与表达式求值
