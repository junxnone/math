# NP难问题

许多重要的图问题至今没有已知的多项式时间算法，并且很可能不存在。理解哪些问题是 NP 难的，以及如何应对（近似、启发式、参数化、特殊图类），是图算法实践的重要部分。

## P、NP 与归约

- **P**：能在多项式时间内求解的判定问题（如最短路径、最小生成树、匹配、网络流）。
- **NP**：解可以在多项式时间内被**验证**的判定问题（给出一个哈密顿回路，很容易验证）。
- **NP 完全**：NP 中最难的一类；若其中任一问题有多项式算法，则 $\text{P}=\text{NP}$。
- **NP 难**：至少与 NP 完全一样难（不一定属于 NP，如优化问题）。

**多项式时间归约** $A\le_pB$：把 $A$ 的任何实例在多项式时间内转换成 $B$ 的实例，答案保持一致。若 $A$ 是 NP 难的且 $A\le_pB$，则 $B$ 也是 NP 难的。第一个 NP 完全问题是 SAT（Cook-Levin，见 [命题逻辑](/0093_离散数学_命题逻辑)），其后 Karp 证明了 21 个经典问题（多为图问题）。

## 经典的 NP 难图问题

| 问题 | 描述 |
| -- | -- |
| 团 (Clique) | 找最大的两两相邻的顶点集 |
| 独立集 (Independent Set) | 找最大的两两不相邻的顶点集 |
| 顶点覆盖 (Vertex Cover) | 找最小的顶点集，使每条边至少有一个端点在其中 |
| 图着色 | 用最少颜色使相邻顶点异色（$k\ge3$） |
| 哈密顿回路 / TSP | 经过每个顶点恰好一次 / 最短的这样的回路 |
| 最大割 (Max-Cut) | 把顶点分成两部分使跨部分的边最多 |
| 支配集 | 最小顶点集，使每个顶点要么在集中要么与集中顶点相邻 |
| Steiner 树 | 连通指定终端顶点的最小权子树 |
| 图同构 | 两个图是否同构（NP 与 coNP 之间，不知是否 NP 完全） |

表中依次为问题名称和描述。对比能高效求解的相近问题：最小生成树（P）vs Steiner 树（NP 难）；欧拉回路（P）vs 哈密顿回路（NP 完全，见 [图论 欧拉图与哈密顿图](/0122_图论_欧拉图与哈密顿图)）；二分图最大匹配（P）vs 一般图三维匹配（NP 完全）；$2$-着色（P）vs $3$-着色（NP 完全，见 [图论 图着色](/0121_图论_图着色)）。

## 团、独立集、顶点覆盖的关系

$$
S\ \text{是独立集}\iff V\setminus S\ \text{是顶点覆盖};\qquad S\ \text{是 }G\text{ 的团}\iff S\ \text{是补图 }\bar G\text{ 的独立集}
$$

其中 $\bar G$ 是补图（相同顶点集，边恰好是 $G$ 中缺失的那些）。由此 $\alpha(G)+\tau(G)=n$，且三个问题可以互相多项式归约，所以同难。推导：独立集内没有边，因此每条边至少有一个端点在补集，补集是顶点覆盖；反之亦然。例：三角形 $K_3$：最大团 $3$，最大独立集 $1$，最小顶点覆盖 $2$，$1+2=3$ ✓。

## 典型归约：3-SAT 到独立集

给定 $3$-CNF 公式（每个子句有 $3$ 个文字），对每个子句建一个三角形（$3$ 个顶点代表该子句的 $3$ 个文字），再把互补的文字（如 $x$ 与 $\neg x$）之间连边。设有 $k$ 个子句，则公式可满足 $\iff$ 图有大小为 $k$ 的独立集：每个三角形至多取一个顶点（取到的文字置为真），互补文字相连保证不矛盾。这说明独立集 NP 难。

## 应对策略

**1. 近似算法**：多项式时间内给出有可证明保证的解，近似比 $\rho=\dfrac{\text{ALG}}{\text{OPT}}$（最小化问题 $\ge1$）。

| 问题 | 方法 | 近似比 |
| -- | -- | -- |
| 顶点覆盖 | 反复取极大匹配的两端点 | $2$ |
| 度量 TSP | MST 双倍 / Christofides | $2$ / $1.5$ |
| Max-Cut | 随机分组 / SDP 取整（Goemans-Williamson） | $0.5$ / $0.878$ |
| 集合覆盖 | 贪心 | $\ln n$ |
| 团 / 独立集 | — | 无 $n^{1-\varepsilon}$ 近似（除非 P=NP） |

表中依次为问题、方法和近似比。顶点覆盖 2-近似：任取一条未覆盖的边，把两端点都加入覆盖——这些边构成匹配，最优解必须至少覆盖这个匹配的每条边各一个端点，所以 $\text{ALG}\le2\,\text{OPT}$（见 [图论 匹配](/0120_图论_匹配)）。

**2. 精确指数算法与剪枝**：回溯、分支定界、动态规划（Held-Karp $O(2^nn^2)$）、整数线性规划求解器（见 [线性规划](/0080_优化理论_线性规划)）、SAT/SMT 求解器——对实际规模的实例常常很有效。

**3. 参数化算法 (FPT)**：以某个参数 $k$（解的大小、树宽）为指数，其余多项式，$O(f(k)\cdot n^c)$。例：顶点覆盖大小为 $k$，分支法 $O(2^kn)$（取一条边，两个端点至少一个在覆盖中，递归）。

**4. 特殊图类**：许多 NP 难问题在树、二分图、弦图、平面图（树宽小，见 [图论 平面图](/0123_图论_平面图)）、区间图上多项式可解。

**5. 启发式与元启发式**：贪心、局部搜索、模拟退火（见 [模拟退火](/0014_Math_SA)）、遗传算法、蚁群算法、禁忌搜索。不保证最优，但常能在可接受时间给出好解。

**6. 凸松弛**：把整数约束放松成连续（LP、SDP 松弛），再取整（见 [非凸优化](/0083_优化理论_非凸优化)）。

## 难度的“相变”

NP 难是**最坏情形**结论。随机实例往往存在相变：例如随机 $3$-SAT，子句数与变量数比 $\alpha=m/n\approx4.27$ 附近从几乎总可满足突变为几乎总不可满足，难的实例集中在阈值附近；图着色、团问题在随机图 $G(n,p)$ 上也有类似阈值（见 [图论 随机图与复杂网络](/0126_图论_随机图与复杂网络)）。

## 应用

- 评估问题难度，避免寻找不存在的多项式算法，转而选择近似或启发式
- 网络设计、调度、芯片布局、物流路径规划
- 密码学：图同构、哈密顿回路的零知识证明
- 机器学习：最大团用于社区发现，$L_0$ 稀疏、聚类的组合优化
