# 数值微分与积分

当函数只有数值（采样数据、黑盒程序）或原函数没有初等表达式时，就需要用数值方法近似导数和积分。基本思路：用插值多项式近似函数，再对多项式精确求导或积分。

## 数值微分：有限差分

由泰勒展开 $f(x\pm h)=f\pm hf'+\tfrac{h^2}2f''\pm\tfrac{h^3}6f'''+\cdots$（见 [中值定理与泰勒公式](https://github.com/junxnone/math/issues/51)）：

| 名称 | 公式 | 截断误差 |
| -- | -- | -- |
| 前向差分 | $\dfrac{f(x+h)-f(x)}h$ | $\tfrac h2f''(\xi)=O(h)$ |
| 后向差分 | $\dfrac{f(x)-f(x-h)}h$ | $O(h)$ |
| 中心差分 | $\dfrac{f(x+h)-f(x-h)}{2h}$ | $\tfrac{h^2}6f'''(\xi)=O(h^2)$ |
| 二阶中心差分 | $\dfrac{f(x+h)-2f(x)+f(x-h)}{h^2}$ | $\tfrac{h^2}{12}f^{(4)}=O(h^2)$ |

表中依次为名称、公式和截断误差，$h$ 是步长，$\xi$ 是区间内某点。中心差分对称，奇次项抵消，所以精度高一阶。二阶差分近似二阶导数（也是图像拉普拉斯滤波器的一维形式，见 [曲线曲面积分与场论](https://github.com/junxnone/math/issues/56)）。

## 步长的权衡

总误差 = 截断误差 + 舍入误差。舍入误差来自分子相消（见 [误差与浮点数](https://github.com/junxnone/math/issues/107)），约为 $\dfrac{\varepsilon\,|f|}{h}$（$\varepsilon$ 为机器精度）：

$$
E(h)\approx\underbrace{C\,h^p}_{\text{截断}}+\underbrace{\frac{\varepsilon|f|}{h}}_{\text{舍入}}\ \Longrightarrow\ h_{\text{opt}}\sim\varepsilon^{1/(p+1)}
$$

其中 $C$ 是与高阶导数有关的常数，$p$ 是方法的阶。双精度下：前向差分 $h_{\text{opt}}\sim10^{-8}$（最优误差约 $10^{-8}$）；中心差分 $h_{\text{opt}}\sim10^{-5}$（最优误差约 $10^{-10}$）。步长不是越小越好。

例：$f=e^x$ 在 $x=0$ 的导数，$h=0.1$：前向 $\dfrac{e^{0.1}-1}{0.1}=1.0517$（误差 $5\times10^{-2}$）；中心 $\dfrac{e^{0.1}-e^{-0.1}}{0.2}=1.00167$（误差 $1.7\times10^{-3}$）。

**理查森外推**：用步长 $h$ 与 $h/2$ 的两个中心差分 $D(h),D(h/2)$ 消去 $h^2$ 项：

$$
D^*=\frac{4D(h/2)-D(h)}{3}\quad(\text{误差 }O(h^4))
$$

其中 $D(h)$ 是步长 $h$ 的近似值。这是 Romberg 积分的基础。

**自动微分**不是数值微分：它按链式法则精确传播导数，没有截断误差，是深度学习反向传播的基础；数值微分主要用于**检验**解析梯度（见 [多元函数微分](https://github.com/junxnone/math/issues/54)）。

## 数值积分：求积公式

把 $[a,b]$ 分成 $n$ 等份，$h=\dfrac{b-a}n$，$x_i=a+ih$。用插值多项式近似被积函数再精确积分，得到“加权求和”形式的求积公式 $\int_a^bf\approx\sum w_if(x_i)$：

| 公式 | 近似 | 复合公式 | 误差 |
| -- | -- | -- | -- |
| 矩形（中点） | 每段取常数 | $h\sum f(x_{i+1/2})$ | $\tfrac{(b-a)h^2}{24}f''=O(h^2)$ |
| 梯形 | 每段取线性 | $\tfrac h2\bigl[f_0+2\sum_{i=1}^{n-1}f_i+f_n\bigr]$ | $-\tfrac{(b-a)h^2}{12}f''=O(h^2)$ |
| 辛普森 | 每两段取二次 | $\tfrac h3\bigl[f_0+4\sum_{\text{奇}}f_i+2\sum_{\text{偶}}f_i+f_n\bigr]$（$n$ 偶数） | $-\tfrac{(b-a)h^4}{180}f^{(4)}=O(h^4)$ |

表中依次为公式、局部近似、复合公式和误差，$f_i=f(x_i)$。精度阶对应能被精确积分的多项式次数：梯形精确到 1 次，辛普森精确到 3 次。

例：$\int_0^1e^xdx=e-1=1.718282$：

- 梯形 $n=1$：$\tfrac12(1+e)=1.8591$（误差 $0.141$）；$n=2$：$\tfrac{0.5}2(1+2e^{0.5}+e)=1.7539$（误差 $0.036$，误差约缩小到 $\tfrac14$，符合 $O(h^2)$）。
- 辛普森 $n=2$：$\tfrac{0.5}3(1+4e^{0.5}+e)=1.71886$（误差 $5.8\times10^{-4}$）：同样两个子区间，精度高两个数量级。

## 高斯求积

选择节点和权重使 $n$ 点公式精确积分次数不超过 $2n-1$ 的多项式（自由度 $2n$：$n$ 个节点 + $n$ 个权重）：

$$
\int_{-1}^1f(x)\,dx\approx\sum_{i=1}^nw_if(x_i)
$$

其中节点 $x_i$ 是勒让德多项式 $P_n$ 的零点，$w_i$ 是权重（均为正）。例：$n=2$：$x_{1,2}=\pm\dfrac1{\sqrt3}\approx\pm0.577$，$w_1=w_2=1$，精确积分三次多项式：$\int_{-1}^1x^2dx=\tfrac23$，而 $\bigl(\tfrac1{\sqrt3}\bigr)^2+\bigl(\tfrac1{\sqrt3}\bigr)^2=\tfrac23$ ✓。对光滑函数收敛极快（指数级），区间 $[a,b]$ 通过线性变换映射到 $[-1,1]$。变体：高斯-埃尔米特（权函数 $e^{-x^2}$，用于期望计算，见 [常见分布](https://github.com/junxnone/math/issues/63)）、高斯-拉盖尔。

## 自适应与外推

- **自适应求积**：对每个子区间估计误差，只在函数变化剧烈处细分（如 `scipy.integrate.quad`），提高效率。
- **Romberg 积分**：对梯形公式 $T(h)$ 的序列 $T(h),T(h/2),\dots$ 反复做理查森外推，得到高阶精度。
- 奇异或无穷区间：变量替换（见 [积分](https://github.com/junxnone/math/issues/52) 中的换元与反常积分），如 $x=\tan\theta$ 把 $[0,\infty)$ 映射到有限区间。

## 多维积分与蒙特卡洛

$d$ 维网格求积需要 $N=n^d$ 个点（维数灾难）。蒙特卡洛积分用随机采样：

$$
\int_\Omega f\,d\mathbf{x}\approx\frac{|\Omega|}N\sum_{i=1}^Nf(\mathbf{x}_i),\qquad \text{误差}\sim\frac{\sigma_f}{\sqrt N}
$$

其中 $|\Omega|$ 是区域体积，$\mathbf{x}_i$ 是均匀采样点，$\sigma_f$ 是 $f$ 的标准差（由大数定律与中心极限定理保证，见 [大数定律与中心极限定理](https://github.com/junxnone/math/issues/66)）。收敛慢（$O(N^{-1/2})$）但**与维数无关**，所以高维积分（贝叶斯推断中的边缘似然、金融、渲染）只能用它；改进：重要性采样、拟蒙特卡洛（低差异序列）、分层采样（见 [重积分](https://github.com/junxnone/math/issues/55)）。

## 应用

- 科学计算中的积分、概率密度的归一化与期望（见 [期望方差与矩](https://github.com/junxnone/math/issues/64)）
- 差分法求解偏微分方程、边缘检测（图像梯度）
- 物理渲染（路径追踪是蒙特卡洛积分）
- 为微分方程数值解提供离散格式（见 [常微分方程数值解](https://github.com/junxnone/math/issues/112)）
